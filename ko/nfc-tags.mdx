title: "NFC 태그"
---

NFC(근거리 무선 통신) 태그는 어디에나 붙일 수 있는 작고 저렴한 물리적 스티커이며, Habitify에서는 이를 습관을 위한 물리적 트리거로 사용할 수 있습니다. 휴대전화의 잠금을 해제하고 앱을 연 다음 체크할 습관을 찾는 대신, 휴대전화를 태그에 대면 체크인이 자동으로 이루어집니다.

핵심은 주변 환경에 습관과 직접 연결되는 실제 접점을 만들어, 공간이 습관 시스템과 분리된 것이 아니라 그 연장선이 되도록 하는 것입니다. 헬스장 가방에 붙인 태그로 "운동" 습관을 실행하고, 책장에 붙인 태그로 "독서"를 실행하며, 침대 옆에 붙인 태그로 "수면"을 실행할 수 있습니다. 습관은 앱을 열어야 한다고 기억해야 하는 일이 아니라, 하루를 보내며 자연스럽게 마주치는 일이 됩니다.

    ## 새로운 NFC-습관 연동 설정하기

    1. Habitify 앱에서 **설정**으로 이동합니다.
    2. **연동** 섹션에서 **NFC**를 탭합니다.
    3. NFC 화면 아래쪽에서 **새 NFC 태그 스캔** 버튼을 탭합니다.
    4. NFC 태그에 휴대전화를 댑니다. <br />_인터넷에서 사용 중인 휴대전화의 NFC 리더 위치를 검색할 수 있습니다. 보통 카메라 근처에 있습니다._
    5. 스캔이 끝나면 다음을 설정합니다.
       1. **NFC 태그를 탭했을 때**에서 앱이 실행할 동작을 선택합니다.
       2. **습관**에서 습관을 선택합니다.
    6. 마지막으로 '**저장**' 버튼을 탭합니다.

    ### 지원되는 동작

    - **완료로 표시**: NFC 태그를 스캔하여 습관을 완료합니다.
    - **건너뜀으로 표시**: NFC 태그를 스캔하여 오늘의 습관을 건너뜁니다.
    - **미달성으로 표시**: NFC 태그를 스캔하여 오늘의 습관을 미달성으로 표시합니다.
    - **진행 상황 기록**: NFC 태그를 스캔하여 미리 정의한 진행 기록을 추가합니다.
    - **질문하기**: NFC 태그를 스캔하고 실행할 동작을 선택합니다.

    ## NFC 태그로 습관 체크인하기

    프로그래밍한 NFC 태그로 체크인하는 방법은 간단합니다.

    - 휴대전화로 태그를 스캔하면 푸시 알림이 표시됩니다.
    - 푸시 알림을 탭하여 앱을 열면 설정한 동작이 실행됩니다.

    <Note>
      **최상의 사용 경험을 위해 Habitify 앱을 백그라운드에서 계속 실행해 두세요.**

      앱이 완전히 종료된 경우 NFC 태그를 스캔하고 푸시 알림을 탭해도 의도한 동작이 원활하게 완료되지 않고 저널 보기만 열립니다.
    </Note>

    ## **새로운 NFC-습관 연동 설정하기**

    1. Habitify 앱에서 **설정**으로 이동합니다.
    2. **자동** 섹션에서 **NFC**를 탭하여 엽니다.
    3. **새 NFC 태그 스캔** 버튼을 탭합니다.
    4. NFC 태그에 휴대전화를 댑니다. <br />_인터넷에서 사용 중인 휴대전화의 NFC 리더 위치를 검색할 수 있습니다. 보통 카메라 근처에 있습니다._
    5. 스캔이 끝나면 다음을 설정할 수 있습니다.
       1. **NFC 탭 완료**에서 앱이 실행할 동작을 선택합니다.
       2. **습관**에서 앱이 동작을 실행할 습관을 선택합니다.
    6. 마지막으로 오른쪽 위 모서리의 **저장** 버튼을 탭합니다.

    ### 지원되는 동작

    - **완료로 표시**: NFC 태그를 스캔하여 습관을 완료합니다.
    - **건너뛴 것으로 표시**: NFC 태그를 스캔하여 오늘의 습관을 건너뜁니다.
    - **실패로 표시**: NFC 태그를 스캔하여 오늘의 습관을 실패로 표시합니다.
    - **타이머 시작**: NFC 태그를 스캔하여 습관의 타이머 세션을 시작합니다.
    - **기록 값**: NFC 태그를 스캔하여 미리 정의한 진행 기록을 추가합니다.
    - **물어보기**: NFC 태그를 스캔하고 실행할 동작을 선택합니다.

    ## NFC 태그로 습관 체크인하기

    프로그래밍한 NFC 태그로 체크인하는 방법은 간단합니다.

    - 푸시 알림이 표시될 때까지 휴대전화로 태그를 스캔하기만 하면 됩니다.
    - 알림을 탭하여 앱을 열면 설정 중에 구성한 대로 다음 단계가 실행됩니다.
