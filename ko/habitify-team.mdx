Habitify Team을 사용하면 팀이나 조직의 Premium 이용 권한을 대량으로 간편하게 구매하고 배포할 수 있습니다.

각 구성원이 개별적으로 결제하는 대신 한 사람이 구매와 라이선스를 관리한 다음, 공유 팀 코드를 통해 모두에게 이용 권한을 배포합니다.

## 팀 라이선스 구매하기

1. 팀 구독 전용 웹페이지로 이동합니다. <br />[https://habitify.me/habitify-for-team](https://habitify.me/habitify-for-team)
2. 랜딩 페이지에서 **팀 업그레이드** 버튼을 클릭합니다.
3. 구매 구성 화면에서 다음을 진행합니다.
   ![팀 구매](/images/Team-Purchase.png "팀 구매")
   1. 라이선스 모델로 **1개월** 또는 **12개월**을 선택합니다.
   2. 팀 구성원 수에 해당하는 **사용자 수**(좌석 수)를 입력합니다.<br />최소 30명이 필요합니다.
   3. **구매 [총액]** 버튼을 탭하여 계속합니다.
4. 주문 세부 정보를 다시 확인한 다음 **구매** 버튼을 탭합니다.
5. _보안 결제 창_에서 다음 정보를 입력해야 합니다.
   - **이메일 주소:** 결제 청구서와 라이선스 코드 설정 링크가 이 주소로 전송되므로 매우 중요합니다.
   - **국가:** 결제와 정책 적용에 필요합니다.
   - **결제 수단:** **PayPal** 또는 직불/신용 **카드** 결제를 선택합니다.

결제가 완료되면 주문 확인 이메일을 받게 됩니다. 이 이메일에는 다음 단계로 이동하는 중요한 링크가 포함되어 있습니다. 이메일을 열어 링크를 확인하고 라이선스 코드를 설정하세요.

## 팀 라이선스 코드 설정하기

구매 후에는 팀 구성원이 자신의 계정에서 Habitify PRO를 활성화할 때 사용할 고유 코드를 만들어야 합니다.

받은편지함에서 제목이 **"Habitify 라이선스 구성"**인 이메일을 찾아 그 안의 링크를 클릭하세요.

링크를 클릭하면 설정 페이지로 이동합니다. 여기에서 다음 정보를 입력합니다.

- **팀 이름** 및 **고유 코드**: 이 정보는 이용 코드 생성에 사용됩니다.
- **설명**(선택 사항)
- **팀 로고**(선택 사항)

모든 설정을 마쳤으면 **저장** 버튼을 탭합니다.

![팀 코드 설정](/images/Team-CodeSetup.png "팀 코드 설정")

코드 생성이 완료되었음을 확인하는 최종 화면으로 이동합니다. 이 페이지에는 **공유 링크**도 표시됩니다.

이제 **공유 링크**를 팀 구성원에게 직접 보낼 수 있습니다. 구성원이 링크를 열면 팀 이름, 로고, 그리고 Premium 이용 권한을 활성화하는 데 필요한 고유 코드가 표시된 페이지로 이동합니다.

## 팀 라이선스 코드로 활성화하기

다음 항목을 준비해 주세요.

1. **Habitify 계정:** Habitify 앱이 설치되어 있고 개인 Habitify 계정에 로그인되어 있어야 합니다. 아직 계정을 만들지 않았다면 먼저 계정을 만드세요.
2. **라이선스 코드:** 팀 관리자가 제공한 고유 라이선스 코드가 필요합니다. 코드가 없다면 관리자나 팀 관리자에게 직접 문의하여 받으세요.

## **팀 라이선스 작동 방식**

팀 라이선스의 핵심 규칙은 다음과 같습니다.

- **만료일 없음:** 활성화 코드에는 만료일이 없습니다. 지금 구매한 뒤 팀이 준비되었을 때 언제든 배포할 수 있습니다.
- **계정당 1회 사용:** 각 Habitify 계정에서는 특정 코드를 한 번만 사용할 수 있습니다.
- **사용 시점부터 기간 시작:** PRO 이용 기간은 코드를 구매한 날부터 시작되지 않습니다. 팀 구성원이 앱에서 실제로 코드를 사용하는 순간부터 시작됩니다.

**예:** **2026년 7월 1일**에 1개월 팀 라이선스 코드를 구매했다고 가정해 보겠습니다. 팀 구성원이 **2026년 7월 7일**까지 기다렸다가 그 코드를 사용하여 Premium을 활성화하면 **2026년 8월 7일**까지 PRO의 모든 기능을 이용할 수 있습니다.

**Habitify Team은 구독이 아니라 기간 한정 이용 라이선스이므로 자동으로 갱신되지 않습니다.** 활성화된 이용 기간이 끝나면 팀 구성원의 계정은 자동으로 무료 버전으로 돌아갑니다.

PRO 이용 권한을 복원하려면 관리자가 새 활성화 코드를 구매하여 팀 구성원에게 제공해야 합니다. 구성원은 해당 코드를 사용해 다음 PRO 이용 주기를 시작할 수 있습니다.
