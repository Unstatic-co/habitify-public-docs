---
title: "작업"
---

작업은 특정 습관에 연결할 수 있는 작은 일회성 할 일입니다. 습관의 주된 목표와는 별개지만 해당 습관에 계속 연결됩니다. 습관 자체를 복잡하게 만들지 않으면서 그 주변에서 생기는 작은 보조 행동을 기록하는 방법이라고 생각해 보세요. 예를 들어 "독서" 습관을 시작하기 전에 가져올 책이나 첫 헬스장 운동 전에 살 장비를 작업으로 만들 수 있습니다.

작업은 연결된 습관과 달리 반복되지 않습니다. 한 번 만들고 한 번 완료하면 끝납니다.

## 작업과 체크리스트 비교

둘 다 습관 안에 있지만 서로 다른 문제를 해결합니다.

- **작업**: 일회성 할 일입니다. 만들고 한 번 완료하면 끝납니다.
- **체크리스트:** 습관을 실천할 때마다 초기화되어 반복 적용되는 단계 모음입니다(예: "아침 루틴" 습관 안의 고정된 아침 루틴 체크리스트).

한 번만 해야 하는 일이라면 작업을 사용하세요. 습관과 함께 반복되는 일이라면 체크리스트를 사용하세요.

    ## 할 일 추가하기

    1. _저널_에서 습관을 탭합니다.
    2. _개별 진행 상황_의 오른쪽 상단에서 **•••**를 탭합니다.
    3. **이 습관 정보**를 선택합니다.
    4. **할 일** 아래에서 **새 할 일**을 탭합니다.
    5. 할 일 이름을 입력하고 할 일의 날짜와 시간을 설정합니다.
    6. 마지막으로 키보드의 **✓** 또는 **↵**를 탭해 새 할 일을 저장합니다.

    ## 할 일 완료하기

    1. **저널**에서 습관을 탭합니다.
    2. 개별 진행 상황의 오른쪽 상단에서 **•••**를 탭합니다.
    3. **이 습관 정보**를 선택합니다.
    4. **할 일** 아래에서 할 일 앞의 〇를 탭해 완료로 표시합니다.

    완료로 표시하면 다음에 이 보기를 열 때 해당 할 일이 목록에서 사라지므로, 습관 페이지에는 아직 해야 할 일만 표시됩니다.

    ## 할 일 삭제하기

    아직 완료하지 않은 할 일을 삭제하려면 다음 단계를 따릅니다.

    1. **저널**에서 습관을 탭합니다.
    2. 개별 진행 상황의 오른쪽 상단에서 **•••**를 탭합니다.
    3. **이 습관 정보**를 선택합니다.
    4. **할 일** 아래에서 할 일을 왼쪽으로 밀고 **삭제**를 선택합니다.

    ## 작업 추가하기

    1. **일지**에서 습관을 탭해 개별 진행 상황을 엽니다.
    2. 개별 진행 상황에서 **대해서** 탭으로 전환합니다.
    3. **작업** 아래에서 **새 작업**을 탭합니다.
    4. 작업 이름을 입력하고 키보드에서 **완료**를 탭해 저장합니다.
    5. 작업을 두 번 탭해 작업의 날짜와 시간을 편집합니다.

    ## 작업 완료하기

    1. **일지**에서 습관을 탭해 개별 진행 상황을 엽니다.
    2. 개별 진행 상황에서 **대해서** 탭으로 전환합니다.
    3. **작업** 아래에서 작업 옆의 **〇**를 탭해 완료합니다.

    작업을 처리한 후에는 습관의 **대해서** 탭에서 바로 완료로 표시하세요.

    ## 작업 삭제하기

    1. **일지**에서 습관을 탭해 개별 진행 상황을 엽니다.
    2. 개별 진행 상황에서 **대해서** 탭으로 전환합니다.
    3. **작업** 아래에서 작업을 왼쪽으로 밀고 **삭제**를 선택합니다.

    ## 모든 작업 검토하기

    작업을 완료로 표시해도 기록이 삭제되지는 않습니다. 완료한 작업을 언제든지 다시 확인할 수 있습니다.

    1. 습관의 개별 진행 상황 오른쪽 상단에서 **(⋮) 버튼**을 탭합니다.
    2. **행동 리스트 관리**를 탭해 엽니다.

    여기에서 일반적인 진행 상황과 함께, 습관을 뒷받침하기 위해 실행했거나 아직 대기 중인 행동의 전체 기록을 확인할 수 있습니다.

    ## 작업 추가하기

    1. 습관 목록 보기에서 습관의 개별 진행 상황을 엽니다.
       1. **그리드**에서는 습관을 한 번 클릭합니다.
       2. **목록**에서는 습관을 두 번 클릭합니다.
    2. 개별 진행 상황의 오른쪽 상단에서 **사이드바 전환 버튼**을 클릭합니다.
    3. 오른쪽 사이드바에서 **정보**를 클릭합니다.
    4. **동작 목록** 아래에서 **새 동작 추가**를 클릭하고 새 작업을 입력한 다음 키보드의 Enter 키를 눌러 저장합니다.
    5. 작업 아래의 **내일 09:00**을 클릭해 작업 마감 시간을 조정합니다.

    ## 작업 완료하기

    1. 습관 목록 보기에서 습관의 개별 진행 상황을 엽니다.
       1. **그리드**에서는 습관을 한 번 클릭합니다.
       2. **목록**에서는 습관을 두 번 클릭합니다.
    2. 개별 진행 상황의 오른쪽 상단에서 **사이드바 전환 버튼**을 클릭합니다.
    3. 오른쪽 사이드바에서 **정보**를 클릭합니다.
    4. **동작 목록** 아래에서 작업 앞의 〇를 클릭해 완료로 표시합니다.

    ## 작업 삭제하기

    1. 습관 목록 보기에서 습관의 개별 진행 상황을 엽니다.
       1. **그리드**에서는 습관을 한 번 클릭합니다.
       2. **목록**에서는 습관을 두 번 클릭합니다.
    2. 개별 진행 상황의 오른쪽 상단에서 **사이드바 전환 버튼**을 클릭합니다.
    3. 오른쪽 사이드바에서 **정보**를 클릭합니다.
    4. **동작 목록** 아래에서 작업 오른쪽의 •••를 클릭한 다음 **동작 삭제**를 선택합니다.
