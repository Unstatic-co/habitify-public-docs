이 문서는 Habitify 앱에 좋은 습관을 추가하고 추적하는 방법을 안내하는 짧은 가이드입니다.

<Tabs>
  <Tab title=" iOS">
    ## 좋은 습관 추가하기

    <iframe src="https://drive.google.com/file/d/1Sm2g8KAFHdm67Je7YV6KH6qSpUps2tDN/preview" width="640" height="360" />

    1. Habitify iOS 앱에서 저널 탭으로 이동합니다.
    2. 오른쪽 하단의 + 버튼을 탭한 다음 **좋은 습관 만들기**를 선택합니다.
    3. 미리 정의된 습관 템플릿을 선택하거나<br />**맞춤 습관**을 탭하여 처음부터 새 습관을 만듭니다.
    4. 새 습관의 **반복**, **목표**, **알림**을 설정합니다.
    5. 모든 설정을 마쳤으면 오른쪽 상단의 ✓ 버튼을 탭하여 새 습관을 목록에 저장하고 추적을 시작합니다.

    ## 좋은 습관의 진행 상황 추적하기

    **저널**의 **일** 보기에서 다음과 같은 방법으로 습관의 진행 상황을 기록할 수 있습니다.

    - 오른쪽으로 쓸어 넘기고 **완료**를 선택하여 습관을 완료로 표시하거나, **기록**을 선택하여 습관의 진행 값을 기록합니다.
    - 왼쪽으로 쓸어 넘기고 **건너뛰기**를 선택하여 오늘을 쉬는 날로 표시하거나, **미달성으로 표시**를 선택하여 실수한 날로 표시합니다.

    또는 **주** 보기에서 다음과 같이 할 수 있습니다.

    - 셀이나 진행 상황 띠를 탭하여 습관의 진행 상황에 +1을 더하거나 값을 기록합니다.
    - 날짜를 길게 누른 다음 **건너뛰기** 또는 **미달성으로 표시**를 선택하여 해당 상태로 표시합니다.
  </Tab>
  <Tab title="🤖 Android">
    ## 새 좋은 습관 추가하기

    <iframe src="https://drive.google.com/file/d/1eq5cs-OzScF595HEu2RXYL_z81mkbO5h/preview" width="640" height="360" />

    1. Habitify Android 앱에서 일지 탭으로 이동합니다.
    2. 오른쪽 하단 근처의 + 버튼을 탭한 다음 **새로운 습관 생성**을 선택합니다.
    3. 미리 정의된 습관 템플릿을 선택하거나<br />**직접 만들기**를 탭하여 처음부터 새 습관을 만듭니다.
    4. 새 습관의 **반복**을 설정하고 **목표**를 지정한 다음 **미리 알림**을 추가합니다.<br />각 항목을 변경한 후에는 ←를 탭하여 변경 사항을 저장하고 이전 화면으로 돌아가세요.
    5. 모든 설정을 마쳤으면 저장 버튼을 탭하여 새 습관을 목록에 추가합니다.

    ## 좋은 습관의 진행 상황 추적하기

    **일지**의 **일** 보기에서 다음과 같은 방법으로 습관의 진행 상황을 기록할 수 있습니다.

    - 오른쪽으로 쓸어 넘기고 **완료**를 선택하여 습관을 완료로 표시하거나, **기록 값**을 선택하여 습관의 진행 값을 기록합니다.
    - 왼쪽으로 쓸어 넘기고 **건너뛰기**를 선택하여 오늘을 쉬는 날로 표시하거나, **미달성**을 선택하여 실수한 날로 표시합니다.

    또는 **주** 보기에서 다음과 같이 할 수 있습니다.

    - 셀이나 진행 상황 띠를 탭하여 습관의 진행 상황에 +1을 더하거나 값을 기록합니다.
    - 날짜를 길게 누른 다음 **건너뛰기** 또는 **미달성**을 선택하여 해당 상태로 표시합니다.

  <Tab title="🖥️ 웹사이트 및 데스크톱">
    ## 좋은 습관 추가하기

    <iframe src="https://drive.google.com/file/d/1W4NzQD2KMWiJ-o1xODD0iIZVpXDP5Cok/preview" width="640" height="360" />

    1. 왼쪽 탐색 막대에서 **모든 습관** 탭으로 이동합니다.
    2. 하단 작업 표시줄로 이동하여 **\+ 습관 추가**를 클릭한 다음 **좋은 습관 만들기**를 선택합니다.
    3. 이름 입력란을 클릭하고 미리 정의된 습관 템플릿 중 하나를 선택합니다.<br />또는 직접 습관 이름을 입력하여 처음부터 시작합니다.
    4. **반복**에서 습관 일정을 설정하고 **목표**를 지정한 다음 새 습관에 **미리 알림**을 추가합니다.
    5. 모든 설정을 마쳤으면 오른쪽 하단의 **저장** 버튼을 클릭하여 새 습관을 추적 목록에 저장합니다.

    ## 좋은 습관의 진행 상황 추적하기

    **그리드** 레이아웃에서는 아무 셀이나 마우스 오른쪽 버튼으로 클릭하고 작업을 선택하여 습관을 완료, 건너뜀 또는 실패로 표시합니다. 여러 셀을 선택하여 한 번에 체크인할 수도 있습니다.

    **목록** 레이아웃에서는 습관을 마우스 오른쪽 버튼으로 클릭하거나 습관 위에 마우스 포인터를 올린 뒤 끝부분 근처의 점 3개 메뉴 버튼을 클릭하고, 작업을 선택하여 습관을 완료, 건너뜀 또는 실패로 표시합니다.
  </Tab>
