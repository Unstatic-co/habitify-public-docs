---
title: "Habitify MCP"
---

Habitify MCP(Model Context Protocol)는 Habitify 계정을 ChatGPT, Claude 같은 AI 비서에 직접 연결합니다.

연결하고 나면 습관에 관해 단순히 대화하는 데 그치지 않고, 원하는 AI 비서와 대화하면서 자연어로 습관을 실제로 관리할 수 있습니다.

## Habitify MCP 연결하기

### Claude에 연결하기

1. Claude를 열고 **맞춤 설정**으로 이동합니다.
2. **커넥터**를 선택합니다.
3. **추가**를 클릭합니다.
4. _사용자 지정 커넥터 추가_에서 다음과 같이 설정합니다.
   1. **이름**: Habitify
   2. **MCP 서버 URL**: `https://mcp.habitify.me/mcp`
5. 안내에 따라 Habitify에 로그인하고 접근을 승인합니다.

승인이 완료되면 방금 추가한 Habitify 커넥터의 상세 설정을 확인할 수 있습니다.

새 채팅에서 + 버튼 → 커넥터 → Habitify를 켠 다음, Claude에서 바로 Habitify의 습관과 상호 작용해 보세요.

### ChatGPT에 연결하기

1. ChatGPT 인터페이스에서 **플러그인**으로 이동합니다.
2. **Habitify**를 검색합니다.
3. +를 클릭하여 연결을 시작합니다.
4. Habitify 웹사이트로 이동하면 Habitify 계정에 로그인한 다음, 승인 단계에서 **연결**을 클릭합니다.

승인이 완료되면 **채팅 시작**을 클릭하여 ChatGPT에서 바로 Habitify의 습관과 상호 작용할 수 있습니다.

### 다른 도구에 연결하기

Habitify를 새로운 도구에 연결할 때는 일반적으로 **서버 URL** 또는 **연결 링크**를 입력하라는 안내가 표시됩니다.

- **연결 URL:** `https://mcp.habitify.me/mcp`
- **연결 유형:** Streamable HTTP

<Warning>
  **Habitify MCP는 Streamable HTTP만 지원합니다.** SSE(Server-Sent Events)는 지원하지 않습니다. 도구가 SSE 연결만 지원하면, 해당 도구의 사용 가능한 연결 목록에 Habitify가 표시되어 있어도 Habitify MCP에 연결할 수 없습니다.
</Warning>

앱마다 화면이 조금씩 달라 정확한 버튼은 다를 수 있지만, 일반적인 과정은 같습니다.

1. 앱 설정에서 "커넥터", "서버" 또는 "확장 프로그램"이라는 섹션을 찾습니다.
2. 새로운 사용자 지정 서버를 추가하는 옵션을 선택합니다.
3. 다음 정보를 입력합니다.
   - **이름:** `Habitify`
   - **URL:** 위에 제공된 링크(`https://mcp.habitify.me/mcp`)를 붙여 넣습니다.
4. 서버를 추가하면 도구에서 접근 승인을 위해 Habitify 계정에 로그인하라는 안내가 표시될 수 있습니다.

## Habitify MCP로 습관에 할 수 있는 일

연결이 완료되면 AI 비서에게 자연어로 요청하는 것만으로 Habitify 계정에서 실제 작업을 수행할 수 있습니다.

- **목록 확인:** "오늘의 습관을 보여 줘" 또는 특정 날짜의 습관을 보여 달라고 요청하여 아직 해야 할 일을 확인할 수 있습니다.

- **기록 추가:** "아침 달리기를 완료로 표시해 줘"라고 요청하거나 수치형 목표에 특정 값을 추가할 수 있습니다.
- **상태 업데이트:** 습관 상태를 완료됨, 건너뜀 또는 미달성으로 변경해 달라고 요청할 수 있습니다.

- **진행 상황 지우기:** 특정 날짜에 기록된 습관 진행 상황을 지워 0 또는 "시작하지 않음"으로 재설정해 달라고 요청할 수 있습니다. 날짜를 지정하지 않으면 오늘이 기본값으로 사용됩니다.

## 문제 해결

<Accordion title="**AI에 오래된 습관이나 다른 계정의 습관이 표시되는 이유는 무엇인가요?**">
  Habitify MCP가 삭제된 습관을 가져오는 경우, 연결을 해제한 다음 다시 연결하여 데이터를 새로 고쳐 보세요.

  Habitify MCP가 사용자의 다른 계정 데이터를 가져오는 경우, Habitify 앱에 로그인한 계정과 연결 승인에 사용한 브라우저에 로그인한 계정을 비교해 보세요. 두 계정이 동일한지 확인합니다.

  문제가 계속되면 팀에 문의하여 추가 지원을 받으세요.
</Accordion>

<Accordion title="**Habitify MCP에서 앱에 있는 습관을 모두 가져오지 못하는 이유는 무엇인가요?**">
  Habitify MCP는 한 번에 최대 50개의 습관 목록을 가져올 수 있습니다.

  습관이 50개 미만인데도 도구에서 모두 가져오지 못한다면, 연결을 해제한 후 다시 연결하여 새로 고쳐 보세요.

  문제가 계속되면 팀에 문의하여 추가 지원을 받으세요.
</Accordion>

<Accordion title="**Claude에 '연결' 대신 '구성'이 표시됩니다. 어떻게 해야 하나요?**">
  Claude의 커넥터 설정에서 Habitify 메뉴를 열고 연결을 해제합니다. 그런 다음 연결을 찾아 Habitify 로그인 및 승인 절차를 완료합니다. 메뉴 레이블이 다르다면 현재 Claude 설정 안내서를 따르세요.

  연결을 계속 사용할 수 없다면 커넥터 화면을 캡처한 후 팀에 문의하여 추가 지원을 받으세요.
</Accordion>

## 자주 묻는 질문

<Accordion title="**유료 플랜이 필요한가요, 아니면 체험 기간에도 연결을 테스트할 수 있나요?**">
  Habitify MCP는 모든 사용자가 무료로 이용할 수 있는 기능이므로 유료 플랜 없이도 사용할 수 있습니다.

  다만 REST API를 고급 방식으로 사용하려면 API 사용을 위한 Pro 구독이 필요할 수 있습니다.
</Accordion>

<Accordion title="**전체 기록 이력과 나중에 수정한 진행 기록 및 메모 변경 내역을 가져올 수 있나요?**">
  Habitify는 아직 습관의 전체 기록 이력 가져오기를 지원하지 않지만, 특정 날짜의 진행 상황은 가져올 수 있습니다.

  값을 기록한 후 변경하면 마지막 변경 내용만 저장되므로 수정 이력에서 가져올 데이터가 없습니다. 메모의 변경 내역도 마찬가지입니다.
</Accordion>

<Accordion title="**currentStreak에는 요청한 과거 날짜의 연속 기록이 표시되나요?**">
  currentStreak에는 오늘까지의 연속 기록만 표시됩니다.

  과거의 특정 날짜까지 이어진 연속 기록을 가져오려면 "_2026년 10월 10일에 명상하기의 연속 기록은 며칠이었어?_"와 같은 프롬프트를 작성하세요.
</Accordion>

<Accordion title="**Habitify MCP가 예약된 검토를 실행하거나 백그라운드에서 습관을 업데이트할 수 있나요?**">
  Habitify MCP는 아직 자동화 워크플로에서 작동하는 기능을 지원하지 않습니다. 실행하려면 여전히 사용자의 입력이나 상호 작용이 필요합니다.
</Accordion>
