---
title: "Команды"
---

Habitify поддерживает интеграцию с приложением Apple «Команды», позволяя отмечать привычки и просматривать прогресс, не открывая сам Habitify.

После настройки команда может записывать прогресс, менять статус привычки или проверять текущее состояние. Запустить её можно любым удобным способом: касанием на экране «Домой», автоматизацией или даже голосом через Siri.

В «Командах» доступно семь действий Habitify:

- **Добавить заметку**: добавить заметку к привычке.
- **Добавить запись**: записать значение прогресса привычки.
- **Записать настроение**: записать своё настроение.
- **Удалить записи**: удалить записанный прогресс привычки за определённую дату.
- **Пропустить/не выполнить привычку**: изменить статус привычки за текущий день.
- **Запустить таймер**: начать сеанс таймера для привычки с целью по времени.
- **Открыть Журнал**: быстро открыть список привычек.

Для любого из этих действий можно оставить поле привычки пустым, чтобы сделать команду более гибкой: при каждом запуске она предложит выбрать привычку, а не будет привязана к одной заранее.

## Настройки команд Habitify

### **Добавить заметку**

![Команда «Добавить заметку» на iOS](/images/AddNote-Shortcut-iOS.png "Команда «Добавить заметку» на iOS")

Эта команда помогает добавить заметку к привычке.

- В приложении «Команды» найдите Habitify и выберите команду **Добавить заметку**.
- В настройках команды нужно выбрать определённую привычку.
- Если оставить поле пустым, при каждом запуске команда будет предлагать выбрать привычку, к которой нужно добавить заметку.
- Для даты можно по умолчанию выбрать «Текущая дата» или «Спрашивать каждый раз» при запуске.

### **Записать привычку**

![Команда «Записать привычку» на iOS](/images/LogHabit-Shortcut-iOS.png "Команда «Записать привычку» на iOS")

Эта команда предназначена для записи значения прогресса.

- В приложении «Команды» найдите Habitify и выберите команду **Записать привычку**.

- В настройках команды выберите определённую привычку и не забудьте выбрать единицу «повтор».
- При каждом запуске команды появляется окно, в котором можно ввести значение.
- Для даты можно по умолчанию выбрать «Текущая дата» или «Спрашивать каждый раз» при запуске.

### **Записать настроение**

![Команда «Записать настроение» на iOS](/images/LogMood-Shortcut-iOS.png "Команда «Записать настроение» на iOS")

Эта команда позволяет удобно записывать настроение.

- В приложении «Команды» найдите Habitify и выберите команду **Записать настроение**.
- В настройках команды выберите настроение, которое будет записываться автоматически.
- Или установите «Спрашивать каждый раз»: при каждом запуске команда покажет список настроений для выбора.

### **Удалить записи**

![Команда «Удалить запись» на iOS](/images/RemoveLog-Shortcut-iOS.png "Команда «Удалить запись» на iOS")

Эта команда удаляет записи прогресса привычки за определённую дату. Обратите внимание: один запуск удалит записи и сбросит прогресс до 0.

- В приложении «Команды» найдите Habitify и выберите команду **Удалить записи**.
- В настройках команды выберите привычку, для которой хотите использовать команду. Поле можно оставить пустым, и тогда команда будет спрашивать привычку при каждом запуске.
- Выберите **Дату**, за которую нужно удалить записи. Также можно установить «Спрашивать каждый раз».

### **Пропустить/не выполнить привычку**

![Команда «Пропустить или не выполнить привычку» на iOS](/images/SkipFailHabit-Shortcut-iOS.png "Команда «Пропустить или не выполнить привычку» на iOS")

Эта команда позволяет изменить статус привычки за текущий день.

- В приложении _«Команды»_ найдите Habitify и выберите команду **Пропустить/не выполнить привычку**.
- В настройках команды выберите привычку, для которой хотите использовать команду. Поле можно оставить пустым, и тогда команда будет спрашивать привычку при каждом запуске.
- Выберите **Действие**, которое должна выполнить команда: пропустить, не выполнить или успешно выполнить. Для действия можно установить «Спрашивать каждый раз».

### **Запустить таймер**

![Команда «Запустить таймер» на iOS](/images/StartTimer-Shortcut-iOS.png "Команда «Запустить таймер» на iOS")

Эта команда позволяет удобно запустить таймер для привычки. Она доступна для привычек, цель которых измеряется в минутах или часах.

- В приложении «Команды» найдите Habitify и выберите команду **Запустить таймер**.
- В настройках команды выберите привычку, для которой хотите запустить таймер. Поле можно оставить пустым, и тогда команда будет спрашивать привычку при каждом запуске.

Для работы таймера всё равно необходимо открыть приложение. Поэтому выполнение этой команды откроет Habitify и перейдёт к настройке сеанса таймера.

### **Открыть Журнал**

![Команда «Открыть Журнал» на iOS](/images/ViewJournal-Shortcut-iOS.png "Команда «Открыть Журнал» на iOS")

Эта команда позволяет быстро открыть список привычек.

- В приложении «Команды» найдите Habitify и выберите команду **Открыть Журнал**.
- В настройках выберите список, который должна открывать команда: все привычки, время дня — утро, день или вечер — либо область. Поле можно оставить пустым или выбрать «Спрашивать каждый раз», и тогда команда будет спрашивать при каждом запуске.

## Команды Habitify и Siri

Habitify не поддерживает прямую голосовую отметку привычек. Однако благодаря интеграции с командами iOS можно воспользоваться обходным способом.

- Создайте команды с действиями Habitify.
- Дайте им простые названия, которые легко запомнить.
- Затем скажите «Привет, Siri!» и произнесите название команды.

После выполнения команды Siri сообщит результат.

Если устройство заблокировано и команда открывает Habitify, Siri попросит разблокировать устройство, прежде чем продолжить.

<Note>
  Начиная с iOS 27 Habitify может напрямую работать с ИИ Siri без настройки стандартных команд iOS.

  Чтобы проверить, поддерживают ли ваши устройства Apple Intelligence и ИИ Siri, ознакомьтесь с руководством Apple: [**Как получить ИИ Siri**](https://support.apple.com/en-us/127893?st_source=ai_mode)
</Note>

## Команды Habitify и автоматизации iOS

Помимо обычных кнопок для ручного запуска команд, основная сила приложения «Команды» заключается в функции **Автоматизации**. Автоматизация — это особый вид команды, который запускается **автоматически** в фоновом режиме при наступлении определённого события-триггера на iPhone или Apple Watch.

### **Логика работы**

Главное — понимать, что каждая автоматизация состоит из двух частей:

- **Триггер («Когда»):** событие, которое отслеживает операционная система iPhone, то есть iOS. **Эти триггеры встроены Apple.**<br />_Примеры: «Когда будильник “Пробуждение” остановлен», «Когда я прихожу в спортзал» или «Когда тренировка на Apple Watch завершается»._

- **Действие («Сделать»):** то, что Habitify должен _выполнить_ при срабатывании триггера. **Это команды Habitify**, например «Отметиться» или «Записать прогресс», доступные в приложении «Команды».

Ваша задача — соединить эти две части.

### **Как настроить**

<Steps>
  <Step title="Создайте команды Habitify">
    Настройка будет проще, если команды Habitify уже готовы.
  </Step>
  <Step title="Создайте автоматизацию">
    1. Откройте приложение **Команды** на iPhone.
    2. Нажмите вкладку **Автоматизация** в центре нижней части экрана.
    3. Нажмите значок **+**, чтобы создать автоматизацию.
    4. Сначала вам предложат **Выбрать триггер**, например «Будильник», «Прибытие» или «Приложение».
    5. После настройки триггера нужно **Добавить действие**. Найдите Habitify и выберите одно из действий или созданных вами команд.
  </Step>
</Steps>

### **Пример**

**Цель:** после завершения тренировки на Apple Watch добавить к привычке «Активные калории» в Habitify заметку «Тренировка завершена!».

<Steps>
  <Step title="Создайте команду «Добавить заметку»">
    Добавьте новую команду Habitify «Добавить заметку»:

    - в поле **Привычка** выберите привычку **Активные калории**;
    - в поле **Содержимое** напишите «Тренировка завершена!» или оставьте поле пустым, чтобы каждый раз вводить свой текст;
    - для поля **Дата** по умолчанию установите **Текущая дата**.

    Дайте команде название, чтобы позднее её было легко найти.
  </Step>
  <Step title="Выберите триггер Apple">
    1. На экране **Новая автоматизация** прокрутите вниз и нажмите **Тренировка Apple Watch**.
    2. Выберите **Завершается**. Можно также выбрать определённый тип тренировки, например «Бег».
    3. Убедитесь, что выбрано **Запускать немедленно**.
    4. Нажмите **Далее**.
  </Step>
  <Step title="Выберите действие Habitify">
    1. Нажмите **Добавить действие**.
    2. Найдите и выберите команду, созданную на первом шаге.
  </Step>
</Steps>

**Несколько идей для автоматизаций:**

- **Триггер:** `Прибытие` по адресу `[Адрес вашего спортзала]` → **Действие:** `Запустить таймер` для привычки «Тренировка».
- **Триггер:** `Приложение` \> `Kindle` \> `Открыто` → **Действие:** `Запустить таймер` для привычки «Читать книгу».
- **Триггер:** `Bluetooth` \> `Подключается к [Название вашего автомобиля]` → **Действие:** `Записать прогресс` — 1 раз — для привычки «Поездка на работу».

Надеемся, теперь принцип понятен и вы сможете создавать эффективные автоматизации!
