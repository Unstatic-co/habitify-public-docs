Habitify Team позволяет централизованно приобрести и распределить доступ Premium для команды или организации.

Вместо того чтобы каждому участнику платить отдельно, один человек оплачивает лицензии и управляет ими, а затем предоставляет доступ остальным с помощью общего кода команды.

## Покупка командной лицензии

1. Откройте специальную страницу командных подписок: <br />[https://habitify.me/habitify-for-team](https://habitify.me/habitify-for-team)
2. На целевой странице нажмите кнопку **Улучшить тариф команды**.
3. На экране настройки покупки необходимо:
   ![Покупка командной лицензии](/images/Team-Purchase.png "Покупка командной лицензии")
   1. Выбрать срок лицензии: **1 месяц** или **12 месяцев**.
   2. Указать **количество пользователей** (мест), то есть число участников команды.<br />Минимальное количество — 30.
   3. Нажать кнопку **Купить за [общая стоимость]**, чтобы продолжить.
4. Еще раз проверьте сведения о заказе и нажмите кнопку **Купить**.
5. В _защищенном окне оплаты_ укажите:
   - **Адрес электронной почты:** это важно — на него мы отправим платежный счет и ссылку для настройки кода лицензии.
   - **Страну:** она необходима для выставления счета и соблюдения правил.
   - **Способ оплаты:** выберите **PayPal** либо дебетовую/кредитную **карту**.

После оплаты вы получите письмо с подтверждением заказа. В нем будет важная ссылка для следующего шага. Откройте письмо, перейдите по ссылке и настройте код лицензии.

## Настройка кода командной лицензии

После покупки создайте уникальный код, с помощью которого участники команды смогут активировать Habitify PRO в своих учетных записях.

Найдите во входящих письмо с темой **«Настройте лицензию Habitify»** и нажмите ссылку внутри.

Откроется страница настройки, где нужно указать:

- **Название команды** и **Уникальный код** — эти данные будут использованы для создания кода доступа.
- **Описание** (необязательно).
- **Логотип команды** (необязательно).

Когда все будет готово, нажмите кнопку **Сохранить**.

![Настройка кода команды](/images/Team-CodeSetup.png "Настройка кода команды")

После перенаправления появится итоговый экран с подтверждением создания кода. На этой странице также будет **ссылка для общего доступа**.

Теперь эту **ссылку** можно отправить участникам команды. Открыв ее, они увидят страницу с названием и логотипом команды, а также уникальным кодом для активации доступа Premium.

## Активация с помощью кода командной лицензии

Заранее подготовьте следующее:

1. **Учетную запись Habitify:** приложение Habitify должно быть установлено, а вход в личную учетную запись — выполнен. Если учетной записи еще нет, сначала создайте ее.
2. **Код лицензии:** понадобится уникальный код, предоставленный администратором команды. Если у вас его нет, обратитесь непосредственно к руководителю или администратору команды.

## **Как работает командная лицензия**

Основные правила командной лицензии:

- **Без срока действия:** срок действия кода активации не ограничен. Его можно приобрести сейчас и раздать, когда команда будет готова.
- **Одна активация на учетную запись:** каждая учетная запись Habitify может активировать конкретный код только один раз.
- **Срок начинается в момент активации:** период доступа PRO отсчитывается не со дня покупки кода, а с момента, когда участник команды активирует его в приложении.

**Например,** вы приобрели код месячной командной лицензии **1 июля 2026 года**. Если участник команды подождет и активирует Premium с помощью этого кода **7 июля 2026 года**, полный доступ PRO будет действовать до **7 августа 2026 года**.

**Habitify Team представляет собой лицензию на ограниченный срок, а не подписку, поэтому она не продлевается автоматически.** После окончания активированного периода учетная запись участника команды автоматически вернется на бесплатный тариф.

Чтобы восстановить доступ PRO, администратору потребуется приобрести новый код активации и передать его участнику команды. Тот сможет активировать код и начать новый период доступа PRO.
