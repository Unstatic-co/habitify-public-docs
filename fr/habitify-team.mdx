---
title: "Habitify pour les équipes"
---

Habitify pour les équipes facilite l’achat et la distribution en volume d’accès Premium au sein de votre équipe ou de votre organisation.

Au lieu que chaque membre paie individuellement, une seule personne gère l’achat et les licences, puis distribue les accès à tous au moyen d’un code d’équipe partagé.

## Acheter une licence d’équipe

1. Accédez à notre page web dédiée aux abonnements pour les équipes : <br />[https://habitify.me/habitify-for-team](https://habitify.me/habitify-for-team)
2. Cliquez sur le bouton **Mettre votre équipe à niveau** sur la page d’accueil.
3. Sur l’écran de configuration de l’achat, vous devrez :
   ![Achat pour une équipe](/images/Team-Purchase.png "Achat pour une équipe")
   1. Choisir le modèle de licence : **1 mois** ou **12 mois**.
   2. Saisir le **nombre d’utilisateurs** (places), c’est-à-dire le nombre de membres de votre équipe.<br />Le minimum requis est de 30.
   3. Toucher le bouton **Acheter [prix total]** pour continuer.
4. Vérifiez à nouveau les détails de votre commande, puis touchez le bouton **Acheter**.
5. Dans la _fenêtre de paiement sécurisé_, vous devrez fournir :
   - **Votre adresse e-mail :** elle est essentielle, car nous y enverrons votre facture ainsi que le lien permettant de configurer votre code de licence.
   - **Votre pays :** à des fins de facturation et pour respecter les conditions applicables.
   - **Votre moyen de paiement :** choisissez de payer via **PayPal** ou par **carte** de débit/crédit.

Une fois votre paiement effectué, vous recevrez un e-mail confirmant votre commande. Cet e-mail contient le lien important pour passer à l’étape suivante. Ouvrez-le afin d’obtenir le lien et de configurer votre code de licence.

## Configurer le code de licence d’équipe

Après l’achat, vous devez créer le code unique que les membres de votre équipe utiliseront pour activer Habitify PRO sur leur compte.

Recherchez dans votre boîte de réception un e-mail ayant pour objet **« Configurez votre licence Habitify »**, puis cliquez sur le lien qu’il contient.

Le lien vous mènera à une page de configuration. Vous devrez y renseigner :

- **Nom de l’équipe** et **Code unique** : ces informations serviront à générer le code d’accès
- **Description** (facultatif)
- **Logo de l’équipe** (facultatif)

Une fois tous les éléments configurés, touchez le bouton **Enregistrer**.

![Configuration du code d’équipe](/images/Team-CodeSetup.png "Configuration du code d’équipe")

Vous serez redirigé vers un écran final confirmant la création de votre code. Cette page fournira également un **lien de partage**.

Vous pouvez désormais envoyer directement le **lien de partage** aux membres de votre équipe. Lorsqu’ils l’ouvriront, ils accéderont à une page affichant le nom et le logo de votre équipe, ainsi que le code unique dont ils ont besoin pour activer leur accès Premium.

## Activer l’accès avec un code de licence d’équipe

Assurez-vous d’avoir les éléments suivants à disposition :

1. **Un compte Habitify :** l’application Habitify doit être installée et vous devez être connecté à votre compte Habitify personnel. Si vous n’avez pas encore créé de compte, commencez par le faire.
2. **Votre code de licence :** vous aurez besoin du code de licence unique fourni par l’administrateur de votre équipe. Si vous ne l’avez pas, contactez directement votre responsable ou l’administrateur de l’équipe pour l’obtenir.

<Tabs>
  <Tab title="iOS">
    1. Ouvrez l’application Habitify et accédez à l’onglet **Réglages**.<br />_Vous devrez peut-être d’abord accéder à l’onglet Progression pour que l’onglet Réglages s’affiche._
    2. Dans _Réglages_, recherchez et touchez **Paiement et facturation**.
    3. Dans _Paiement_, touchez **Saisir un code**.
    4. Saisissez votre code et touchez **Utiliser**.

    Si l’onglet Passer à la version supérieure n’apparaît plus dans la barre de navigation inférieure, cela signifie que vous avez activé l’accès PRO avec succès.
  </Tab>
  <Tab title="Android">

    2. Dans _Paramètres_, accédez à la section **Paiement**, puis touchez **Tapez votre code**.
    3. Saisissez votre code et touchez **Enregistrer**

    Si l’onglet Mise à niveau n’apparaît plus dans la barre de navigation inférieure, cela signifie que vous avez activé l’accès PRO avec succès.

## **Fonctionnement de la licence d’équipe**

Voici les principales règles d’une licence d’équipe :

- **Aucune date d’expiration :** votre code d’activation n’a pas de date d’expiration. Vous pouvez l’acheter dès maintenant et le distribuer lorsque votre équipe sera prête.
- **Une seule utilisation par compte :** chaque compte Habitify ne peut utiliser un code donné qu’une seule fois.
- **La durée commence lors de l’utilisation :** la période d’accès PRO ne commence pas le jour où vous achetez le code. Elle débute uniquement au moment où le membre de l’équipe utilise effectivement le code dans son application.

**Par exemple,** supposons que vous achetiez un code de licence d’équipe d’un mois le **1er juillet 2026**. Si un membre de l’équipe attend le **7 juillet 2026** pour utiliser ce code et activer son accès Premium, il bénéficiera d’un accès PRO complet jusqu’au **7 août 2026**.

**Habitify pour les équipes fonctionne comme une licence d’accès à durée limitée, et non comme un abonnement : elle ne se renouvelle donc pas automatiquement.** Lorsque l’accès activé arrive à son terme, le compte du membre de l’équipe repasse automatiquement à la version gratuite.

Pour rétablir son accès PRO, l’administrateur devra acheter un nouveau code d’activation et le transmettre au membre de l’équipe, afin que celui-ci puisse l’utiliser et commencer un nouveau cycle d’accès PRO.
