Habitify for Team facilite l’achat et la distribution en volume de l’accès Premium à une équipe ou une organisation.

Au lieu que chaque membre paie individuellement, une personne achète et gère les licences, puis distribue l’accès à tous avec un code d’équipe partagé.

## Acheter une licence d’équipe

1. Ouvrez la page dédiée :<br />[https://habitify.me/habitify-for-team](https://habitify.me/habitify-for-team)
2. Cliquez sur **Mettre votre équipe à niveau**.
3. Sur l’écran de configuration de l’achat :
   ![Team Purchase](/images/Team-Purchase.png "Team Purchase")
   1. Choisissez une licence de **1 mois** ou **12 mois**.
   2. Saisissez le **nombre d’utilisateurs**, ou sièges, correspondant aux membres de l’équipe.<br />Le minimum est de 30.
   3. Touchez **Acheter [prix total]** pour continuer.
4. Vérifiez les détails de la commande, puis touchez **Acheter**.
5. Dans la _fenêtre de paiement sécurisé_, saisissez :
   - **votre adresse e-mail**, utilisée pour envoyer la facture et le lien de configuration du code de licence ;
   - **votre pays**, pour la facturation et les règles applicables ;
   - **votre moyen de paiement**, PayPal ou carte bancaire.

Une fois le paiement terminé, vous recevez un e-mail de confirmation contenant le lien nécessaire pour configurer le code de licence.

## Configurer le code de licence d’équipe

Après l’achat, créez le code unique que les membres utiliseront pour activer Habitify PRO sur leur compte.

Recherchez l’e-mail intitulé **« Configure Your Habitify License »**, puis ouvrez le lien qu’il contient.

Sur la page de configuration, renseignez :

- le **nom de l’équipe** et le **code unique**, utilisés pour générer le code d’accès ;
- une **description**, facultative ;
- le **logo de l’équipe**, facultatif.

Touchez ensuite **Enregistrer**.

![Team Code Setup](/images/Team-CodeSetup.png "Team Code Setup")

Un écran confirme la création du code et fournit un **lien de partage**.

Envoyez ce lien aux membres. Lorsqu’ils l’ouvrent, une page affiche le nom, le logo et le code unique de l’équipe nécessaires pour activer Premium.

## Activer l’accès avec un code d’équipe

Préparez les éléments suivants :

1. **Un compte Habitify :** l’application doit être installée et vous devez être connecté à votre compte personnel. Créez-en un si nécessaire.
2. **Le code de licence :** demandez à votre responsable ou administrateur le code unique de l’équipe.

<Tabs>
  <Tab title="iOS">
    1. Ouvrez Habitify et accédez à **Paramètres**.<br />_Vous devrez peut-être d’abord ouvrir Progression pour afficher l’onglet Paramètres._
    2. Touchez **Paiement et facturation**.
    3. Dans _Paiement_, touchez **Saisir un code**.
    4. Saisissez le code et touchez **Utiliser**.

    Si l’onglet de mise à niveau n’apparaît plus dans la barre inférieure, l’accès PRO a été activé.
  </Tab>
  <Tab title="Android">
    1. Ouvrez Habitify et accédez à **Paramètres**.
    2. Dans la section Paiement, touchez **Saisir un code**.
    3. Saisissez le code et touchez **Enregistrer**.

    Si l’onglet de mise à niveau n’apparaît plus dans la barre inférieure, l’accès PRO a été activé.
  </Tab>
</Tabs>

## **Fonctionnement de la licence d’équipe**

- **Aucune date d’expiration :** les codes d’activation n’expirent pas. Vous pouvez les acheter maintenant et les distribuer lorsque l’équipe est prête.
- **Une utilisation par compte :** chaque compte Habitify ne peut utiliser un code donné qu’une seule fois.
- **La durée commence à l’activation :** la période PRO ne démarre pas le jour de l’achat, mais au moment où le membre utilise le code dans l’application.

**Exemple :** vous achetez une licence d’équipe d’un mois le **1er juillet 2026**. Si un membre l’active le **7 juillet 2026**, il bénéficie de PRO jusqu’au **7 août 2026**.

**Habitify Team est une licence d’accès à durée limitée, pas un abonnement ; elle ne se renouvelle donc pas automatiquement.** À son expiration, le compte revient automatiquement à la version gratuite.

Pour rétablir PRO, l’administrateur doit acheter un nouveau code et le transmettre au membre, qui pourra l’utiliser pour démarrer une nouvelle période d’accès.
