title: "Mode Off"
---

La vie ne s’arrête pas pour suivre le rythme de vos habitudes. En réalité, les vacances, la maladie, les déplacements professionnels ou une période de travail intense peuvent perturber votre suivi. Le Mode Off est la manière dont Habitify gère honnêtement ces situations : au lieu d’accumuler discrètement des jours manqués et des séries interrompues pendant votre absence, vous prévenez l’application à l’avance, et elle protège votre progression pendant toute la période.

Vous définissez une **Période Off** et, dès que celle-ci commence, le Mode Off s’active automatiquement. Son activation vous apporte trois avantages :

- **Rappels désactivés** : chaque rappel d’habitude est désactivé pendant toute la durée, y compris votre notification de récapitulatif quotidien, afin que rien ne vous sollicite pendant votre repos ou votre absence.
- **Statut En vacances** : toutes vos habitudes sont automatiquement marquées comme « en vacances » chaque jour de la Période Off.
- **Protection des séries** : vos séries sont préservées au lieu d’être remises à zéro, afin qu’une pause planifiée n’annule pas des semaines ou des mois de régularité.

Vous recevrez tout de même deux notifications pendant le Mode Off : une à son démarrage et une le dernier jour, pour vous prévenir qu’il est sur le point de prendre fin.

    ## Planifier une période Off

    1. Dans l’application Habitify, accédez à **Réglages**.
    2. Sous la section **Données**, touchez **Mode Off** pour y accéder.
    3. Sur l’écran suivant, touchez **Planifier une nouvelle période Off**.
    4. Sur l’écran **Planifier une nouvelle période Off**, configurez les détails de votre période Off :
       1. Choisissez une icône : celle-ci apparaîtra sur les jours de votre période Off lorsque vous les consulterez ultérieurement dans la vue de progression individuelle de l’habitude.
       2. Touchez le champ de saisie **Motif**, puis saisissez le nom de la période Off.
       3. Dans **Date de début** et **Date de fin**, sélectionnez les dates qui définiront la durée de votre période Off. <br />La Date de début doit être fixée à demain ou à une date ultérieure, et la durée doit être d’au moins 2 jours.<br />_Par exemple, si la Date de début est le 1er septembre, la Date de fin doit être le 2 septembre ou une date ultérieure._
    5. Enfin, touchez **Enregistrer** dans le coin supérieur droit pour planifier votre période Off.

    ## Supprimer une période Off

    Si vous avez planifié une Période Off dont vous n’avez plus besoin, par exemple parce que vos projets ont changé avant même son début, vous pouvez la supprimer :

    - Dans **Réglages**, accédez à **Mode Off**.
    - Balayez la Période Off vers la gauche.
    - Touchez **Supprimer.**

    ## Mettre fin plus tôt à une période Off

    Si vos projets changent et que vous souhaitez reprendre avant la date de fin prévue, vous pouvez désactiver le Mode Off au cours d’une Période Off active.

    - Dans **Réglages**, accédez à **Mode Off**.
    - Balayez la **Période Off** vers la gauche, puis touchez **Arrêter**.
    - Dans **Confirmation**, touchez **OK**.

    Vous pourrez ensuite reprendre le suivi de vos habitudes à compter de la date actuelle.

    ## Enregistrer une progression pendant une période Off

    Lorsque le Mode Off est activé, la vue Journal n’affiche pas la liste des habitudes. Cela signifie également que vous ne pouvez pas pointer ni enregistrer la progression de vos habitudes pendant cette période.

    Pour résoudre ce problème, attendez la fin de la période Off et la réapparition de la liste des habitudes dans la vue Journal. Procédez ensuite comme suit :

    - Dans **Journal**, balayez votre habitude vers la droite et choisissez **Enregistrer.**
    - Saisissez la valeur de progression et choisissez une date comprise dans la période Off.
    - Touchez **✓** pour enregistrer l’entrée.

    ## FAQ

    <Accordion title="**Comment ajouter une période Off qui a eu lieu dans le passé ?**">
      Habitify ne permet pas d’ajouter une période Off à une date passée. Vous pouvez marquer manuellement ces dates comme Ignorées, ce qui revient techniquement au même.
    </Accordion>

    <Accordion title="**Comment ajouter une période Off d’une seule journée ?**">
      Habitify ne permet pas d’ajouter une période Off qui ne dure qu’une journée. À la place, vous pouvez :

      - Marquer manuellement vos habitudes comme ignorées ce jour-là, ou
      - Accéder à **Réglages** → **Intégration** → **Automatisation** → l’activer, définir l’heure, puis régler **Marquer les habitudes non enregistrées comme** sur **Ignorée**.
    </Accordion>

    ## Planifier une période de pause

    1. Dans l’application _Habitify_, accédez à **Paramètres**.
    2. Sous la section _Données_, touchez **Mode Pause** pour y accéder.
    3. Sur l’écran _Mode Pause_, touchez **Nouveau temps de pause**.
    4. Sur l’écran _Planifier une nouvelle pause_, configurez les détails de votre période de pause :
       1. **Choisissez une icône** : celle-ci apparaîtra sur les jours de votre période de pause lorsque vous les consulterez ultérieurement dans la vue de progression individuelle de l’habitude.
       2. Touchez le champ de saisie **Raison**, puis saisissez le nom de la période de pause.
       3. Dans **Date de début** et **Date de fin**, sélectionnez les dates qui définiront la durée de votre période de pause. Cette durée doit être d’au moins 2 jours.<br />_Par exemple, si votre date de début est le 1er septembre, la date de fin doit être le 2 septembre ou une date ultérieure._
    5. Enfin, touchez le bouton « **Enregistrer** » dans le coin supérieur droit pour planifier votre période de pause.

    ## Supprimer une période de pause

    Si vous avez planifié une période de pause dont vous n’avez plus besoin, par exemple parce que vos projets ont changé avant même son début, vous pouvez la supprimer :

    - Dans **Paramètres**, ouvrez **Mode Pause**.
    - Balayez la période de pause vers la gauche, puis touchez **Supprimer**.

    - Dans **Journal**, balayez votre habitude vers la droite et touchez **Valeur enregistrée.**
    - Saisissez la valeur de progression et choisissez une date comprise dans la période de pause.
    - Touchez le bouton **Enregistrer** pour sauvegarder l’entrée.

    ## Planifier une période d’absence

    1. Dans l’application Habitify, accédez, depuis _la barre latérale gauche_, à **Préférences** → **Mode Hors Ligne.**
    2. Dans la fenêtre **Mode Hors Ligne**, cliquez, dans la barre latérale gauche, sur **\+ Planifier une nouvelle période d’absence.**
    3. Configurez les détails de votre prochaine période d’absence :
       1. **Choisissez une icône** : celle-ci apparaîtra sur les jours de votre période d’absence lorsque vous les consulterez ultérieurement dans la vue de progression individuelle de l’habitude.
       2. Cliquez sur le champ **Motif du mode Hors Ligne** et saisissez le nom de la période d’absence.
       3. Dans **Date de début** et **Date de fin**, définissez le premier et le dernier jour de votre période d’absence. La durée minimale doit être de 2 jours.
    4. Cliquez sur le bouton **Enregistrer** pour planifier votre période d’absence.

    ## Supprimer une période d’absence

    Pour supprimer une période d’absence à venir :

    - Dans **Mode Hors Ligne**, recherchez la période d’absence à supprimer,<br />puis cliquez sur le bouton rouge en forme de corbeille situé à son extrémité droite.
    - Dans **Confirmation**, cliquez sur le bouton **Supprimer la période d’absence**.

    ## Mettre fin plus tôt à une période d’absence

    Si vos projets changent et que vous souhaitez reprendre avant la date de fin prévue :

    - Dans **Mode Hors Ligne**, recherchez la période d’absence active.
    - Cliquez sur **⦰ Arrêter la période d’absence.**
    - Dans **Confirmation**, cliquez sur le bouton **Arrêter la période d’absence**.

    ## Enregistrer une progression pendant une période d’absence

    Pendant une période d’absence, votre liste d’habitudes cesse d’apparaître dans la disposition Liste, mais vous pouvez toujours voir vos habitudes dans la disposition Grille. Vous pouvez donc continuer votre suivi avec la disposition Grille pendant votre période d’absence.

    Plus précisément, pour enregistrer une valeur de progression à une date comprise dans la période d’absence :

    - Dans la disposition **Grille**, cliquez une fois sur le nom de votre habitude.
    - Dans la vue de progression individuelle, cliquez sur **⌨️** dans le coin supérieur droit.
    - Saisissez une valeur dans le champ, puis choisissez une date dans le Calendrier.
    - Cliquez sur le bouton **Ajouter un enregistrement** pour sauvegarder votre progression.
