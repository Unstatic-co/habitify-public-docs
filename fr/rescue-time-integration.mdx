title: "RescueTime"
---

RescueTime suit la manière dont vous passez réellement votre temps sur votre ordinateur : quelles apps et quels sites vous utilisez, et pendant combien de temps. En le connectant à Habitify, vous n’avez plus besoin d’enregistrer manuellement chaque jour le temps consacré à une activité comme « Travail en profondeur » ou « Programmation » ; RescueTime le sait déjà et peut transmettre directement ces données à l’habitude correspondante.

## Ajouter une habitude synchronisée avec RescueTime

<Tabs>
  <Tab title=" iOS">
    1. Depuis le **Journal**, touchez + dans le coin inférieur droit.
    2. Choisissez **Créer une bonne habitude** ou **Rompre une mauvaise habitude**.
    3. En haut de l’écran de création, passez à l’onglet **RescueTime**.
       ![RescueTime sur iOS](/images/RescueTime-iOS.png "RescueTime sur iOS")
    4. Dans la liste, choisissez le type de données que vous souhaitez suivre.
    5. À l’étape suivante, touchez **Autoriser l’accès**. Vous serez redirigé vers le site de RescueTime pour vous connecter à votre compte de service et autoriser Habitify à lire les données de RescueTime.
    6. Une fois l’autorisation accordée, vous reviendrez dans Habitify.<br />Configurez les détails de votre habitude comme d’habitude.
    7. Une fois tous les réglages terminés, touchez **✓** pour enregistrer la nouvelle habitude dans votre liste.

    Une habitude associée à RescueTime est facile à repérer après sa création : une petite icône RescueTime apparaît directement dans la vue Journal, ce qui permet de la distinguer d’un coup d’œil de vos habitudes suivies manuellement.
  </Tab>
  <Tab title="🤖 Android">
    1. Dans le **Journal**, touchez **\+** dans la barre de date, dans le coin inférieur droit de l’écran.
    2. Choisissez **Créer de nouvelles habitudes** ou **Briser la mauvaise habitude**.
    3. Parmi les onglets situés en haut de l’écran des modèles d’habitude, touchez **RescueTime**.
       ![RescueTime sur Android](/images/RescueTime-Android.png "RescueTime sur Android")
    4. Touchez une option de données dans la liste de toutes les activités et de tous les types de données qu’Habitify peut importer depuis RescueTime.
    5. Sur l’écran suivant, touchez **Autoriser l’accès**.
    6. À l’étape suivante, vous serez redirigé vers le site de RescueTime pour vous connecter et autoriser Habitify à lire les données de RescueTime.
    7. Une fois l’autorisation accordée, revenez dans Habitify et touchez le bouton **Continuer**. <br />Configurez ensuite l’habitude comme d’habitude.
    8. Une fois tous les réglages terminés, touchez le bouton **Enregistrer** dans le coin supérieur droit.

    Une habitude associée à RescueTime est facile à repérer après sa création : une petite icône RescueTime apparaît directement dans la vue Journal, ce qui permet de la distinguer d’un coup d’œil de vos habitudes suivies manuellement.
  </Tab>
</Tabs>

## Comment votre temps d’écran est catégorisé

Votre temps d’écran dans une app ou sur un site Web est catégorisé par RescueTime. Habitify lit les données et leur libellé afin de déterminer lesquelles seront synchronisées avec la progression de votre habitude dans Habitify.

Vous pouvez gérer les apps et les sites Web de chaque catégorie dans votre compte RescueTime. Découvrez comment procéder : **[Comment catégoriser vos apps et vos sites Web](https://help.rescuetime.com/article/74-changing-categories-and-productivity-scores).**

## **Remarques importantes**

Cette intégration présente certains comportements propres au système de RescueTime. Veuillez prendre connaissance des points suivants :

- **Délai de la première synchronisation :** lors de la toute première configuration de l’habitude, la première synchronisation des données prend environ **10 minutes**.
- **Synchronisation des données du jour _précédent_ :** il s’agit de la limitation la plus importante à comprendre. Le système de RescueTime finalise ses données à la fin de la journée. Par conséquent, les données RescueTime du jour 1 ne seront synchronisées avec Habitify pour le jour 1 que le jour 2.
- **Un compte RescueTime, plusieurs comptes :** vous **pouvez** connecter un même compte RescueTime à plusieurs comptes Habitify si vous le souhaitez.
