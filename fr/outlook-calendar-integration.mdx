Vos habitudes n’existent pas séparément du reste de votre journée. Elles s’inscrivent aux côtés de vos réunions, de vos rendez-vous et de tout ce qui figure dans votre calendrier.

Cette intégration synchronise directement vos habitudes Habitify avec Outlook Calendar. Vous pouvez ainsi les consulter et les gérer au même endroit que votre emploi du temps, sans avoir à passer d’une app à l’autre pour obtenir une vue d’ensemble de votre journée.

## Fonctionnement

- Une habitude sans rappel associé à une heure précise est synchronisée sous forme d’événement sur toute la journée.
- Pour une habitude avec des rappels associés à une heure précise, chaque rappel est synchronisé sous forme d’événement de l’habitude. L’heure du rappel devient l’heure de début.
- La description de votre habitude est également synchronisée en tant que description de l’événement.

**Dans Outlook Calendar, un nouveau calendrier Habitify est créé pour tous les événements d’habitudes synchronisés depuis Habitify.** Vous pouvez ainsi gérer plus facilement ces événements, puisqu’il vous suffit de modifier le calendrier Habitify pour agir sur l’ensemble des événements d’habitudes.

## Configuration

  <Tab title=" iOS">

    1. Dans l’app _Habitify_, accédez à **Réglages**.
    2. Accédez à **Intégration**, puis touchez **Outlook Calendar** pour l’ouvrir.
    3. Sur l’écran des réglages d’Outlook Calendar, touchez le bouton **Connecter**.
    4. Lors de la première connexion, vous devrez peut-être vous connecter à votre compte Outlook Calendar et accorder les autorisations demandées.
    5. Une fois la connexion correctement configurée, vous pouvez régler l’option suivante :
       1. Sous **Lors de la suppression d’un événement**_,_ choisissez le statut à appliquer lorsque vous supprimez d’Outlook Calendar un événement d’habitude synchronisé : **Marquer comme échouée** ou **Marquer comme ignorée**.
    6. Une fois tous les réglages terminés, touchez **く** dans le coin supérieur droit pour enregistrer et revenir en arrière.

    2. Accédez à **Intégration**, puis touchez **Synchroniser avec Outlook Calendar**.

    4. Lors de la première connexion, vous devrez peut-être vous connecter à votre compte Outlook Calendar et accorder les autorisations demandées.
    5. Une fois la connexion correctement configurée, vous pouvez régler l’option suivante :
       1. Sous **À la suppression de l'événement**, choisissez le statut à appliquer lorsque vous supprimez d’Outlook Calendar un événement d’habitude synchronisé : **Marquer comme échec** ou **Marquer comme ignoré**.
    6. Une fois tous les réglages terminés, touchez **←** dans le coin supérieur droit pour enregistrer et revenir en arrière.

## **Limitations**

- Si vous supprimez le calendrier Habitify d’Outlook Calendar, les modifications ultérieures ne seront plus synchronisées. Déconnectez l’intégration, puis répétez les étapes de connexion.
- Archiver ou supprimer votre habitude dans Habitify supprimera tous ses événements d’Outlook Calendar.
- Supprimer tous les événements ou tous les événements futurs d’une habitude dans Outlook Calendar ne marquera pas votre habitude comme ignorée ou échouée.

## FAQ

<Accordion title="**Comment changer le compte Outlook intégré à mon compte Habitify ?**">
  Si vous souhaitez utiliser un autre compte Outlook Calendar pour l’intégration, procédez comme suit :

  - Déconnectez le compte actuel.
  - Accédez à votre navigateur et connectez-vous au nouveau compte Outlook.
  - Suivez de nouveau les étapes d’intégration.
</Accordion>
