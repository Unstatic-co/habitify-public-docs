---
title: "Catégorie"
---

Une catégorie est un groupe, ou un dossier, d’habitudes qui vous permet d’organiser votre suivi selon les différents domaines de votre vie, au lieu de traiter toutes vos habitudes comme une seule liste uniforme et indifférenciée. Regroupez vos habitudes d’exercice, d’hydratation et de sommeil sous « Santé », vos habitudes de travail en profondeur et de gestion des e-mails sous « Travail », et vos habitudes de journal et de méditation sous « Pleine conscience » — en fonction de la façon dont votre vie s’organise réellement.

Les catégories sont là pour vous aider à définir vos priorités. Au lieu d’un score quotidien unique qui englobe tout à la fois, vous pouvez vous concentrer sur une catégorie et voir précisément comment évolue ce domaine de votre vie.

    ## Créer une nouvelle catégorie

    <iframe src="https://drive.google.com/file/d/1tvk66uyWt5d6rRJoQHpPx_TnZR7C53Kb/preview" width="640" height="360" />

    1. Dans le **Journal**, balayez la barre des catégories vers la gauche jusqu’à son extrémité, puis touchez **\+**.
    2. Choisissez **Nouvelle catégorie**.
    3. Sur l’écran **Nouvelle catégorie**,
       1. touchez l’icône, choisissez-en une et attribuez une couleur à votre nouvelle catégorie, puis touchez ✓ pour enregistrer vos choix.
       2. Touchez le champ du nom et saisissez le nom de votre catégorie.
    5. Dans la liste **Exclure**, touchez ⊕ devant le nom de l’habitude pour l’ajouter à la catégorie.
    6. Lorsque tout est configuré, touchez ✓ pour enregistrer la nouvelle catégorie.

    ## Gérer une catégorie personnalisée

    Vous pouvez librement modifier le nom et l’icône d’une catégorie personnalisée, gérer les habitudes qui y sont incluses et supprimer une catégorie.

    ### Modifier une catégorie

    1. Dans l’application Habitify, accédez aux **Réglages**.
    2. Recherchez et ouvrez la section **Toutes les catégories**.
    3. Dans la liste des catégories, touchez celle que vous souhaitez modifier.
    4. Sur l’écran des détails de la catégorie, vous pouvez :
       1. toucher l’**icône** pour modifier l’icône et la couleur.<br />Touchez le bouton ✓ dans le coin supérieur droit pour enregistrer vos choix.
       2. toucher le **champ du nom** pour modifier le nom de la catégorie.
       3. dans la liste **Inclure**, toucher ⊖ devant le nom de l’habitude pour la retirer de la catégorie.
       4. dans la liste **Exclure**, toucher ⊕ devant le nom de l’habitude pour l’ajouter à la catégorie.
    5. Touchez le **bouton ✓** dans le coin supérieur droit pour enregistrer toutes les modifications.

    ### Modifier l’ordre des habitudes dans une catégorie

    1. Dans l’application Habitify, accédez aux **Réglages**.
    2. Recherchez et ouvrez la section **Toutes les catégories**.
    3. Dans la liste des catégories, touchez celle dont vous souhaitez réorganiser les habitudes.
    4. Dans la liste **Inclure**, maintenez le bouton ☰ situé à droite de l’habitude, puis faites-le glisser vers le haut ou le bas pour modifier sa position dans la liste.
    5. Lorsque tout est configuré, touchez le bouton ✓ pour enregistrer vos modifications.

    ### Supprimer une catégorie

    1. Dans Habitify, accédez aux **Réglages**.
    2. Recherchez et ouvrez la section **Toutes les catégories**.
    3. Dans la liste des catégories, touchez celle que vous souhaitez supprimer.
    4. Touchez le bouton « **Supprimer cette catégorie** ».
    5. À l’étape de confirmation, touchez « **Supprimer** ».

    ## Gérer l’ordre des catégories

    Vous pouvez organiser l’ordre de vos catégories personnalisées dans la barre des catégories du Journal. Voici comment :

    1. Dans l’application Habitify, accédez aux **Réglages**.
    2. Recherchez et ouvrez la section **Toutes les catégories**.
    3. Maintenez le bouton ☰ situé à droite de la catégorie, puis faites-le glisser vers le haut ou le bas pour modifier l’ordre de la catégorie.
    4. Touchez le bouton ✓ pour enregistrer les modifications.

    <Info>
      Les modifications apportées à l’ordre des catégories depuis les applications iOS et Android sont immédiatement synchronisées avec les applications Web et pour ordinateur dès qu’elles sont enregistrées.
    </Info>

    ## Gérer une catégorie personnalisée

    Vous pouvez librement modifier le nom et l’icône d’une catégorie personnalisée, gérer les habitudes qui y sont incluses et supprimer une catégorie.

    ### Modifier l’icône, la couleur et le nom d’une catégorie

    Pour modifier l’icône et la couleur d’une catégorie :

    1. Dans la barre latérale gauche, accédez à la section **Catégories**.
    2. Cliquez sur l’icône de la catégorie.
    3. Choisissez une nouvelle icône et une nouvelle couleur.
    4. Cliquez à l’extérieur pour confirmer les modifications.

    Pour modifier le nom d’une catégorie :

    1. Dans la barre latérale gauche, accédez à la section **Catégories**.
    2. Cliquez sur la catégorie que vous souhaitez modifier pour la sélectionner.
    3. Cliquez de nouveau pour activer la modification.
    4. Saisissez le nouveau nom.
    5. Appuyez sur Entrée pour enregistrer la modification.

    ### Gérer les habitudes d’une catégorie

    Pour ajouter une habitude à une catégorie :

    1. Dans la barre latérale gauche, accédez à **Préférences \> Habitudes.**
    2. Ouvrez la liste **Actives**.
    3. Recherchez l’habitude et faites-la glisser vers la catégorie souhaitée.

    Pour retirer une habitude d’une catégorie :

    1. Dans la barre latérale gauche, accédez à **Préférences \> Habitudes**.
    2. Accédez à **Catégories**, puis cliquez sur la catégorie qui contient actuellement votre habitude.
    3. Faites un clic droit sur l’habitude, puis choisissez **Modifier**.
    4. Dans les détails de l’habitude, accédez au **champ Catégorie**, puis cliquez pour retirer la catégorie.
    5. Cliquez sur **Enregistrer**.

    ### Supprimer une catégorie

    Pour supprimer une catégorie :

    1. Dans la barre latérale gauche, accédez à la section **Catégories**.
    2. Faites un clic droit sur l’habitude que vous souhaitez supprimer, puis choisissez **Supprimer**.
