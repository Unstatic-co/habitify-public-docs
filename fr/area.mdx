Un espace est un groupe, ou dossier, d’habitudes. Il vous permet d’organiser votre suivi selon les différents domaines de votre vie au lieu de conserver toutes vos habitudes dans une liste unique et indifférenciée. Regroupez par exemple le sport, l’hydratation et le sommeil sous « Santé » ; le travail de fond et les e-mails sous « Travail » ; le journal et la méditation sous « Pleine conscience » — adaptez les espaces à votre propre vie.

Les espaces vous aident à définir vos priorités. Au lieu d’un seul score quotidien couvrant tout à la fois, vous pouvez vous concentrer sur une catégorie et voir précisément comment évolue ce domaine de votre vie.

    ## Créer un espace

    <iframe src="https://drive.google.com/file/d/1tvk66uyWt5d6rRJoQHpPx_TnZR7C53Kb/preview" width="640" height="360" />

    2. Touchez **+ Nouvel espace**.
    3. Touchez l’icône, choisissez-en une et attribuez une couleur au nouvel espace.<br />Touchez le bouton ✓ pour enregistrer votre sélection.
    4. Touchez le champ du nom et saisissez le nom de l’espace.
    5. Dans la liste **Exclure**, touchez ⊕ devant le nom d’une habitude pour l’ajouter à l’espace.
    6. Lorsque tout est prêt, touchez le bouton ✓ pour enregistrer le nouvel espace.

    ## Gérer un espace personnalisé

    Vous pouvez modifier librement le nom et l’icône d’un espace personnalisé, gérer les habitudes qu’il contient et le supprimer.

    ### Modifier un espace

    1. Dans Habitify, ouvrez les **Paramètres**.
    2. Recherchez et ouvrez la section **Tous les espaces**.
    3. Dans la liste, touchez l’espace à modifier.
    4. Sur l’écran des détails de l’espace, vous pouvez :
       1. toucher l’**icône** pour modifier l’icône et la couleur,<br />puis toucher le bouton ✓ en haut à droite pour enregistrer votre sélection ;
       2. toucher le **champ du nom** pour modifier le nom de l’espace ;
       3. dans la liste **Inclure**, toucher ⊖ devant le nom d’une habitude pour la retirer de l’espace ;
       4. dans la liste **Exclure**, toucher ⊕ devant le nom d’une habitude pour l’ajouter à l’espace.
    5. Touchez le **bouton ✓** en haut à droite pour enregistrer toutes les modifications.

    ### Modifier l’ordre des habitudes dans un espace

    1. Dans Habitify, ouvrez les **Paramètres**.
    2. Recherchez et ouvrez la section **Tous les espaces**.
    3. Dans la liste, touchez l’espace dont vous souhaitez réorganiser les habitudes.
    4. Dans la liste **Inclure**, maintenez le bouton ☰ à droite de l’habitude, puis faites-le glisser vers le haut ou le bas.
    5. Lorsque tout est prêt, touchez le bouton ✓ pour enregistrer.

    ### Supprimer un espace

    1. Dans Habitify, ouvrez les **Paramètres**.
    2. Recherchez et ouvrez la section **Tous les espaces**.
    3. Dans la liste, touchez l’espace à supprimer.
    4. Touchez **Supprimer cet espace**.
    5. Lors de la confirmation, touchez **Supprimer**.

    ## Gérer l’ordre des espaces

    Vous pouvez organiser l’ordre de vos espaces personnalisés dans la barre des espaces du Journal :

    1. Dans Habitify, ouvrez les **Paramètres**.
    2. Recherchez et ouvrez la section **Tous les espaces**.
    3. Maintenez le bouton ☰ à droite de l’espace et faites-le glisser vers le haut ou le bas.
    4. Touchez le bouton ✓ pour enregistrer.

    <Info>
      Dès leur enregistrement, les modifications apportées à l’ordre des espaces depuis les applications iOS et Android sont immédiatement synchronisées avec les applications web et de bureau.
    </Info>

    ## Créer un espace

    <iframe src="https://drive.google.com/file/d/1-jFIqXsmgOC3dAhdALhaUJw_JrwXUl34/preview" width="640" height="360" />

    5. Cliquez à l’extérieur pour enregistrer les modifications.

    ## Gérer un espace personnalisé

    Vous pouvez modifier librement le nom et l’icône d’un espace personnalisé, gérer les habitudes qu’il contient et le supprimer.

    ### Modifier l’icône, la couleur et le nom d’un espace

    Pour modifier l’icône et la couleur d’un espace :

    1. Dans la barre latérale gauche, accédez à la section **Espaces**.
    2. Cliquez sur l’icône de l’espace.
    3. Choisissez une nouvelle icône et une nouvelle couleur.
    4. Cliquez à l’extérieur pour confirmer.

    Pour modifier le nom d’un espace :

    1. Dans la barre latérale gauche, accédez à la section **Espaces**.
    2. Cliquez sur l’espace à modifier.
    3. Cliquez de nouveau pour activer la modification.
    4. Saisissez le nouveau nom.
    5. Appuyez sur Entrée pour enregistrer.

    ### Gérer les habitudes d’un espace

    Pour ajouter une habitude à un espace :

    1. Dans la barre latérale gauche, accédez à **Préférences \> Habitudes**.
    2. Ouvrez la liste **Actives**.
    3. Recherchez l’habitude et faites-la glisser vers l’espace souhaité.

    Pour retirer une habitude d’un espace :

    1. Dans la barre latérale gauche, accédez à **Préférences \> Habitudes**.
    2. Accédez à **Espaces**, puis cliquez sur l’espace qui contient l’habitude.
    3. Faites un clic droit sur l’habitude et choisissez **Modifier**.
    4. Dans les détails de l’habitude, accédez au champ **Espace**, puis cliquez pour retirer l’espace.
    5. Cliquez sur **Enregistrer**.

    ### Supprimer un espace

    Pour supprimer un espace :

    1. Dans la barre latérale gauche, accédez à la section **Espaces**.
    2. Faites un clic droit sur l’espace à supprimer, puis choisissez **Supprimer**.
