---
title: "Tâche"
---

Une tâche est une petite action ponctuelle que vous pouvez associer à une habitude précise. Elle est distincte de l’objectif principal de l’habitude, mais reste liée à celle-ci. Considérez-la comme un moyen de noter les petites actions de soutien qui se présentent autour d’une habitude sans encombrer l’habitude elle-même : un livre à récupérer avant de commencer votre habitude « Lire », ou du matériel à acheter avant votre première séance de sport.

Contrairement à l’habitude à laquelle elle appartient, une tâche ne se répète pas. Elle est créée une fois, accomplie une fois, puis elle est terminée.

## Tâche ou liste de vérification

Toutes deux se trouvent dans une habitude, mais répondent à des besoins différents :

- **Tâche** : une action ponctuelle. Créez-la, accomplissez-la une fois, et c’est terminé.
- **Liste de vérification :** un ensemble d’étapes récurrentes qui se réinitialise et s’applique chaque fois que l’habitude se présente (par exemple, une liste de vérification fixe pour la routine matinale dans votre habitude « Routine matinale »).

Si ce dont vous avez besoin ne se produit qu’une fois, utilisez une tâche. Si cela se répète en même temps que l’habitude elle-même, utilisez une liste de vérification.

    ## Ajouter une tâche

    1. Dans le _Journal_, touchez votre habitude.
    2. Dans la _vue de progression individuelle_, touchez **•••** dans le coin supérieur droit.
    3. Choisissez **À propos de cette habitude**.
    4. Sous **Tâches**, touchez **Nouvelle tâche**.
    5. Saisissez le nom de la tâche, puis définissez sa date et son heure.
    6. Enfin, touchez **✓** ou **↵** sur votre clavier pour enregistrer la nouvelle tâche.

    ## Accomplir une tâche

    1. Dans le **Journal**, touchez votre habitude.
    2. Dans la vue de progression individuelle, touchez **•••** dans le coin supérieur droit.
    3. Choisissez **À propos de cette habitude**.
    4. Sous **Tâches**, touchez le 〇 devant la tâche pour la marquer comme terminée.

    Dès qu’elle est marquée comme terminée, elle est retirée de cette liste lors de votre prochaine visite dans cette vue. La page de votre habitude reste ainsi centrée sur ce qu’il vous reste à faire.

    ## Supprimer une tâche

    Pour supprimer une tâche en attente :

    1. Dans le **Journal**, touchez votre habitude.
    2. Dans la vue de progression individuelle, touchez **•••** dans le coin supérieur droit.
    3. Choisissez **À propos de cette habitude**.
    4. Sous **Tâches**_,_ balayez la tâche vers la gauche et choisissez **Supprimer**.

    ## Ajouter une tâche

    1. Dans le **Journal**_,_ touchez votre habitude pour ouvrir sa vue de progression individuelle.
    2. Dans la vue de progression individuelle, passez à l’onglet **À propos**.
    3. Sous **Tâches**, touchez **Nouvelle tâche**.
    4. Saisissez le nom de votre tâche et touchez **Fait** sur votre clavier pour l’enregistrer.
    5. Touchez deux fois la tâche pour modifier sa date et son heure.

    ## Accomplir une tâche

    1. Dans le **Journal**, touchez votre habitude pour ouvrir sa vue de progression individuelle.
    2. Dans la vue de progression individuelle, passez à l’onglet **À propos**.
    3. Sous **Tâches**, touchez le **〇** à côté de votre tâche pour l’accomplir.

    Une fois que vous avez effectué une tâche, marquez-la comme terminée directement depuis l’onglet **À propos** de l’habitude.

    ## Supprimer une tâche

    1. Dans le **Journal**, touchez votre habitude pour ouvrir sa vue de progression individuelle.
    2. Dans la vue de progression individuelle, passez à l’onglet **À propos**.
    3. Sous **Tâches**, balayez la tâche vers la gauche et choisissez **Supprimer**.

    ## Consulter toutes les tâches

    Marquer une tâche comme terminée n’efface pas son enregistrement. Vous pouvez toujours revoir ce que vous avez accompli :

    1. Dans la vue de progression individuelle de votre habitude, touchez le **bouton (⋮)** dans le coin supérieur droit.
    2. Touchez **Gestion des actions** pour l’ouvrir.

    Vous obtenez ainsi un historique continu des actions que vous avez effectuées ou qui sont encore en attente pour soutenir l’habitude, aux côtés de votre progression habituelle.

    ## Ajouter une tâche

    1. Depuis l’affichage de votre liste d’habitudes, ouvrez la vue de progression individuelle de votre habitude :
       1. dans **Grille** : cliquez une fois sur l’habitude.
       2. dans **Liste** : double-cliquez sur l’habitude.
    2. Dans la vue de progression individuelle, cliquez sur le **bouton d’affichage de la barre latérale** dans le coin supérieur droit.
    3. Dans la barre latérale droite, cliquez sur **À propos.**
    4. Sous **Liste d’actions**, cliquez sur **Ajouter une action**, saisissez votre nouvelle tâche, puis appuyez sur Entrée sur votre clavier pour l’enregistrer.
    5. Cliquez sur **Demain 09:00** sous la tâche pour ajuster l’échéance à laquelle la tâche doit être effectuée.

    ## Accomplir une tâche

    1. Depuis l’affichage de votre liste d’habitudes, ouvrez la vue de progression individuelle d’une habitude :
       1. dans **Grille** : cliquez une fois sur l’habitude.
       2. dans **Liste** : double-cliquez sur l’habitude.
    2. Dans la vue de progression individuelle, cliquez sur le **bouton d’affichage de la barre latérale** dans le coin supérieur droit.
    3. Dans la barre latérale droite, cliquez sur **À propos**.
    4. Sous **Liste d’actions**, cliquez sur le 〇 devant votre tâche pour la marquer comme terminée.

    ## Supprimer une tâche

    1. Depuis l’affichage de votre liste d’habitudes, ouvrez la vue de progression individuelle d’une habitude :
       1. dans **Grille** : cliquez une fois sur l’habitude.
       2. dans **Liste** : double-cliquez sur l’habitude.
    2. Dans la vue de progression individuelle, cliquez sur le **bouton d’affichage de la barre latérale** dans le coin supérieur droit.
    3. Dans la barre latérale droite, cliquez sur **À propos**.
    4. Sous **Liste d’actions**, cliquez sur ••• à droite de la tâche, puis choisissez **Supprimer l’action**.
