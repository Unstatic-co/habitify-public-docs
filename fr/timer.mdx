Le minuteur est un outil intégré destiné aux habitudes dont l’objectif se mesure en temps plutôt qu’avec une simple case à cocher. Au lieu de pratiquer l’activité puis d’essayer de vous souvenir de sa durée, lancez le minuteur : Habitify enregistrera automatiquement le temps pour vous.

Trois modes sont disponibles :

- **Compte à rebours :** décompte une durée définie, idéal lorsque vous savez exactement combien de temps consacrer à l’activité.
- **Chronomètre :** compte à partir de zéro sans fin prédéfinie, idéal lorsque vous ignorez la durée nécessaire.
- **Pomodoro :** alterne des périodes de concentration et de courtes pauses, idéal pour les tâches qui bénéficient de sessions structurées.

<Note>
  Le minuteur est disponible pour toute habitude dont l’unité de base de l’objectif est la minute ou l’heure.
</Note>

Voici comment utiliser le minuteur pour suivre une habitude dont l’objectif est une durée.

    ## Démarrer une session

    ### Démarrer un compte à rebours

    ![Timer Countdown I OS](/images/Timer-Countdown-iOS.png "Timer Countdown I OS")

    1. Dans le _Journal_, repérez l’habitude et touchez le bouton intelligent **⏱️ Minuteur**.
    2. Sur l’écran _Minuteur_, ouvrez l’onglet **Compte à rebours**.
    3. Réglez la durée de la session.<br />Pour ajouter un bruit blanc, touchez _၊၊||၊ Aucun son d’arrière-plan_, choisissez-en un, puis touchez **Terminé** en haut à droite. Sinon, touchez _Annuler_.
    4. Touchez **Démarrer**.

    ### Démarrer une session Pomodoro

    ![Timer Pomodoro I OS](/images/Timer-Pomodoro-iOS.png "Timer Pomodoro I OS")

    1. Dans le _Journal_, repérez l’habitude et touchez **⏱️ Minuteur**.
    2. Sur l’écran _Minuteur_, ouvrez l’onglet **Pomodoro**.
    3. Configurez la session :
       1. **Nombre de pomodoros :** choisissez le nombre de périodes de travail, jusqu’à 30.
       2. **Durée du pomodoro :** définissez chaque période de travail, jusqu’à 23 h 59 min.
       3. **Pauses :**
          - _Durée de la pause courte :_ durée entre deux périodes de travail.
          - _Pause longue :_ configurez les réglages suivants, puis touchez **Terminé**.
            - _Pomodoros avant la pause longue :_ nombre de périodes à terminer avant celle-ci.
            - _Durée de la pause longue :_ durée de chaque pause longue.
    4. Pour ajouter un bruit blanc, touchez _၊၊||၊ Aucun son d’arrière-plan_ sous le nom de l’habitude, choisissez-en un, puis touchez **Terminé**. Sinon, touchez **Annuler**.
    4. Lorsque tout est prêt, touchez **Démarrer**.

    ### Démarrer le chronomètre

    ![Timer Stopwatch I OS](/images/Timer-Stopwatch-iOS.png "Timer Stopwatch I OS")

    1. Dans le _Journal_, repérez l’habitude et touchez **⏱️ Minuteur**.
    2. Sur l’écran _Minuteur_, ouvrez l’onglet **Chronomètre**.
    3. Pour ajouter un bruit blanc, touchez _၊၊||၊ Aucun son d’arrière-plan_, choisissez-en un, puis touchez _Terminé_. Sinon, touchez _Annuler_.
    4. Touchez **Démarrer**.

    ## Pendant une session

    ### Mettre en pause ou arrêter

    - **Pour mettre la session en pause**, touchez **⏸ Pause** sous le compteur, puis **▶︎ Reprendre** pour continuer.
    - **Pour l’arrêter**, touchez **◼ Arrêter** en haut à droite, confirmez avec **Arrêter**, puis choisissez :
      - **Enregistrer** pour ajouter le temps compté à la progression ;
      - **Saisir une autre durée** pour enregistrer une valeur personnalisée ;
      - **Ignorer** en haut à gauche pour ne rien enregistrer ;
      - éventuellement **Notes (facultatif)** pour ajouter une note.

    ### Suivre la liste de contrôle

    ![Timer Checklist I OS](/images/Timer-Checklist-iOS.png "Timer Checklist I OS")

    1. Touchez **⫶☰ #/# tâches** sous le nom de l’habitude.
    2. Consultez et cochez les éléments.
    3. Touchez ⨂ en haut à droite pour fermer.

    ### Contrôler le son d’arrière-plan

    ![Timer Background Sound](/images/Timer-BackgroundSound.png "Timer Background Sound")

    Pour modifier le son pendant le décompte :

    1. Touchez le bouton **၊၊||၊** sous le nom de l’habitude.
    2. Choisissez _Aucun_ pour le couper ou sélectionnez un bruit blanc.
    3. Touchez **Enregistrer**, ou **Annuler** pour ignorer les modifications.

    ## FAQ

    <Accordion title="**Comment modifier le son de fin de session ?**">
      Il n’est actuellement pas possible de modifier ni de personnaliser ce son.
    </Accordion>

    <Accordion title="**Comment couper le son de fin de session ?**">
      Passez votre téléphone en mode silencieux à l’aide de l’interrupteur situé sur son côté gauche.
    </Accordion>

    <Accordion title="**Le minuteur s’arrête soudainement. Comment résoudre le problème ?**">
      Si une session s’arrête inopinément, suivez ces étapes.

      **1/ Vérifier les autorisations**

      Assurez-vous que Habitify peut fonctionner sans interruption :

      - Ouvrez **Réglages**.
      - Faites défiler puis touchez **Habitify**.
      - Activez les autorisations utiles, notamment **Actualisation en arrière-plan** et **Notifications**.

      **2/ Rechercher les mises à jour**

      Vérifiez que Habitify et le système sont à jour :

      - Ouvrez l’**App Store**.
      - Recherchez Habitify et ouvrez sa page.
      - Si une mise à jour est disponible, touchez **Mettre à jour**.
      - Recherchez également une mise à jour d’iOS dans **Réglages** \> **Général** \> **Mise à jour logicielle**.

      **3/ Éviter le mode économie d’énergie**

      - Ouvrez **Réglages**.
      - Accédez à **Batterie**.
      - Désactivez **Mode économie d’énergie**.
    </Accordion>

    ## Démarrer une session

    <Steps>
      <Step title="Ouvrez l’écran Minuteur">
        - Dans la disposition en grille, faites un clic droit sur la cellule et choisissez « Démarrer le minuteur ».

        - Cliquez sur le champ de durée.
        - Choisissez une valeur prédéfinie dans la liste.

    ## Pendant une session

    Vous pouvez mettre en pause ou arrêter une session en cours.

    - **Pour mettre en pause :** cliquez sur _Pause_ sous l’horloge, puis sur _Continuer_ pour reprendre.
    - **Pour arrêter :** cliquez sur _Arrêter_ sous l’horloge, puis sur _Ignorer la session_ dans la confirmation pour fermer le minuteur.

    <Note>
      Dans les applications web et de bureau, l’arrêt d’une session ne permet actuellement pas d’ajouter directement le temps compté à la progression de l’habitude.
