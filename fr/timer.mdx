title: "Minuteur"
---

Le minuteur est un outil intégré destiné à toute habitude dont l’objectif se mesure en temps plutôt qu’avec une simple case à cocher. Au lieu de réaliser l’activité puis d’essayer de vous rappeler combien de temps elle a réellement duré, vous démarrez le minuteur, effectuez l’habitude et laissez Habitify enregistrer automatiquement la durée pour vous.

Le minuteur propose trois modes, afin que vous puissiez choisir celui qui correspond le mieux à votre façon de fonctionner :

- **Compte à rebours** : décompte à partir d’une durée définie ; idéal lorsque vous savez exactement combien de temps vous souhaitez consacrer à une activité.
- **Chronomètre** : compte le temps écoulé sans fin prédéfinie ; idéal lorsque vous ne savez pas à l’avance combien de temps durera l’activité.
- **Pomodoro** : alterne des périodes de travail concentré et de courtes pauses ; idéal pour les tâches qui bénéficient de séquences de concentration structurées.

<Note>
  Le minuteur est disponible pour toute habitude dont l’objectif est mesuré avec l’unité de base « minute » ou « heure ».
</Note>

Voici comment utiliser le minuteur avec Habitify pour suivre la progression de vos habitudes ayant un objectif de durée.

    ## Démarrer une session du minuteur

    ### Démarrer une session Compte à rebours

    ![Minuteur Compte à rebours iOS](/images/Timer-Countdown-iOS.png "Minuteur Compte à rebours iOS")

    1. Dans le **Journal** :
       1. Dans la vue **Jour**, accédez à l’habitude et touchez le bouton intelligent **⏱️** à côté de celle-ci.
       2. Dans la vue **Semaine**, maintenez la cellule d’aujourd’hui et choisissez **Démarrer le chrono**.
    2. Sur l’écran du minuteur, touchez l’onglet **Compte à rebours** pour l’ouvrir.
    3. Ajustez la durée de votre session.<br />Si vous souhaitez ajouter un bruit blanc, vous pouvez toucher **၊၊||၊ Aucun son d’ambiance** et en choisir un dans la liste, puis toucher le bouton **« **_Terminé_** »** dans le coin supérieur droit. Sinon, touchez **Annuler**.
    4. Touchez le bouton **Démarrer** pour commencer votre session.

    ### Démarrer une session Pomodoro

    ![Minuteur Pomodoro iOS](/images/Timer-Pomodoro-iOS.png "Minuteur Pomodoro iOS")

    1. Dans le **Journal** :
       1. Dans la vue **Jour**, accédez à l’habitude et touchez le bouton intelligent **⏱️** à côté de celle-ci.
       2. Dans la vue **Semaine**, maintenez la cellule d’aujourd’hui et choisissez **Démarrer le chrono**.
    2. Sur l’écran du minuteur, touchez l’onglet **Pomodoro** pour l’ouvrir.
    3. Ajustez la durée de votre session.
       1. **Nombre de Pomodoros** : choisissez le nombre de périodes de travail de la session. Le maximum est de 30.
       2. **Durée du Pomodoro** : définissez la durée de chaque période de travail. Le maximum est de 23 heures et 59 minutes par période.
       3. **Pauses** :
          - **Durée de la pause courte :** définissez la durée de chaque pause courte entre 2 périodes de travail.
          - **Pause longue** : configurez les réglages ci-dessous et touchez **Terminé** pour enregistrer.
            - **Nombre de Pomodoros avant la longue pause** : définissez le nombre de périodes de travail à terminer avant la pause longue.
            - **Durée de la pause longue** : définissez la durée de chaque pause longue.
    4. Si vous souhaitez ajouter un bruit blanc, vous pouvez toucher **၊၊||၊ Aucun son d’ambiance** sous le nom de l’habitude et en choisir un dans la liste.<br />Touchez le bouton **Terminé** dans le coin supérieur droit pour enregistrer la modification. Sinon, touchez **Annuler**.
    4. Lorsque tout est configuré, touchez le bouton **Démarrer** pour commencer la session de concentration.

    3. Si vous souhaitez ajouter un bruit blanc, vous pouvez toucher **၊၊||၊ Aucun son d’ambiance** et en choisir un dans la liste.<br />Touchez ensuite le bouton **Terminé** dans le coin supérieur droit pour enregistrer la modification. Sinon, touchez **Annuler**.
    4. Touchez le bouton **Démarrer** pour commencer votre session.

    ## Pendant une session du minuteur

    ### Mettre la session en pause ou l’arrêter

    - Pour mettre la session en cours en pause, touchez le bouton **⏸ Mettre en pause** sous le compteur.<br />Plus tard, touchez le bouton **▶︎ Reprendre** pour que le décompte du temps continue.
    - Pour arrêter la session en cours, touchez le bouton **◼Arrêter** dans le coin supérieur droit, touchez de nouveau **Arrêter** pour confirmer, puis choisissez entre :
      - **Enregistrer** : pour consigner le temps comptabilisé dans la progression de votre habitude.
      - **Saisir une autre durée** : pour consigner une valeur personnalisée dans la progression de votre habitude.
      - **Abandonner** (dans le coin supérieur gauche) : pour ne rien enregistrer.
      - Si vous le souhaitez, touchez **Notes (facultatives)** pour ajouter facilement une note à votre habitude.

    ### Suivre la liste de vérification de l’habitude

    ![Liste de vérification du minuteur iOS](/images/Timer-Checklist-iOS.png "Liste de vérification du minuteur iOS")

    1. Touchez **⫶☰ #/# tâches** sous le nom de l’habitude.
    2. Consultez et cochez les éléments de votre liste de vérification.
    3. Touchez le bouton ⨂ dans le coin supérieur droit de la liste de vérification pour la fermer.

    ### Contrôler le son d’arrière-plan

    ![Son d’arrière-plan du minuteur](/images/Timer-BackgroundSound.png "Son d’arrière-plan du minuteur")

    De plus, **pour contrôler le son d’arrière-plan** pendant le fonctionnement du compteur :

    1. Touchez le **bouton ၊၊||၊** sous le nom de l’habitude.
    2. Choisissez **Aucun** (pour le désactiver) ou sélectionnez un bruit blanc dans la liste.
    3. Touchez **Enregistrer** pour enregistrer la modification. <br />Sinon, touchez **Annuler** pour abandonner les modifications.

    ## FAQ

    <Accordion title="**Comment modifier le son émis à la fin d’une session ?**">
      Il n’est actuellement pas possible de modifier ou de personnaliser le son de fin d’une session du minuteur.
    </Accordion>

    <Accordion title="**Comment désactiver le son émis à la fin d’une session ?**">
      Pour désactiver le son du minuteur, passez votre téléphone en mode silencieux ou basculez simplement le bouton situé sur le côté gauche du téléphone.
    </Accordion>

    <Accordion title="**Le minuteur s’arrête soudainement. Comment résoudre ce problème ?**">
      Il peut arriver que la session du minuteur s’arrête soudainement. Voici les étapes permettant de diagnostiquer et de résoudre ce problème.

      **1/ Vérifier les autorisations de l’app**

      Assurez-vous que Habitify dispose des autorisations nécessaires pour fonctionner sans interruption :

      - Ouvrez **Réglages**.
      - Faites défiler l’écran vers le bas et touchez **Habitify**.
      - Vérifiez que toutes les autorisations pertinentes, telles qu’**Actualisation en arrière-plan** et **Notifications**, sont activées.

      **2/ Rechercher les mises à jour logicielles**

      Assurez-vous que Habitify et le système d’exploitation de votre appareil sont tous deux à jour :

      - Ouvrez l’**App Store**.
      - Recherchez Habitify et ouvrez la page de l’app.
      - Si une mise à jour est disponible, touchez **Mettre à jour**.
      - Recherchez également les éventuelles mises à jour iOS ou Android en accédant à **Réglages** \> **Général** \> **Mise à jour logicielle**.

      **3/ Éviter le mode économie d’énergie**

      Vérifiez que votre appareil n’est pas en mode économie d’énergie, car celui-ci peut limiter les fonctionnalités de l’app :

      - Ouvrez **Réglages**.
      - Accédez à **Batterie**.
      - Vérifiez que le **Mode économie d’énergie** est désactivé.
    </Accordion>

    ## Démarrer une session du minuteur

    <Steps>
      <Step title="Ouvrir l’écran du minuteur">
        - Dans la disposition **Grille**, faites un clic droit sur la cellule et choisissez **Démarrer le minuteur**.
        - Dans la disposition **Liste**, survolez l’habitude avec votre curseur, puis cliquez sur ⏱️.
      </Step>
      <Step title="Configurer la durée de la session">
        - Cliquez sur le champ de la valeur de durée.
        - Choisissez une valeur prédéfinie dans la liste.

        <Note>
          Les applications Web et pour ordinateur ne permettent actuellement pas de configurer une durée personnalisée pour une session du minuteur.
        </Note>
      </Step>
      <Step title="Démarrer la session">
        - Cliquez sur le bouton **Démarrer la session** pour commencer.
      </Step>
    </Steps>

    ## Pendant une session du minuteur

    Pendant une session, vous pouvez la mettre en pause ou l’arrêter en cours de route.

    - **Pour la mettre en pause** : cliquez sur le bouton **Pause** sous l’horloge. Vous pourrez ensuite cliquer sur le bouton **Continuer** pour reprendre la session.
    - **Pour l’arrêter** : cliquez sur le bouton **Arrêter** sous l’horloge. Dans **Confirmation**, cliquez sur **Abandonner la session** pour confirmer et fermer le minuteur.

    <Note>
      Actuellement, dans les applications Web et pour ordinateur, l’arrêt d’une session en cours ne permet pas d’enregistrer directement le temps comptabilisé dans la progression de votre habitude.
    </Note>
