Une note est un petit journal intégré à chaque habitude : un endroit où consigner vos pensées, vos émotions et vos expériences pendant le suivi de votre progression.

Contrairement à une validation, qui indique seulement _si_ vous avez réalisé l’habitude, une note permet d’expliquer _pourquoi_ : ce qui vous traversait l’esprit ce jour-là, ce qui vous a freiné ou ce qui vous a incité à continuer. Vous pouvez également joindre une photo afin qu’un entraînement, un repas ou un projet terminé reste associé au jour où il a eu lieu.

La note ne sert pas à un usage unique : elle s’adapte à ce dont vous avez besoin au quotidien. Voici quelques exemples :

- **Inspiration et vision :** notez la raison pour laquelle vous avez commencé cette habitude. Les jours où la motivation baisse, retrouver votre « pourquoi » directement dans l’habitude peut vous remettre sur la bonne voie.
- **Journal et réflexion :** utilisez-la comme un journal continu de l’habitude : votre ressenti, son déroulement, vos observations. Au fil du temps, ces réflexions permettent d’identifier ce qui vous aide réellement à progresser au lieu de vous fier uniquement à votre mémoire.
- **Résolution de problèmes :** lorsque vous ne pouvez pas terminer une habitude, notez ce qui vous en a empêché. Mettre l’obstacle par écrit permet de mieux l’anticiper la prochaine fois au lieu de se heurter encore au même problème.

Cet article vous explique comment utiliser les notes.

    ## Ajouter une note

    1. Dans le _Journal_, faites glisser votre habitude vers la gauche.
    2. Touchez **Ajouter une note**.
    3. **Rédigez votre texte** et, si vous le souhaitez, **joignez une photo et/ou une humeur**.<br />Par défaut, la date et l’heure actuelles sont attribuées à la note.
    4. Touchez le **bouton ✓** en haut à droite pour enregistrer la note.

    ## Consulter toutes les notes

    Dans l’application iOS, vous pouvez consulter les notes ajoutées à chaque habitude :

    1. Dans le _Journal_, touchez votre habitude.
    2. Ouvrez la section **Notes**.

    Vous pouvez ensuite modifier ou supprimer vos notes.

    ## Modifier une note

    Pour modifier une note :

    1. Dans la vue de toutes les notes, touchez celle à modifier.
    2. Modifiez le texte et ajoutez, remplacez ou supprimez la photo et l’humeur si nécessaire.
    3. Touchez le **bouton ✓** en haut à droite pour enregistrer les modifications.

    ## Supprimer une note

    Pour supprimer une note :

    1. Dans la vue de toutes les notes, maintenez la note à supprimer.
    2. Choisissez **Supprimer**.

    ## FAQ

    <Accordion title="**Où consulter les notes de toutes mes habitudes ?**">
      Vous pouvez voir, jour par jour, toutes les notes enregistrées sur vos habitudes dans **Réflexion**.

      Tirez la vue Journal vers le bas, puis faites glisser vers la gauche pour sélectionner et ouvrir l’espace **Réflexions**.
    </Accordion>

    <Accordion title="**Comment modifier la date et l’heure d’une note ?**">
      L’application iOS ne permet actuellement pas d’ajouter des notes à une date passée. La note est conçue pour consigner une expérience en temps réel et la relire plus tard.

      Si vous souhaitez tout de même ajouter des notes dans le passé, utilisez les applications web ou de bureau.
    </Accordion>

    ## Ajouter une note

    1. Dans le _Journal_, selon la disposition actuelle :

    ## Consulter toutes les notes

    Vous pouvez consulter les notes ajoutées à chaque habitude :

    1. Dans le _Journal_, touchez votre habitude.
    2. Sur l’écran _[nom de l’habitude]_, ouvrez la section **Notes**.

    Vous pouvez ensuite modifier ou supprimer vos notes.

    ## Modifier une note

    Pour modifier une note :

    1. Dans la vue de toutes les notes, **maintenez la note** à modifier.
    2. Choisissez **Modifier**.
    3. Modifiez le texte et ajoutez, remplacez ou supprimez la photo et l’humeur si nécessaire.
    4. Touchez **Enregistrer** en haut à droite pour conserver les modifications.

    ## Supprimer une note

    Pour supprimer une note :

    1. Dans la vue de toutes les notes, **maintenez la note** à supprimer.
    2. Choisissez **Supprimer**.

    ## Ajouter une note

    Dans la _disposition en grille_ :

    1. **Repérez l’habitude** à laquelle ajouter une note.
    2. **Faites un clic droit sur la cellule de la date** à attribuer à la note.
    3. Choisissez **Ajouter une note**.
    4. Rédigez votre texte et ajoutez des photos ou une humeur si vous le souhaitez.
    5. Cliquez sur **Enregistrer**.

    Dans la _disposition en liste_ :

    - **Option 1 :** faites un **clic droit** sur l’habitude → choisissez **Ajouter une note** → rédigez le texte et ajoutez des photos ou une humeur si nécessaire → cliquez sur **Enregistrer**.
    - **Option 2 :** survolez l’habitude → cliquez sur le **bouton •••** à droite → choisissez **Ajouter une note** → rédigez votre texte et ajoutez des photos ou une humeur si nécessaire → cliquez sur **Enregistrer**.

    <Note>
      **Lorsque vous ajoutez une note dans la disposition en liste**, la date et l’heure actuelles lui sont attribuées par défaut et ne peuvent pas être modifiées ultérieurement.
    </Note>

    ## Consulter les notes existantes

    Dans la _disposition en grille_, lorsqu’une note est enregistrée pour une habitude à une date donnée, un petit triangle apparaît en haut à droite de la cellule correspondante.

    Un emplacement commun permet également de consulter toutes les notes d’une habitude donnée. Pour y accéder :

    <Steps>
      <Step title="Ouvrez la vue de progression d’une habitude.">
        - Dans la _disposition en grille_, cliquez une fois sur le nom de l’habitude.
        - Dans la _disposition en liste_, double-cliquez sur le nom de l’habitude.
      </Step>
      <Step title="Ouvrez la barre latérale de la vue de progression.">
        - Accédez au coin supérieur droit.
        - Cliquez sur le **bouton d’affichage de la barre latérale**, situé tout à droite.
      </Step>
      <Step title="Cliquez sur « Notes » pour voir toutes les notes de l’habitude.">
        Depuis cette vue, vous pouvez :

        - consulter toutes les notes existantes ;
        - ajouter de nouvelles notes ;
        - modifier les notes existantes.
      </Step>
    </Steps>

    ## Modifier une note

    Pour modifier une note existante :

    - Ouvrez la section qui regroupe toutes les notes dans la vue de progression de l’habitude.
    - Repérez la note à modifier, puis cliquez sur le **bouton •••** en bas à droite de la note.
    - Choisissez :
      - **Modifier** pour changer le texte ;
      - **Ajouter une image** pour joindre des photos.
    - Vous pouvez également cliquer sur l’**icône emoji** en bas à gauche de la note pour ajouter ou modifier l’humeur.

    ## Supprimer une note

    Pour supprimer une note existante :

    - Ouvrez la section qui regroupe toutes les notes dans la vue de progression de l’habitude.
    - Repérez la note à supprimer, puis cliquez sur le **bouton •••** en bas à droite de la note.
    - Choisissez **Supprimer**.

    ## FAQ

    <Accordion title="**Comment ajouter une note pour une date passée ?**">
      Pour ajouter une note à une date passée, utilisez la disposition en grille. La date la plus ancienne accessible dépend actuellement de la taille de la fenêtre de l’application et du niveau de zoom choisi.
    </Accordion>

    <Accordion title="**Où consulter les notes de toutes les habitudes ?**">
      Les applications web et de bureau ne proposent actuellement aucun emplacement commun regroupant les notes de toutes les habitudes.

      Dans l’application iOS ou Android, tirez la vue Journal vers le bas, puis faites glisser vers la gauche pour sélectionner l’espace **Réflexions**. Vous y verrez toutes les notes d’habitudes, classées par date.
    </Accordion>
