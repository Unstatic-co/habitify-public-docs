title: "Note"

Une Note est un petit journal intégré et associé à chaque habitude, dans lequel vous pouvez consigner vos pensées, vos émotions et vos expériences au fil de votre progression.

Contrairement à un pointage, qui indique uniquement _si_ vous avez réalisé l’habitude, une Note vous permet de saisir _pourquoi_ : ce qui vous traversait l’esprit ce jour-là, ce qui vous a freiné ou ce qui vous a poussé à continuer. Vous pouvez également joindre une photo à une note afin qu’une séance de sport, un repas ou un projet terminé apparaisse juste à côté du jour où l’événement a eu lieu.

Une Note n’est pas réservée à un usage particulier : elle s’adapte à ce dont vous avez réellement besoin ce jour-là. Voici quelques exemples d’utilisation :

- **Inspiration et vision :** notez la raison pour laquelle vous avez commencé l’habitude. Les jours où votre motivation faiblit, le fait de conserver votre « pourquoi » initial directement dans l’habitude peut vous aider à reprendre le cap.
- **Journal et réflexion :** utilisez-la comme un journal continu de l’habitude pour indiquer comment vous vous êtes senti, comment cela s’est passé et ce que vous avez remarqué. Au fil du temps, cette réflexion permet de repérer plus facilement ce qui vous aide réellement à progresser, sans vous fier uniquement à votre mémoire.
- **Résolution de problèmes :** les jours où vous n’avez pas pu réaliser l’habitude, notez ce qui vous en a empêché. Le fait de consigner l’obstacle au lieu de le laisser passer sous silence permet de beaucoup mieux l’anticiper la prochaine fois et d’éviter de vous heurter de nouveau au même problème.

Cet article vous explique comment utiliser les Notes.

    ## Ajouter de nouvelles notes

    1. Dans le **Journal**, selon la disposition actuelle :
       1. dans la vue **Jour**, balayez votre habitude vers la gauche, puis touchez **Notes** ;
       2. dans la vue **_Semaine_**, maintenez le doigt n’importe où sur la progression de l’habitude, puis choisissez **Ajouter des notes**.
    3. **Rédigez votre note** ; vous pouvez **joindre une photo et/ou une humeur** si vous le souhaitez.<br />Par défaut, la note sera datée de la date et de l’heure actuelles.
    4. Touchez **✓** dans le coin supérieur droit pour enregistrer votre nouvelle note.

    ## Consulter toutes les notes

    Dans l’application iOS, vous pouvez actuellement consulter les notes ajoutées à chaque habitude :

    1. Dans le **Journal**, touchez votre habitude pour ouvrir sa vue de progression individuelle.
    2. Accédez à la section **Notes**.

    Vous pouvez alors modifier ou supprimer vos notes.

    ## Modifier des notes existantes

    Pour modifier une note :

    1. Dans la vue affichant toutes les notes, touchez celle que vous souhaitez modifier.
    2. Modifiez votre texte et, si vous le souhaitez, ajoutez, remplacez ou supprimez la photo et l’humeur.
    3. Touchez **✓** dans le coin supérieur droit pour enregistrer vos modifications.

    ## Supprimer des notes existantes

    Pour supprimer une note :

    1. Dans la vue affichant toutes les notes, maintenez le doigt sur celle que vous souhaitez supprimer.
    2. Choisissez **Supprimer**.

    ## FAQ

    <Accordion title="**Où consulter toutes les notes de l’ensemble des habitudes ?**">
      Vous pouvez voir, jour par jour, toutes les notes consignées pour vos habitudes dans **Réflexions**.

      Faites glisser la vue Journal vers le bas, puis balayez vers la gauche pour sélectionner et ouvrir l’espace **Réflexions**.
    </Accordion>

    <Accordion title="**Comment modifier la date et l’heure d’une note ?**">
      Dans l’application iOS, il n’est actuellement pas possible d’ajouter des notes à des dates passées. Les Notes sont conçues pour vous aider à consigner une expérience en temps réel afin d’y réfléchir ultérieurement.

      Si vous souhaitez malgré tout ajouter des notes dans le passé, essayez d’utiliser les Notes sur le site Web ou dans les applications pour ordinateur.
    </Accordion>

    ## Ajouter de nouvelles notes

    Dans la disposition **Grille** :

    1. **Accédez à l’habitude** à laquelle vous souhaitez ajouter une note.
    2. **Faites un clic droit sur une cellule de la date** à laquelle vous souhaitez attribuer la note.
    3. Choisissez **Ajouter une note**.
    4. Rédigez votre note et ajoutez des photos ainsi qu’une humeur si vous le souhaitez.
    5. Cliquez sur **Enregistrer**.

    Dans la disposition **Liste** :

    - Faites un clic droit sur l’habitude → Choisissez **Ajouter une note** → Rédigez la note et ajoutez des photos ou une humeur si vous le souhaitez → Cliquez sur **Enregistrer**.

    Ou

    - Survolez l’habitude → Cliquez sur **•••** à l’extrémité droite → Choisissez **Ajouter une note** → Rédigez votre note et ajoutez des photos ou une humeur si vous le souhaitez → Cliquez sur **Enregistrer**.

    <Note>
      Lorsque vous ajoutez une note dans la disposition Liste, elle reçoit par défaut la date et l’heure actuelles, qui ne peuvent pas être modifiées ultérieurement.
    </Note>

    ## Consulter les notes existantes

    Dans la _disposition Grille_, si vous consignez une note pour une habitude à une date donnée, la cellule correspondante est signalée par un petit triangle dans son coin supérieur droit.

    Il existe également un emplacement commun où vous pouvez consulter toutes les notes consignées pour une habitude précise. Pour y accéder :

    <Steps>
      <Step title="Ouvrir la vue de progression individuelle d’une habitude.">
        - Dans la disposition **Grille**, cliquez une fois sur le nom de l’habitude.
        - Dans la disposition **Liste**, double-cliquez sur le nom de l’habitude.
      </Step>
      <Step title="Ouvrir la barre latérale de la vue de progression individuelle.">
        - Accédez au coin supérieur droit.
        - Cliquez sur le bouton d’affichage de la barre latérale situé à l’extrémité droite.
      </Step>
      <Step title="Cliquer sur Notes pour voir toutes les notes ajoutées à l’habitude.">
        Dans cette vue, vous pouvez :

        - Voir toutes les notes existantes
        - Ajouter de nouvelles notes
        - Modifier les notes existantes
      </Step>
    </Steps>

    ## Modifier des notes existantes

    Pour modifier une note existante :

    - Ouvrez la section permettant de consulter toutes les notes dans la vue de progression individuelle de l’habitude.
    - Accédez à la note que vous souhaitez modifier, puis cliquez sur **•••** dans le coin inférieur droit de la note.
    - Choisissez parmi les options suivantes :
      - **Modifier** : pour modifier le texte.
      - **Ajouter une image** : pour joindre des photos.
    - Si vous le souhaitez, cliquez sur l’icône d’emoji dans le coin inférieur gauche de la note pour ajouter ou modifier l’humeur.

    ## Supprimer des notes existantes

    Pour supprimer une note existante :

    - Ouvrez la section permettant de consulter toutes les notes dans la vue de progression individuelle de l’habitude.
    - Accédez à la note que vous souhaitez modifier, puis cliquez sur **•••** dans le coin inférieur droit de la note.
    - Choisissez **Supprimer**.

    ## FAQ

    <Accordion title="**Comment ajouter une nouvelle note dans le passé ?**">
      Pour ajouter une note à une date passée, utilisez la disposition Grille. Actuellement, la date passée la plus éloignée à laquelle vous pouvez ajouter une nouvelle note dépend de la taille de la fenêtre de l’application et du pourcentage de zoom avant ou arrière que vous avez défini.
    </Accordion>

    <Accordion title="**Où consulter toutes les notes ajoutées à l’ensemble des habitudes ?**">
      Sur le site Web et dans l’application pour ordinateur, il n’existe actuellement aucun emplacement commun permettant de voir toutes les notes ajoutées à l’ensemble des habitudes.

      Vous pouvez accéder à l’application iOS ou Android, faire glisser la vue Journal vers le bas, puis balayer vers la gauche afin de sélectionner et d’ouvrir l’espace **Bilans**, où toutes les notes des habitudes sont regroupées et triées par date.
    </Accordion>
