Ce guide explique brièvement comment ajouter une bonne habitude et suivre sa progression dans Habitify.

<Tabs>
  <Tab title=" iOS">
    ## Ajouter une bonne habitude

    <iframe src="https://drive.google.com/file/d/1Sm2g8KAFHdm67Je7YV6KH6qSpUps2tDN/preview" width="640" height="360" />

    1. Dans l’application **Habitify pour iOS**, ouvrez l’onglet **Journal**.
    2. Touchez le bouton **\+** en bas à droite, puis choisissez **Créer une bonne habitude**.
    3. Choisissez un **modèle prédéfini**<br />ou touchez **Habitude personnalisée** pour partir de zéro.
    4. Planifiez l’habitude dans **Répétition**, définissez son **Objectif** et ajoutez des **Rappels**.
    5. Touchez **✓** en haut à droite pour enregistrer l’habitude et commencer son suivi.

    ## Suivre la progression d’une bonne habitude

    Dans le Journal :

    - Balayez vers la droite pour choisir **Terminer** ou **Enregistrer**.
    - Balayez vers la gauche pour choisir **Ignorer** ou **Échec**.

    Dans la vue **Semaine** :

    - Touchez la progression de l’habitude pour ajouter une valeur.
    - Maintenez un jour appuyé pour le marquer comme **Ignoré** ou **Échec**.
  </Tab>
  <Tab title="🤖 Android">
    ## Ajouter une bonne habitude

    <iframe src="https://drive.google.com/file/d/1eq5cs-OzScF595HEu2RXYL_z81mkbO5h/preview" width="640" height="360" />

    1. Dans l’application **Habitify pour Android**, ouvrez **Journal**.
    2. Touchez le bouton **\+** près du coin inférieur droit, puis choisissez **Créer une bonne habitude**.
    3. Choisissez un **modèle prédéfini**<br />ou touchez **Créer la vôtre** pour partir de zéro.
    4. Planifiez l’habitude dans **Répétition**, définissez son **Objectif** et ajoutez des **Rappels**.<br />Après chaque changement, touchez ← pour enregistrer et revenir en arrière.
    5. Touchez **Enregistrer** pour ajouter la nouvelle habitude à votre liste.

    ## Suivre la progression d’une bonne habitude

    Dans la vue **Jour** :

    - Balayez vers la droite pour choisir **Terminer** ou **Enregistrer une valeur**.
    - Balayez vers la gauche pour choisir **Ignorer** ou **Échec**.

    Dans la vue **Semaine** :

    - Touchez la progression de l’habitude pour ajouter une valeur.
    - Maintenez un jour appuyé pour le marquer comme **Ignoré** ou **Échec**.
  </Tab>
  <Tab title="🖥️ Web et ordinateur">
    ## Ajouter une bonne habitude

    <iframe src="https://drive.google.com/file/d/1W4NzQD2KMWiJ-o1xODD0iIZVpXDP5Cok/preview" width="640" height="360" />

    1. Dans la barre de navigation gauche, ouvrez **Toutes les habitudes**.
    2. Dans la barre d’actions inférieure, cliquez sur **\+ Ajouter une habitude**, puis sur **Créer une bonne habitude**.
    3. Cliquez sur le champ du nom et choisissez un modèle prédéfini.<br />Vous pouvez aussi saisir le nom de votre propre habitude pour partir de zéro.
    4. Planifiez l’habitude dans **Répétition**, définissez son **Objectif** et ajoutez des **Rappels**.
    5. Cliquez sur **Enregistrer** en bas à droite pour l’ajouter à votre liste.

    ## Suivre la progression d’une bonne habitude

    Dans la **vue Grille**, faites un clic droit sur une cellule et choisissez une action. Vous pouvez sélectionner plusieurs cellules pour les mettre à jour en même temps.

    Dans la **vue Liste**, faites un clic droit sur une habitude, ou placez le pointeur dessus et cliquez sur le menu à trois points à droite, puis choisissez une action.
  </Tab>
</Tabs>
