Les tags NFC, pour Near Field Communication, sont de petits autocollants physiques peu coûteux que vous pouvez placer n’importe où. Habitify peut les utiliser comme déclencheurs : au lieu de déverrouiller le téléphone, ouvrir l’application et rechercher une habitude, approchez simplement le téléphone du tag.

Ces points de contact physiques relient votre environnement à vos habitudes. Un tag sur le sac de sport peut valider « Entraînement », un autre sur une étagère « Lire », et un tag près du lit « Dormir ». L’habitude apparaît naturellement dans votre journée sans que vous deviez penser à ouvrir l’application.

    ## Configurer une nouvelle intégration NFC

    1. Dans Habitify, ouvrez **Paramètres**.
    2. Sous **Intégrations**, touchez **NFC**.
    3. En bas de l’écran, touchez **Scanner un nouveau tag NFC**.
    4. Placez le téléphone sur le tag.<br />_Recherchez sur Internet l’emplacement du lecteur NFC de votre modèle ; il se trouve souvent près de l’appareil photo._
    5. Après le scan :
       1. Sous _Lorsque le tag NFC est touché_, choisissez l’action à exécuter.
       2. Sous _Habitude_, choisissez une habitude.
    6. Touchez **Enregistrer**.

    ### Actions prises en charge

    - **Marquer comme terminée** : termine une habitude.
    - **Marquer comme ignorée** : ignore l’habitude pour aujourd’hui.
    - **Marquer comme échec** : enregistre un échec pour aujourd’hui.
    - **Enregistrer une valeur de progression** : ajoute une valeur prédéfinie.
    - **Me demander** : permet de choisir l’action après le scan.

    ## Faire le point avec un tag NFC

    - Scannez le tag avec le téléphone pour recevoir une notification push.
    - Touchez la notification pour ouvrir l’application et exécuter l’action configurée.

    <Note>
      **Laissez Habitify fonctionner en arrière-plan pour une expérience optimale.**

      Si l’application est complètement fermée, scanner le tag puis toucher la notification ouvre seulement le Journal au lieu d’exécuter directement l’action.
    </Note>

    ## **Configurer une nouvelle intégration NFC**

    1. Dans Habitify, ouvrez **Paramètres**.
    2. Sous **Automatisation**, ouvrez **NFC**.
    3. Touchez **Scanner un nouveau tag NFC**.
    4. Placez le téléphone sur le tag.<br />_Recherchez sur Internet l’emplacement du lecteur NFC de votre modèle ; il se trouve souvent près de l’appareil photo._
    5. Après le scan :
       1. Sous _Lors du contact NFC_, choisissez l’action à exécuter.
       2. Sous _Habitude_, choisissez l’habitude concernée.
    6. Touchez **Enregistrer** en haut à droite.

    ### Actions prises en charge

    - **Marquer comme terminée** : termine une habitude.
    - **Marquer comme ignorée** : ignore l’habitude pour aujourd’hui.
    - **Marquer comme échec** : enregistre un échec pour aujourd’hui.
    - **Démarrer le minuteur** : lance une session de minuteur pour une habitude.
    - **Enregistrer une valeur de progression** : ajoute une valeur prédéfinie.
    - **Me demander** : permet de choisir l’action après le scan.

    ## Faire le point avec un tag NFC

    - Scannez le tag jusqu’à l’apparition d’une notification push.
    - Touchez la notification pour ouvrir l’application et poursuivre selon la configuration.

    <Note>
      **Laissez Habitify fonctionner en arrière-plan pour une expérience optimale.** <br /><br />Si l’application est complètement fermée, scanner le tag puis toucher la notification ouvre seulement le Journal au lieu d’exécuter directement l’action.
    </Note>

## Questions fréquentes

<Accordion title="**Combien d’habitudes peuvent être associées à un tag NFC ?**">
  Une seule.
</Accordion>

<Accordion title="**Quels types de tags NFC sont compatibles ?**">
  Nous recommandons les tags NTAG213, NTAG215 ou NTAG216.
</Accordion>

<Accordion title="**Quelle capacité de stockage minimale faut-il ?**">
  L’association d’une habitude nécessite moins de 100 octets.
</Accordion>
