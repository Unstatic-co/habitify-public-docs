title: "Tags NFC"
---

Les tags NFC (communication en champ proche) sont de petits autocollants physiques peu coûteux que vous pouvez placer n’importe où. Habitify peut les utiliser comme déclencheurs physiques de vos habitudes. Au lieu de déverrouiller votre téléphone, d’ouvrir l’app et de chercher l’habitude à pointer, il vous suffit d’approcher votre téléphone d’un tag pour que le pointage s’effectue à votre place.

L’idée est de créer dans votre environnement des points de contact réels et physiques directement reliés à vos habitudes, afin que votre espace devienne une extension de votre système d’habitudes plutôt qu’un élément distinct. Un tag collé sur votre sac de sport peut déclencher l’habitude « Entraînement » ; un autre sur votre bibliothèque, « Lire » ; un autre près de votre lit, « Dormir ». L’habitude devient quelque chose que vous rencontrez au fil de la journée, et non quelque chose qui vous oblige à penser à ouvrir une app.

    ## Configurer une nouvelle intégration NFC avec une habitude

    1. Dans l’app Habitify, accédez à **Réglages**.
    2. Dans la section **Intégration**, touchez **NFC**.
    3. En bas de l’écran NFC, touchez le bouton **Scanner une nouvelle balise NFC**.
    4. Placez votre téléphone sur votre tag NFC. <br />_Vous pouvez rechercher sur Internet l’emplacement du lecteur NFC de votre téléphone. Il se trouve souvent près de l’appareil photo._
    5. Une fois la lecture terminée :
       1. Sous **Lorsqu’une balise NFC est touchée**, choisissez l’action que l’app exécutera.
       2. Sous **Habitude**, choisissez une habitude.
    6. Enfin, touchez le bouton **Enregistrer**.

    ### Actions prises en charge

    - **Marquer comme terminé** : lire le tag NFC pour terminer une habitude.
    - **Marquer comme ignorée** : lire le tag NFC pour ignorer une habitude pour la journée en cours.
    - **Marquer comme échouée** : lire le tag NFC pour marquer une habitude comme échouée pour la journée en cours.
    - **Enregistrer la progression** : lire le tag NFC pour enregistrer une valeur de progression prédéfinie.
    - **Demandez-moi** : lire le tag NFC, puis choisir l’action à exécuter.

    ## Pointer une habitude avec le tag NFC

    Pointer une habitude à l’aide de votre tag NFC programmé est très simple :

    - Lisez le tag avec votre téléphone afin de recevoir une notification push.
    - Touchez la notification push pour ouvrir l’app et exécuter l’action que vous avez définie.

    <Note>
      **Pour une expérience optimale, laissez l’app Habitify s’exécuter en arrière-plan.**

      Si l’app est complètement fermée, lire le tag NFC puis toucher la notification push ouvrira uniquement la vue Journal, au lieu d’exécuter directement l’action prévue.
    </Note>

    ## **Configurer une nouvelle intégration NFC avec une habitude**

    1. Dans l’app Habitify, accédez à **Paramètres**.
    2. Dans la section **Automatisation**, touchez **NFC** pour y accéder.
    3. Touchez le bouton **Scanner nouvelle étiquette NFC**.
    4. Placez votre téléphone sur votre tag NFC. <br />_Vous pouvez rechercher sur Internet l’emplacement du lecteur NFC de votre téléphone. Il se trouve souvent près de l’appareil photo._
    5. Une fois la lecture terminée, vous pouvez configurer les éléments suivants :
       1. Sous **Lorsque NFC est touché**, choisissez l’action que l’app exécutera.
       2. Sous **l'habitude**, choisissez l’habitude sur laquelle l’app exécutera l’action.
    6. Enfin, touchez le bouton **Enregistrer** dans le coin supérieur droit.

    ### Actions prises en charge

    - **Marquer comme terminé** : lire le tag NFC pour terminer une habitude.
    - **Marquer comme ignoré** : lire le tag NFC pour ignorer une habitude pour la journée en cours.
    - **Marquer comme échec** : lire le tag NFC pour marquer une habitude comme échouée pour la journée en cours.
    - **Démarrer la minuterie** : lire le tag NFC pour démarrer une session de minuterie pour une habitude.
    - **Valeur enregistrée** : lire le tag NFC pour enregistrer une progression prédéfinie.
    - **Demande-moi** : lire le tag NFC, puis choisir l’action à exécuter.

    ## Pointer une habitude avec le tag NFC

    Pointer une habitude à l’aide de votre tag NFC programmé est très simple :

    - Lisez simplement le tag avec votre téléphone jusqu’à ce qu’une notification push apparaisse.
    - Touchez la notification pour ouvrir l’app, puis laissez-la exécuter les étapes que vous avez configurées.

    <Note>
      **Pour une expérience optimale, laissez l’app Habitify s’exécuter en arrière-plan.** <br /><br />Si l’app est complètement fermée, lire le tag NFC puis toucher la notification push ouvrira uniquement la vue Journal, au lieu d’exécuter directement l’action prévue.
    </Note>

## FAQ

<Accordion title="**Combien d’habitudes peuvent être associées à un tag NFC ?**">
  Une seule
</Accordion>

<Accordion title="**Quel type de tag NFC est compatible ?**">
  Nous recommandons les tags NTAG213, NTA215 ou NTA216.
</Accordion>

<Accordion title="**Quelle capacité de stockage minimale un tag NFC doit-il avoir ?**">
  Associer une habitude à un tag NFC nécessite moins de 100 octets de stockage.
</Accordion>
