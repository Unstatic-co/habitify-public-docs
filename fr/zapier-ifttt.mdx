## Intégration Zapier

Zapier connecte Habitify à plus de 500 applications et outils. Chaque connexion, appelée **Zap**, comporte deux parties : un **déclencheur**, l’événement qui lance le Zap, par exemple la fin d’une habitude dans Habitify, et une **action**, ce qui se produit ensuite, par exemple l’ajout d’une ligne dans une feuille de calcul.

Commencer à utiliser Habitify sur Zapier : [https://zapier.com/apps/habitify/integrations](https://zapier.com/apps/habitify/integrations)

Chaque connexion entre Habitify et une application ou un outil via Zapier est appelée un Zap.

- **Déclencheur** : événement qui démarre un Zap.
- **Action** : événement exécuté par un Zap.

### **Déclencheurs envoyés par Habitify à un Zap**

- **Nouveau journal ajouté** : se déclenche lorsque vous ajoutez une progression à une habitude.
- **Nouvelle humeur ajoutée** : se déclenche lorsque vous enregistrez une humeur.
- **Nouvelle note ajoutée** : se déclenche lorsque vous ajoutez une note à une habitude.
- **Nouveau statut ajouté** : se déclenche lorsqu’une habitude est terminée, ignorée ou marquée en échec.

### **Actions envoyées par un Zap à Habitify**

- **Ajouter un journal** : ajoute une progression à une habitude après une action dans une autre application.
- **Ajouter une humeur** : crée une humeur après une action dans une autre application.
- **Ajouter une note** : ajoute une note à une habitude après une action dans une autre application.
- **Mettre à jour le statut** : modifie le statut d’une habitude après une action dans une autre application.

## Intégration IFTTT

IFTTT, abréviation de « If This, Then That », est un service d’automatisation plus général qui connecte des applications, appareils et services, avec plus de 700 services disponibles.

Commencer à utiliser Habitify sur IFTTT : [https://ifttt.com/habitify](https://ifttt.com/habitify)

Les connexions Zapier sont appelées Zaps, tandis que celles d’IFTTT sont des **Applets**. Une Applet comporte trois éléments :

- un **déclencheur** : changement de données qui la lance, en temps réel ou par interrogation périodique ;
- une **requête** : données supplémentaires facultatives récupérées pendant l’exécution ;
- une **action** : opération exécutée par IFTTT après le déclenchement.

### Déclencheurs envoyés par Habitify à une Applet

- **Nouveau statut d’habitude :** se déclenche lorsqu’un nouveau statut est attribué à une habitude.
- **Nouvelle humeur enregistrée :** se déclenche lorsqu’une humeur est enregistrée.
- **Nouveau journal d’habitude :** se déclenche lorsqu’une progression est ajoutée à une habitude.
- **Nouvelle note d’habitude :** se déclenche lorsqu’une note est ajoutée à une habitude.

### Actions envoyées par une Applet à Habitify

- **Créer un journal :** ajoute une nouvelle progression à une habitude.
- **Créer une humeur :** ajoute un nouveau journal d’humeur.
- **Créer une note :** ajoute une nouvelle note à une habitude.
- **Mettre à jour le statut d’une habitude :** modifie le statut d’une habitude.

## Questions fréquentes

<Accordion title="**Zapier ou IFTTT : lequel choisir ?**">
  Les deux permettent à Habitify de communiquer avec d’autres applications, mais leurs orientations diffèrent :

  - **Zapier** est généralement mieux adapté aux outils de productivité et professionnels, comme les feuilles de calcul, gestionnaires de tâches et CRM, ainsi qu’aux flux comportant plusieurs étapes.
  - **IFTTT** convient généralement mieux aux appareils domotiques et aux automatisations simples à une seule action.

  Si l’outil souhaité est compatible avec les deux, choisissez en général la plateforme que vous utilisez déjà pour vos autres automatisations.
</Accordion>

<Accordion title="**Un abonnement payant est-il nécessaire pour utiliser ces intégrations ?**">
  Vous pouvez généralement utiliser Habitify et configurer ces intégrations avec les formules gratuites. Des frais apparaissent uniquement si vous utilisez une fonctionnalité payante ou dépassez le quota gratuit ; la tarification du service concerné s’applique alors.
</Accordion>
