## Definition of a good habit

In Habitify, a habit is a behavior that you perform regularly, often unconsciously. It can be a simple action like drinking water or a more complex routine like exercising daily. 

A good habit is one that helps you become a better version of yourself by improving your productivity, health, or overall well-being.

## Detailed settings of a good habit

### Repeat

Configuring Repeat is to schedule your habit - when the habit shows up in the Journal (mobile) or List View (web/desktop), and which days count toward your streak and your completion score.

| Mode | How it works | Best for |
| :-- | :-- | :-- |
| **Daily** | Appears every single day | Everyday habits |
| **Monthly** | Repeats on one or more specific date(s) of the month | Recurring monthly tasks like paying bills or a personal review |
| **Interval** | Repeats every N days (e.g., every 3 or 5 days); the app previews the next 3 upcoming dates | Habits that don't follow a weekly pattern, like watering plants |

<Info>
  Habitify does not support intervals longer than monthly (no "every 2 months" or "yearly" repeat).
</Info>

### Goal

Goal is the minimum target that defines "success" for a given period. Configure three parts:

- **Value** — the minimum amount to hit (e.g., 1 time, 30 minutes, 2 litres)
- **Unit** — pick from a pre-defined list suited to the habit template (e.g., "Drink Water" suggests litres, ml, US fl oz, cup), or create a **custom unit** by choosing base unit "times" and naming it (e.g., "chapters," "clients")
- **Period** — per day, per week, per month, or per year

<Info>
  **Unit type can't change after saving.** You can switch within the same type (minutes → hours), but not across types (minutes → km). Changing type requires creating a new habit.
</Info>

<Info>
  **Editing a custom unit's label rewrites past data.** If you rename "bottles" to "glasses," all historical logs display the new label too.
</Info>

### Time of Day

Groups habits into **Morning, Afternoon, or Evening** so your daily list reads as a structured plan rather than a flat checklist. You can select one or multiple periods — at least one is required. This is purely organizational and is not the same as a Reminder (a Reminder is an actual push notification at a set time). Time-of-day ranges themselves are customizable in app settings.

### Area

Custom folders for grouping habits by life category (e.g., "Health," "Work," "Morning Routine"). Requires at least one existing custom area before you can assign a habit to it. Create one via the Areas tab → "\+ New Area" → set name, icon, and color. A habit can belong to one or several areas.

### Reminders

Notifications that prompt you to do the habit. There are three types:

- **Time-based** — set a specific time; add multiple reminders per habit. For this type of reminders, you can set:
  - **Custom Schedule**: ability to set the different times per day, e.g., 6:30 AM weekdays  and 9:00 AM weekends
  - **Show as Alarm**: let the reminder show as a full alarm-style alert instead of a standard notification. 
  - **Show as Live Activity**: iOS also supports Live Activity (Lock Screen / Dynamic Island); Android has "Show as Live Update."
- **Location-based** (Premium) — triggers on arriving at or leaving a set location (e.g., gym, home).
- **Habit-stacking** (Premium) — triggers based on completion of another habit (e.g., "Journal" reminder fires 2 minutes after "Read a Book" is completed).

### Checklist

Breaks a complex habit (e.g., "Morning Routine," "Clean the House") into smaller sub-tasks. The checklist auto-refreshes on the same cadence as the habit's goal period.

- **iOS:** Checklist → New Item → type → Done
- **Android:** Checklist → Add More → type → Done
- Reordering isn't supported — items appear in the order added; to resequence, delete and re-add.

### Start Date

The first date the habit begins appearing in the Journal/List View. Defaults to today; can be set in the past to backfill progress, or in the future to plan ahead. Note: if you move the start date further into the past later, the default goal for the newly-included date range becomes "1 time."

### End Condition

End Condition allows you to give a habit a defined finish line instead of running indefinitely. Four types:

| Type | Ends when... | Example |
| :-- | :-- | :-- |
| **On a Date** | A specific calendar date is reached | "Study Vietnamese 1 hr/day" ends the day before a trip |
| **After a Streak** | A target number of consecutive periods is hit | "Meditate 10 min" ends after a 100-day streak |
| **After Total Completions** | A target number of completed periods is reached (non-consecutive allowed) | "Gym 4x/week" ends after 50 successful weeks |
| **By Total Amount** | Cumulative logged value hits a target | "Read" ends after 10,000 total pages logged |

If added to an _existing_ habit, the value must exceed what's already been achieved (e.g., date ≥ 7 days out, streak/completions/amount greater than current progress). Reaching a milestone or the end condition triggers a celebration, and the app prompts you to continue or archive the habit.

## How to create a good habit

<Tabs>
  <Tab title=" iOS">
    1. From the **Journal** tab, tap the **"\+"** icon.
    2. Pick a template from the gallery (e.g., "Read a Book," "Drink Water"), or choose **"Create Your Own"** / **Custom Habit** for a fully custom habit.
    3. Configure the detailed settings. 
    4. Tap **Save**.
  </Tab>
  <Tab title="🤖 Android ">
    1. From the **Journal** tab, tap the **"\+"** icon.
    2. Pick a template, or choose **"Create Your Own"** for a custom habit.
    3. Configure the detailed settings. <br />For every change in each field, tap ✔️ button to save the changes.
    4. Tap **Save**.
  </Tab>
</Tabs>

## **How habit appears in Journal view**

When a habit appears in Today list of the Journal view is based on the settings of **Repeat** and **Start Date**. 

For example, if your habit has **Start Date** as `2026-07-01` and **Repeat** as `every 2 days` , then it will appear on the list of date `2026-07-01`, `2026-07-03`, `2026-07-05,`etc.
