Journal é a tela principal para visualizar os hábitos programados e registrar o progresso diário ou semanal.

    ## Alternando entre listas

    Deslize a barra de Áreas para escolher All Habits, Morning, Afternoon, Evening ou uma Área personalizada. Cada lista mostra apenas os hábitos que pertencem a ela.

    ![Barra de Áreas no iOS](/images/Areabar_Journal_iOS.png "Barra de Áreas no iOS")

    ## Alternando entre layouts

    Use o botão de layout no canto superior para alternar entre Day View e Week View. O aplicativo lembra sua escolha.

    ### **Day View**

    Mostra os hábitos de uma única data, agrupados por meta e status. Use a barra de data para navegar e toque em Today para voltar ao dia atual.

    ![Status no Journal do iOS](/images/HabitStatus_Journal_iOS-copy.png "Status no Journal do iOS")

    Hábitos pendentes aparecem antes dos grupos Completed, Skipped e Failed. Metas semanais, mensais e anuais ficam em seções próprias; hábitos de abandono aparecem em Quit Habits.

    ![Tipos de hábito no Journal do iOS](/images/HabitType_Journal_iOS.png "Tipos de hábito no Journal do iOS")

    Toque nos botões inteligentes ou deslize o hábito para registrar progresso, concluir, pular, falhar, adicionar nota ou iniciar o Timer.

    ### Week View

    <iframe src="https://drive.google.com/file/d/1rP5gma82_VPux2kBGOyRJrX72UAw218U/preview" width="640" height="360" />

    Exibe uma grade com hábitos nas linhas e dias nas colunas, permitindo comparar a semana e registrar diretamente em uma célula.

    ![Hábitos positivos na Week View do iOS](/images/WeekView_GoodHabit_iOS.png "Hábitos positivos na Week View do iOS")

    Para hábitos positivos, os símbolos e cores indicam conclusão, progresso, Skip, Fail ou ausência de registro. Toque em uma célula para registrar; segure para ver ações adicionais.

    ![Hábitos negativos na Week View do iOS](/images/WeekView_BadHabit_iOS.png "Hábitos negativos na Week View do iOS")

    Para hábitos negativos, uma célula bem-sucedida, pulada ou com falha representa o resultado daquele dia. Metas de período usam uma faixa de progresso.

    ## Gerenciando a ordem dos hábitos

    <iframe src="https://drive.google.com/file/d/1cKK8d2w8I12G02TvZX4_9q0icU_Kni-L/preview" width="640" height="360" />

    Você pode usar ordem personalizada, por nome, status, sequência ou horário. A ordenação ajuda a priorizar hábitos incompletos e manter uma rotina previsível.

    ### **Como a ordenação é aplicada em cada layout**

    A Day View respeita os grupos de status e meta antes do critério escolhido. A Week View mantém uma ordem estável entre as linhas. A ordem de cada Área pode ser configurada separadamente.

    ### Como personalizar My Habits Order

    1. Acesse **Settings > All Habits**.
    2. Toque em **Sort** ou **My Habits Order**.
    3. Segure ☰ e arraste cada hábito.
    4. Toque em ✓ para salvar.

    Hábitos arquivados não aparecem no Journal. A ordem sincroniza com as plataformas compatíveis.

    ## **Pesquisando hábitos**

    <iframe src="https://drive.google.com/file/d/1cCGRzUANz0gI0XlhaJiXkoFPezvG1hud/preview" width="640" height="360" />

    Puxe o Journal para baixo, deslize até Search e solte. Digite parte do nome para filtrar hábitos ativos. Toque em um resultado para abrir o progresso individual.

    ## Journal no iPhone Duo

    <iframe src="https://drive.google.com/file/d/1sEK7isUjhRWzXzPIRgF45hUh9cCLbdkp/preview" width="640" height="360" />

    No layout de tela ampla, a lista permanece de um lado e os detalhes do hábito do outro, reduzindo a necessidade de navegar entre telas. As ações e os filtros funcionam da mesma forma.

    ## Perguntas frequentes

    <Accordion title="**Por que um hábito não aparece no Journal hoje?**">
      Verifique Repeat, Start Date, End Condition, Área e Time of Day. Confirme também que ele não está arquivado e que você está na lista e data corretas.
    </Accordion>

    <Accordion title="**Por que um hábito concluído mudou de posição?**">
      Na Day View, hábitos registrados são movidos para Completed, Skipped ou Failed. Isso mantém os itens pendentes em destaque; o hábito continua na ordem configurada dentro de seu grupo.
    </Accordion>

    <Accordion title="**Até onde posso voltar na Week View?**">
      Navegue pelas semanas anteriores usando a barra de data. O histórico disponível começa na Start Date de cada hábito e permanece acessível enquanto os dados não forem excluídos.
    </Accordion>

    ## Perguntas frequentes

    <Accordion title="**Por que um hábito não aparece hoje?**">
      Confira Repeat, datas, Área, Time of Day, estado arquivado, data e lista atuais.
    </Accordion>

    <Accordion title="**Como volto rapidamente para hoje?**">
      Toque em Today ou no indicador da data atual na barra de navegação.
    </Accordion>

    <Accordion title="**Até onde posso visualizar datas futuras na Day View?**">
      A Day View permite uma prévia limitada das próximas datas programadas. Para planejar mais adiante, consulte Repeat e o calendário do hábito.
    </Accordion>

    ## Barra lateral de navegação

    A barra esquerda oferece All Habits, períodos do dia, Áreas, Progress e Preferences. Clique em uma lista para filtrar o Journal.

    ## Visualização principal da lista

    ### Grid Layout

    Exibe hábitos nas linhas e datas nas colunas. Clique em uma célula para selecioná-la, clique com o botão direito para ações ou abra o hábito para ver o progresso individual. É ideal para comparar vários dias e registrar datas anteriores.

    ### List Layout

    Exibe os hábitos programados para a data atual em uma lista compacta. Use botões inteligentes, menu •••, clique com o botão direito ou a barra inferior para registrar progresso.

    ## Ordenando hábitos

    Escolha a ordem personalizada ou critérios como nome, status e horário. Os grupos de meta e status ainda organizam a List Layout.

    #### Como personalizar My Habit Order

    1. Acesse **Preferences > Habits**.
    2. Abra Active ou uma Área.
    3. Arraste os hábitos para a ordem desejada.
    4. As alterações são salvas automaticamente ou ao clicar fora.

    ## Pesquisando hábitos

    Use o campo Search ou o atalho de pesquisa na barra lateral. Digite parte do nome e selecione o resultado.

    ## Perguntas frequentes

    <Accordion title="**Qual layout devo usar?**">
      Use Grid para histórico, comparação e datas passadas; use List para o acompanhamento rápido de hoje.
    </Accordion>

    <Accordion title="**Por que o hábito aparece no Grid, mas não no List?**">
      Grid pode mostrar hábitos fora da programação atual, enquanto List exibe apenas os hábitos aplicáveis à data e à lista selecionadas. Confira Repeat, Start Date, End Condition e filtros.
    </Accordion>

    <Accordion title="**Até onde posso revisar o histórico no Grid?**">
      O Grid permite navegar por todo o histórico disponível, sujeito ao intervalo carregado na janela. Reduza o zoom ou role horizontalmente para alcançar datas mais antigas.
    </Accordion>
