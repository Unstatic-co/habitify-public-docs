Welcome to our REST API. Use it to programmatically access your habit tracking data, build integrations, and automate workflows.

## **Authentication**

All endpoints require authentication using an API key passed in the `X-API-Key` header.

To generate your API key, open our app and go to **Settings \> API**. Only one API key can be active at a time — generating a new key automatically revokes the previous one.

> **Note:** API access requires a paid subscription and is not available on the free plan.
