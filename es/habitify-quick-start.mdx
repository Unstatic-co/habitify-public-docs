Esta es una breve guía sobre cómo añadir un hábito positivo y registrarlo en la aplicación Habitify.

<Tabs>
  <Tab title=" iOS">
    ## Añadir un hábito positivo

    <iframe src="https://drive.google.com/file/d/1Sm2g8KAFHdm67Je7YV6KH6qSpUps2tDN/preview" width="640" height="360" />

    1. En la aplicación Habitify para iOS, abre la pestaña Diario.
    2. Toca el botón + de la esquina inferior derecha y elige **Crear un hábito positivo**.
    3. Elige una plantilla de hábito predefinida<br />o toca **Hábito personalizado** para crear uno desde cero.
    4. Configura **Repetición**, **Objetivo** y **Recordatorio** para el hábito nuevo.
    5. Cuando todo esté configurado, toca el botón ✓ de la esquina superior derecha para guardar el hábito nuevo en tu lista y empezar a registrarlo.

    ## Registrar el progreso de un hábito positivo

    Desde la vista **Día** de **Diario**, puedes registrar el progreso de un hábito de las siguientes formas.

    - Desliza hacia la derecha y elige **Completar** para marcar el hábito como hecho, o **Registrar** para añadir un valor al progreso del hábito.
    - Desliza hacia la izquierda y elige **Omitir** para marcar ese día como descanso, o **Fallar** para indicar un tropiezo.

    También puedes hacer lo siguiente en la vista **Semana**:

    - Toca una celda o una franja de progreso para añadir +1 o registrar un valor en el progreso del hábito.
    - Mantén pulsado un día y elige marcarlo como **Omitido** o **Fallido**.
  </Tab>
  <Tab title="🤖 Android">
    ## Añadir un hábito positivo nuevo

    <iframe src="https://drive.google.com/file/d/1eq5cs-OzScF595HEu2RXYL_z81mkbO5h/preview" width="640" height="360" />

    1. En la aplicación Habitify para Android, abre la pestaña Diario.
    2. Toca el botón + situado cerca de la esquina inferior derecha y elige **Crear un hábito positivo**.
    3. Elige una plantilla de hábito predefinida<br />o toca **Crear uno propio** para empezar desde cero.
    4. Configura **Repetición**, establece un **Objetivo** y añade **Recordatorios** para el hábito nuevo.<br />Después de cada cambio, recuerda tocar ← para guardarlo y volver.
    5. Cuando todo esté configurado, toca el botón Guardar para confirmar el hábito nuevo y añadirlo a tu lista.

    ## Registrar el progreso de un hábito positivo

    Desde la vista **Día** de **Diario**, puedes registrar el progreso de un hábito de las siguientes formas.

    - Desliza hacia la derecha y elige **Completar** para marcar el hábito como hecho, o **Registrar valor** para añadir un valor al progreso del hábito.
    - Desliza hacia la izquierda y elige **Omitir** para marcar ese día como descanso, o **Fallar** para indicar un tropiezo.

    También puedes hacer lo siguiente en la vista **Semana**:

    - Toca una celda o una franja de progreso para añadir +1 o registrar un valor en el progreso del hábito.
    - Mantén pulsado un día y elige marcarlo como **Omitido** o **Fallido**.
  </Tab>
  <Tab title="🖥️ Sitio web y escritorio">
    ## Añadir un hábito positivo

    <iframe src="https://drive.google.com/file/d/1W4NzQD2KMWiJ-o1xODD0iIZVpXDP5Cok/preview" width="640" height="360" />

    1. En la barra de navegación izquierda, abre la pestaña **Todos los hábitos**.
    2. Ve a la barra de acciones inferior, haz clic en **+ Añadir hábito** y elige **Crear un hábito positivo**.
    3. Haz clic en el campo del nombre y elige una de las plantillas de hábitos predefinidas.<br />También puedes escribir directamente el nombre de tu propio hábito y empezar desde cero.
    4. Programa el hábito en **Repetición**, establece un **Objetivo** y añade **Recordatorios** para el hábito nuevo.
    5. Cuando todo esté configurado, haz clic en el botón **Guardar** de la esquina inferior derecha para añadir el hábito nuevo a tu lista de seguimiento.

    ## Registrar el progreso de un hábito positivo

    En el diseño de **Cuadrícula**, haz clic con el botón derecho en cualquier celda y elige una acción para marcar el hábito como completado, omitido o fallido. Puedes seleccionar varias celdas para registrarlas a la vez.

    En el diseño de **Lista**, haz clic con el botón derecho en un hábito o coloca el cursor sobre él y pulsa el botón del menú de tres puntos que aparece cerca del extremo. Después, elige una acción para marcar el hábito como completado, omitido o fallido.
  </Tab>
</Tabs>
