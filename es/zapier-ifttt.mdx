## Integración con Zapier

Zapier conecta Habitify con más de 500 aplicaciones y herramientas. Cada conexión que creas se denomina **Zap** y consta de dos partes: un **desencadenante** (el evento que inicia el Zap, como completar un hábito en Habitify) y una **acción** (lo que ocurre como resultado, como añadir una fila a una hoja de cálculo).

Empieza a usar Habitify en Zapier: [https://zapier.com/apps/habitify/integrations](https://zapier.com/apps/habitify/integrations)

Cada conexión entre Habitify y una aplicación o herramienta mediante la integración con Zapier se denomina Zap.

- **Desencadenante**: evento que inicia un Zap.
- **Acción**: evento que ejecuta un Zap.

### **Desencadenantes de Habitify para un Zap**

- **Add new log**: se activa cuando añades un nuevo registro de progreso a un hábito.
- **Add new mood**: se activa cuando añades un registro de estado de ánimo.
- **Add new note**: se activa cuando añades una nota nueva a un hábito.
- **Add new status**: se activa cuando marcas un hábito como completado, omitido o fallido.

### **Acciones de un Zap en Habitify**

- **Add Log**: añade registros a tu hábito después de una acción de otras aplicaciones.
- **Add Mood**: crea un nuevo estado de ánimo después de una acción de otras aplicaciones.
- **Add Note**: añade una nota a tu hábito después de una acción de otras aplicaciones.
- **Update Status**: cambia el estado de tu hábito después de una acción de otras aplicaciones.

## Integración con IFTTT

IFTTT, abreviatura de «If This, Then That», es un servicio de automatización más amplio que conecta aplicaciones, dispositivos y servicios, con más de 700 servicios disponibles.

Empieza a usar Habitify en IFTTT: [https://ifttt.com/habitify](https://ifttt.com/habitify)

Las conexiones de Zapier se llaman Zaps, mientras que las de IFTTT se denominan **Applets**. Un Applet consta de tres partes:

- un **desencadenante**: el cambio de datos que lo inicia, ya sea en tiempo real o mediante una consulta periódica;
- una **consulta**: datos adicionales opcionales que se obtienen durante el proceso;
- una **acción**: lo que hace IFTTT cuando se activa el desencadenante.

### Desencadenantes de Habitify para un Applet

- **New habit status:** se activa cuando un hábito recibe un estado nuevo.
- **New mood logged:** se activa cuando se registra un nuevo estado de ánimo.
- **New habit log:** se activa cuando se añade un registro nuevo a tu hábito.
- **New habit note:** se activa cuando se añade una nota a tu hábito.

### Acciones de un Applet en Habitify

- **Create a new log:** añade un registro nuevo a tu hábito.
- **Create a new mood:** añade un nuevo registro de estado de ánimo.
- **Create a new note:** añade una nota nueva a tu hábito.
- **Update status of habit:** actualiza el estado de tu hábito.

## Preguntas frecuentes

<Accordion title="**Zapier o IFTTT: ¿cuál debería usar?**">
  Ambos cumplen esencialmente la misma función —permitir que Habitify se comunique con otras aplicaciones—, pero están orientados a necesidades distintas:

  - **Zapier** suele ser la mejor opción para conectar Habitify con herramientas de productividad y empresa (hojas de cálculo, gestores de tareas o CRM), y ofrece más posibilidades para flujos de trabajo de varios pasos.
  - **IFTTT** suele ser la mejor opción para dispositivos domésticos inteligentes y automatizaciones más sencillas de una sola acción.

  Si ambos admiten la herramienta que quieres conectar, la elección suele depender de la plataforma que ya utilices para tus demás automatizaciones.
</Accordion>

<Accordion title="**¿Se necesita alguna suscripción de pago para usar estas integraciones?**">
  En principio, puedes usar Habitify y configurar estas integraciones con un plan gratuito. Solo tendrás que pagar si utilizas una función de pago o agotas la cuota gratuita; en ese caso, pagarás conforme a la política de precios del servicio correspondiente.
</Accordion>
