---
title: "Área"
---

Un área es un grupo o carpeta de hábitos que te permite organizar el seguimiento según las distintas partes de tu vida, en lugar de tratar todos los hábitos como una única lista plana e indiferenciada. Agrupa el ejercicio, la ingesta de agua y el sueño en «Salud»; el trabajo concentrado y el correo electrónico en «Trabajo»; y la escritura y la meditación en «Atención plena», o utiliza la división que mejor represente tu vida.

Las áreas te ayudan a establecer prioridades. En lugar de tener una única Puntuación diaria para todo, puedes centrarte en una categoría y ver exactamente cómo marcha esa parte de tu vida.

    ## Crear un área nueva

    <iframe src="https://drive.google.com/file/d/1tvk66uyWt5d6rRJoQHpPx_TnZR7C53Kb/preview" width="640" height="360" />

    1. En **Diario**, desliza la barra de áreas hacia la izquierda hasta el final y toca **+**.
    2. Elige **Nueva área**.
    3. En la pantalla **Nueva área**:
       1. Toca el icono, elige uno y asigna un color al área nueva. Toca ✓ para guardar la selección.
       2. Toca el campo del nombre y escribe el nombre del área.
    5. En la lista **Excluir**, toca ⊕ delante del nombre de un hábito para añadirlo al área.
    6. Cuando todo esté configurado, toca ✓ para guardar el área nueva.

    ## Gestionar un área personalizada

    Puedes editar libremente el nombre y el icono de un área personalizada, gestionar los hábitos incluidos y eliminar el área.

    ### Editar un área

    1. En la aplicación Habitify, abre **Configuración**.
    2. Busca la sección **Todas las áreas** y tócala para abrirla.
    3. En la lista de áreas, toca el área que quieres modificar.
    4. En la pantalla de detalles del área, puedes hacer lo siguiente:
       1. Toca el **icono** para cambiarlo y elegir otro color.<br />Toca el botón ✓ de la esquina superior derecha para guardar la selección.
       2. Toca el **campo del nombre** para cambiar el nombre del área.
       3. En la lista **Incluir**, toca ⊖ delante del nombre de un hábito para eliminarlo del área.
       4. En la lista **Excluir**, toca ⊕ delante del nombre de un hábito para añadirlo al área.
    5. Toca el **botón ✓** de la esquina superior derecha para guardar todos los cambios.

    ### Cambiar el orden de los hábitos de un área

    1. En la aplicación Habitify, abre **Configuración**.
    2. Busca la sección **Todas las áreas** y tócala para abrirla.
    3. En la lista de áreas, toca el área cuyos hábitos quieras reordenar.
    4. En la lista **Incluir**, mantén pulsado el botón ☰ situado a la derecha del hábito y arrástralo hacia arriba o hacia abajo para cambiar su posición.
    5. Cuando termines, toca el botón ✓ para guardar los cambios.

    ### Eliminar un área

    1. En Habitify, abre **Configuración**.
    2. Busca la sección **Todas las áreas** y tócala para abrirla.
    3. En la lista de áreas, toca el área que quieres eliminar.
    4. Toca el botón **Eliminar esta área**.
    5. En el paso de confirmación, toca **Eliminar**.

    ## Gestionar el orden de las áreas

    Puedes organizar el orden de tus áreas personalizadas en la barra de áreas de Diario. Para hacerlo:

    1. En la aplicación Habitify, abre **Configuración**.
    2. Busca la sección **Todas las áreas** y tócala para abrirla.
    3. Mantén pulsado el botón ☰ situado a la derecha del área y arrástralo hacia arriba o hacia abajo para cambiar su posición.
    4. Toca el botón ✓ para guardar los cambios.

    <Info>
      Los cambios en el orden de las áreas realizados en las aplicaciones para iOS y Android se sincronizan inmediatamente con las aplicaciones web y de escritorio después de guardarlos.
    </Info>

    ## Gestionar un área personalizada

    Puedes editar libremente el nombre y el icono de un área personalizada, gestionar los hábitos incluidos y eliminar el área.

    ### Editar el icono, el color y el nombre de un área

    Para editar el icono y el color de un área:

    1. En la barra lateral izquierda, abre la sección **Áreas**.
    2. Haz clic en el icono del área.
    3. Elige un icono y un color nuevos.
    4. Haz clic fuera para confirmar los cambios.

    Para editar el nombre de un área:

    1. En la barra lateral izquierda, abre la sección **Áreas**.
    2. Haz clic para elegir el área que quieres editar.
    3. Haz clic de nuevo para activar la edición.
    4. Escribe el nombre nuevo.
    5. Pulsa Intro para guardar el cambio.

    ### Gestionar los hábitos de un área

    Para añadir un hábito a un área:

    1. En la barra lateral izquierda, abre **Preferencias \> Hábitos**.
    2. Abre la lista **Activos**.
    3. Busca el hábito y arrástralo al área de destino.

    Para eliminar un hábito de un área:

    1. En la barra lateral izquierda, abre **Preferencias \> Hábitos**.
    2. Ve a **Áreas** y haz clic en el área actual que contiene el hábito.
    3. Haz clic con el botón derecho en el hábito y elige **Editar**.
    4. En los detalles del hábito, ve al **campo Área** y haz clic para eliminar el área.
    5. Haz clic en **Guardar**.

    ### Eliminar un área

    Para eliminar un área:

    1. En la barra lateral izquierda, abre la sección **Áreas**.
    2. Haz clic con el botón derecho en el hábito que quieres eliminar y elige **Eliminar**.
