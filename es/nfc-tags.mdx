---
title: "Etiquetas NFC"
---

Las etiquetas NFC —comunicación de campo cercano— son pequeñas pegatinas físicas y económicas que puedes colocar en cualquier lugar. Habitify puede utilizarlas como desencadenantes físicos para tus hábitos. En lugar de desbloquear el teléfono, abrir la aplicación y buscar el hábito correcto para marcarlo, solo tienes que acercar el teléfono a una etiqueta para que se registre la actividad.

La idea es crear puntos de contacto físicos y reales en tu entorno que se conecten directamente con tus hábitos. Así, tu espacio se convierte en una extensión de tu sistema de hábitos en lugar de ser algo independiente. Una etiqueta en tu bolsa del gimnasio puede activar el hábito «Entrenar»; otra en la estantería puede activar «Leer»; y otra junto a la cama puede activar «Dormir». El hábito se convierte en algo que encuentras durante el día, no en algo para lo que tengas que acordarte de abrir una aplicación.

    ## Configurar una nueva integración entre NFC y un hábito

    1. En la aplicación Habitify, ve a **Ajustes**.
    2. En la sección **Integraciones**, toca **NFC**.
    3. En la parte inferior de la pantalla NFC, toca el botón **Escanear una etiqueta NFC nueva**.
    4. Coloca el teléfono sobre la etiqueta NFC.<br />_Puedes buscar en Internet dónde se encuentra el lector NFC de tu teléfono. Suele estar situado cerca de la cámara._
    5. Cuando termine el escaneo:
       1. En **Al tocar la etiqueta NFC**, elige la acción que ejecutará la aplicación.
       2. En **Hábito**, elige un hábito.
    6. Por último, toca el botón **Guardar**.

    ### Acciones compatibles

    - **Marcar como completado**: escanea la etiqueta NFC para completar un hábito.
    - **Marcar como omitido**: escanea la etiqueta NFC para omitir un hábito durante el día actual.
    - **Marcar como fallido**: escanea la etiqueta NFC para marcar un hábito como fallido durante el día actual.
    - **Registrar un valor de progreso**: escanea la etiqueta NFC para añadir un registro de progreso predefinido.
    - **Preguntarme**: escanea la etiqueta NFC y elige la acción que quieres ejecutar.

    ## Registrar un hábito con la etiqueta NFC

    Registrar una actividad con una etiqueta NFC programada es sencillo:

    - Escanea la etiqueta con el teléfono y recibirás una notificación push.
    - Toca la notificación push para abrir la aplicación y ejecutar la acción que hayas configurado.

    <Note>
      **Mantén la aplicación Habitify en ejecución en segundo plano para obtener la mejor experiencia.**

      Si la aplicación está completamente cerrada, al escanear la etiqueta NFC y tocar la notificación push solo se abrirá la vista Diario, en lugar de completar directamente la acción prevista.
    </Note>

    ## **Configurar una nueva integración entre NFC y un hábito**

    1. En la aplicación Habitify, ve a **Ajustes**.
    2. En la sección **Automatización**, toca **NFC** para abrirlo.
    3. Toca el botón **Escanear una etiqueta NFC nueva**.
    4. Coloca el teléfono sobre la etiqueta NFC.<br />_Puedes buscar en Internet dónde se encuentra el lector NFC de tu teléfono. Suele estar situado cerca de la cámara._
    5. Cuando termine el escaneo, puedes configurar lo siguiente:
       1. En **Al tocar NFC**, elige la acción que ejecutará la aplicación.
       2. En **Hábito**, elige el hábito en el que la aplicación ejecutará la acción.
    6. Por último, toca el botón **Guardar** en la esquina superior derecha.

    ### Acciones compatibles

    - **Marcar como completado**: escanea la etiqueta NFC para completar un hábito.
    - **Marcar como omitido**: escanea la etiqueta NFC para omitir un hábito durante el día actual.
    - **Marcar como fallido**: escanea la etiqueta NFC para marcar un hábito como fallido durante el día actual.
    - **Iniciar temporizador**: escanea la etiqueta NFC para iniciar una sesión del temporizador para un hábito.
    - **Registrar un valor de progreso**: escanea la etiqueta NFC para añadir un registro de progreso predefinido.
    - **Preguntarme**: escanea la etiqueta NFC y elige la acción que quieres ejecutar.

    ## Registrar un hábito con la etiqueta NFC

    Registrar una actividad con una etiqueta NFC programada es sencillo:

    - Escanea la etiqueta con el teléfono hasta que aparezca una notificación push.
    - Toca la notificación para abrir la aplicación y permitir que realice los pasos que configuraste.

## Preguntas frecuentes

<Accordion title="**¿Cuántos hábitos se pueden vincular con una etiqueta NFC?**">
  Solo 1.
</Accordion>

<Accordion title="**¿Qué tipo de etiqueta NFC es compatible?**">
  Recomendamos etiquetas NTAG213, NTA215 o NTA216.
</Accordion>

<Accordion title="**¿Cuál es la capacidad de almacenamiento mínima que necesita una etiqueta NFC?**">
  Para vincular un hábito con una etiqueta NFC se necesitan menos de 100 bytes de almacenamiento.
</Accordion>
