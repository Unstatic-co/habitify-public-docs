---
title: "Habitify para equipos"
---

Habitify para equipos facilita la compra y distribución en bloque del acceso Premium para tu equipo u organización.

En lugar de que cada miembro pague individualmente, una sola persona gestiona la compra y las licencias, y después distribuye el acceso a todos mediante un código de equipo compartido.

## Comprar licencias para equipos

1. Abre nuestra página web dedicada a las suscripciones para equipos:<br />[https://habitify.me/habitify-for-team](https://habitify.me/habitify-for-team)
2. Haz clic en el botón **Mejorar el plan de tu equipo** de la página de destino.
3. En la pantalla de configuración de la compra, debes hacer lo siguiente:
   ![Compra para equipos](/images/Team-Purchase.png "Compra para equipos")
   1. Elige el modelo de licencia: **1 mes** o **12 meses**.
   2. Introduce el **número de usuarios** —plazas—, es decir, el número de miembros del equipo.<br />El mínimo obligatorio es 30.
   3. Toca el botón **Comprar [precio total]** para continuar.
4. Revisa de nuevo los detalles del pedido y toca el botón **Comprar**.
5. En la _ventana de pago seguro_, deberás proporcionar lo siguiente:
   - **Tu dirección de correo electrónico:** es fundamental, ya que enviaremos a esta dirección la factura de pago y el enlace para configurar el código de licencia.
   - **Tu país:** necesario para la facturación y el cumplimiento de las políticas.
   - **Tu método de pago:** elige pagar mediante **PayPal** o con una **tarjeta** de débito o crédito.

Cuando se complete el pago, recibirás un correo electrónico de confirmación del pedido. El mensaje contiene el enlace importante para el paso siguiente. Abre el correo, accede al enlace y configura el código de licencia.

## Configurar el código de licencia del equipo

Después de la compra, debes crear el código único que los miembros del equipo utilizarán para activar Habitify PRO en sus cuentas.

Busca en tu bandeja de entrada un correo con el asunto **«Configura tu licencia de Habitify»** y haz clic en el enlace incluido.

El enlace te llevará a una página de configuración. Allí debes indicar lo siguiente:

- **Nombre del equipo** y **Código único**: esta información se utilizará para generar el código de acceso.
- **Descripción** —opcional—.
- **Logotipo del equipo** —opcional—.

Cuando todo esté configurado, toca el botón **Guardar**.

![Configuración del código de equipo](/images/Team-CodeSetup.png "Configuración del código de equipo")

Se te redirigirá a una pantalla final que confirmará que el código se ha creado. Esta página también mostrará un **enlace para compartir**.

Ya puedes enviar el **enlace para compartir** directamente a los miembros del equipo. Cuando lo abran, accederán a una página donde se muestran el nombre y el logotipo del equipo, además del código único que necesitan para activar su acceso Premium.

## Activar el acceso con un código de licencia de equipo

Asegúrate de tener preparado lo siguiente:

1. **Una cuenta de Habitify:** debes tener instalada la aplicación Habitify y haber iniciado sesión en tu cuenta personal de Habitify. Si todavía no has creado una cuenta, hazlo primero.
2. **Tu código de licencia:** necesitas el código de licencia único proporcionado por el administrador de tu equipo. Si no lo tienes, ponte en contacto directamente con tu responsable o administrador del equipo para recibirlo.

## **Cómo funciona la licencia para equipos**

Estas son las reglas principales de una licencia para equipos:

- **Sin fecha de caducidad:** el código de activación no tiene fecha de caducidad. Puedes comprarlo ahora y distribuirlo cuando el equipo esté preparado.
- **Un canje por cuenta:** cada cuenta individual de Habitify solo puede canjear un código concreto una vez.
- **La duración comienza al canjearlo:** el periodo de acceso PRO no empieza el día en que compras el código. Comienza exactamente en el momento en que el miembro del equipo canjea el código en la aplicación.

**Por ejemplo:** supongamos que compras un código de licencia para equipos de 1 mes el **1 de julio de 2026**. Si un miembro del equipo espera hasta el **7 de julio de 2026** para canjear el código y activar su acceso Premium, disfrutará de acceso PRO completo hasta el **7 de agosto de 2026**.

**Habitify para equipos funciona como una licencia de acceso con una duración limitada, no como una suscripción, por lo que no se renueva automáticamente.** Cuando termine el acceso activado, la cuenta del miembro del equipo volverá automáticamente a la versión gratuita.

Para restablecer el acceso PRO, el administrador deberá comprar un código de activación nuevo y entregárselo al miembro del equipo para que pueda canjearlo e iniciar su siguiente periodo de acceso PRO.
