---

Habit Gateは、習慣を完了するまで、選択したアプリやウェブサイトをブロックする機能です。ウェブサイトはChrome、Firefox、スマートフォンのブラウザでブロックされます。ロックを解除するには、写真、場所、アプリのスクリーンタイム、ヘルスデータ、またはNFCタグを使って習慣を確認します。各ゲートは1つの習慣に紐づきます。

## クイックセットアップ

習慣にHabit Gateを設定する手順は次のとおりです。

- **新しい習慣**または**習慣を編集**画面で、**Habit Gate**をタップします。
- **アプリとウェブサイトをブロック**を選択して有効にします。
- **アプリとウェブサイト**で、ブロックするアプリやウェブサイトを追加します。
- 習慣の完了を確認し、アプリ／ウェブサイトのブロックを解除する確認方法を選びます。
- **バイパスポリシー**で、ブロックと確認をどの程度厳格にするかを選びます。
- **確認後**で、確認に成功した後にアプリが行う処理を選びます。
- 設定が完了したら、**←**をタップして保存し、習慣の設定画面へ戻ります。

## 確認方法

### 場所で確認する

**設定方法**

![Habit Gate Location Android 1](/images/HabitGate_Location_Android-1.png "Habit Gate Location Android 1")

1. _Habit Gate_の**確認方法**で、**場所で確認**を選びます。
2. **場所を選択**をタップします。
3. **現在地**を選ぶか、ジムや図書館など、確認条件にする場所を**検索**します。
4. 距離を設定します。習慣を完了とみなすために、その場所へどの程度近づく必要があるかを指定します。
5. ←をタップして保存し、前の画面へ戻ります。

**確認方法**

1. ピン留めした場所へ移動し、設定した範囲内に入ります。
2. ブロックされたアプリまたはウェブサイトを開いてブロック画面を表示し、**確認**をタップします。
3. 確認対象の範囲内にいる場合、この画面で**確認**ボタンをタップできます。<br />範囲外の場合、ボタンは無効になり、現在地から必要なエリアまでの距離が表示されます。

### 写真で確認する

**設定方法**

![Habit Gate Photo Android 1](/images/HabitGate_Photo_Android-1.png "Habit Gate Photo Android 1")

1. _Habit Gate_の**確認方法**で、**写真で確認**を選びます。
2. 写真に写す内容を具体的に説明します。「_走った証拠_」より「_玄関先に置いたランニングシューズ_」のような説明が適しています。
3. 必要に応じて、次のルールを有効にします。
   1. 新しい写真を撮影する
   2. 過去の写真とは異なる写真にする
4. ←をタップして保存し、前の画面へ戻ります。

**確認方法**

1. ブロックされたアプリまたはウェブサイトを開いてブロック画面を表示し、**確認**をタップします。
3. 説明に合う写真を撮影します。
4. HabitifyのAIが写真と説明を照合するまで待ちます。
   1. 写真が条件を満たさない場合は理由が表示されます。**別の写真を撮る**をタップして、もう一度試せます。
   2. 写真が条件を満たすと緑色の✔️が表示され、**［ブロックされたアプリ／ウェブサイト］へ進む**をタップして利用できます。

![Verify By Photo Android](/images/Verify-by-Photo_Android.png "Verify By Photo Android")

### スクリーンタイムで確認する

**設定方法**

![Habit Gate Screen Time Android 1](/images/HabitGate_ScreenTime_Android-1.png "Habit Gate Screen Time Android 1")

1. _Habit Gate_の**確認方法**で、**スクリーンタイムで確認**を選びます。
2. Duolingoなど、使用するアプリを選びます。
3. 30分など、目標時間を設定します。
4. ←をタップして保存し、前の画面へ戻ります。

**確認方法**

1. 選択したアプリを開き、目標時間に達するまで使用します。
2. ブロックされたアプリまたはウェブサイトを開いてブロック画面を表示し、**確認**をタップします。
3. スクリーンタイムが条件を満たしていれば、続けて**確認**ボタンをタップできます。条件を満たしていない場合、ボタンは無効になります。

![Verify By Screen Time 1](/images/Verify-by-Screen-Time-1.png "Verify By Screen Time 1")

### Health Connectで確認する

**設定方法**

![Habit Gate Health Connect Android](/images/HabitGate_HealthConnect_Android.png "Habit Gate Health Connect Android")

1. _Habit Gate_の**確認方法**で、**Health Connectで確認**を選びます。
2. **対象アクティビティ**で、歩数や消費カロリーなど、記録するアクティビティを選びます。
3. **目標**で、10,000歩や800 kcalなど、達成する値を設定します。
4. ←をタップして保存し、前の画面へ戻ります。

**確認方法**

1. 目標を達成するまでアクティビティを行います。データはヘルスケアアプリから取得されます。
2. ブロックされたアプリまたはウェブサイトを開いてブロック画面を表示し、**確認**をタップします。
4. 現在の達成量をすぐに確認できます。初回はHealth Connectへのアクセス許可を求められる場合があります。
5. 目標値に達していれば、続けて**確認**ボタンをタップできます。達していない場合、ボタンは無効になります。

![Verify By Health Data](/images/Verify-by-Health-data.png "Verify By Health Data")

### NFCで確認する

**設定方法**

![NFC Verify Set Up](/images/NFC-Verify-SetUp.png "NFC Verify Set Up")

1. _Habit Gate_の**確認方法**で、**NFCで確認**を選びます。
2. **タグをスキャンしてリンク...**をタップします。
3. この習慣へ紐づけるNFCタグをスキャンし、ブロック画面に表示する短いメッセージを入力します。ブロック解除に必要な行動を思い出すために役立ちます。
4. ←をタップして保存し、前の画面へ戻ります。

**確認方法**

1. ブロックされたアプリまたはウェブサイトを開き、ブロック画面を表示します。
2. **確認**をタップし、**NFC**を選びます。
3. 紐づけたタグへスマートフォンをかざします。

![Verify By NFC](/images/Verify-by-NFC.png "Verify By NFC")

## バイパスポリシー

バイパスポリシーには、次の3段階があります。

- **簡単：** 簡単な確認を行えば、いつでもブロックされたアプリを開けます。習慣の確認は不要です。
- **制限：** Habitifyで確認操作を行った後、ブロックされたアプリを短時間だけ開けます。その後、再びブロックされます。
- **厳格：** 習慣が確認されるまで、アプリはブロックされたままです。確認を省略することはできません。

![Bypass Policy 1](/images/Bypass-Policy-1.png "Bypass Policy 1")

## 確認後

この設定では、確認が承認された時点でHabitifyが追加で行う処理を指定します。ゲートが開くと自動的に実行されるため、追加の操作は必要ありません。

次の2つのオプションがあります。

- **習慣を完了にする：** 確認が承認されると、Habitifyがその習慣を完了として記録します。
- **写真を習慣のノートに保存：** 確認用の写真が承認されると、その習慣のノートへ保存されます。

## よくある質問

<Accordion title="**翌日になるとアプリは再びブロックされますか？**">
  はい。ゲートは午前0時にリセットされます。習慣を確認すると、その日の残り時間はブロックされたアプリとウェブサイトを利用できます。午前0時になると再びブロックされ、もう一度確認するまで解除されません。
</Accordion>

<Accordion title="**同じアプリが複数の習慣でブロックされている場合はどうなりますか？**">
  対象となるすべての習慣を確認する必要があります。1つの習慣を確認しても、そのアプリをブロックする別の習慣が未確認であれば、アプリのロックは解除されません。
</Accordion>

<Accordion title="**複数の確認方法を有効にした場合、最初に表示されるのはどれですか？**">
  Habitifyでは、場所、写真、スクリーンタイム、Health Connect、NFCの固定順で表示されます。順序は変更できませんが、ブロック画面で**その他の確認方法**を選ぶと、確認に使う方法を切り替えられます。
</Accordion>
