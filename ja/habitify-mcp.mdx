---
title: "Habitify MCP"
---

Habitify MCP（Model Context Protocol）は、HabitifyアカウントをChatGPTやClaudeなどのAIアシスタントへ直接接続します。

接続後は習慣について会話するだけでなく、選んだAIアシスタントとの会話から、自然な言葉で実際に習慣を管理できます。

## Habitify MCPを接続する

### Claudeに接続する

1. Claudeを開き、**Customize**へ移動します。
2. **Connectors**を選びます。
3. **Add**をクリックします。
4. _Add custom connector_で、次のように設定します。
   1. **Name**：Habitify
   2. **MCP server URL**：`https://mcp.habitify.me/mcp`
5. 画面の案内に従ってHabitifyへログインし、アクセスを許可します。

認証が完了すると、追加したHabitifyコネクターの詳細設定を確認できます。

新しいチャットで、＋ボタン → Connectors → Habitifyをオンにすると、ClaudeからHabitifyの習慣を操作できます。

### ChatGPTに接続する

1. ChatGPTの画面で、**Plugins**へ移動します。
2. **Habitify**を検索します。
3. ＋をクリックして接続を開始します。
4. HabitifyのWebサイトへ移動したら、Habitifyアカウントにログインし、認証画面で**Connect**をクリックします。

認証が完了したら、**Start Chat**をクリックして、ChatGPTからHabitifyの習慣を操作できます。

### ほかのツールに接続する

Habitifyを別のツールに接続するときは、通常、**Server URL**または**Connection Link**の入力を求められます。

- **Connection URL：** `https://mcp.habitify.me/mcp`
- **Connection Type：** SSE（Server-Sent Events）

アプリによってボタン名や画面は異なりますが、一般的な手順は次のとおりです。

1. アプリの設定で、「Connectors」「Servers」「Extensions」などの項目を探します。
2. 新しいカスタムサーバーを追加するオプションを選びます。
3. 次の情報を入力します。
   - **Name：** `Habitify`
   - **URL：** 上記のURL（`https://mcp.habitify.me/mcp`）を貼り付けます。
4. 追加後、Habitifyアカウントへのログインとアクセスの承認を求められます。

## Habitify MCPで習慣に対してできること

接続後は、自然な言葉だけで、AIアシスタントにHabitifyアカウント上の操作を依頼できます。

- **一覧を確認：** 「今日の習慣を表示して」と頼んだり、特定の日付を指定したりして、残っている習慣を確認できます。
- **記録を追加：** 「朝のランニングを完了にして」と頼んだり、数値目標へ具体的な値を追加したりできます。
- **ステータスを更新：** 習慣のステータスを完了、スキップ、失敗へ変更できます。
- **進捗を消去：** 指定した日の習慣の進捗記録を消去し、0または「未開始」へ戻せます。日付を指定しなければ、当日が対象になります。

## トラブルシューティング

<Accordion title="**AIに削除済みの習慣や別アカウントの習慣が表示されるのはなぜですか？**">
  Habitify MCPが削除済みの習慣を取得する場合は、一度接続を解除してから再接続し、データを更新してください。

  別の自分のアカウントのデータを取得する場合は、Habitifyアプリにログインしているアカウントと、接続の認証を行ったブラウザでログインしているアカウントを比較し、同じアカウントであることを確認してください。

  問題が解決しない場合は、サポートチームへお問い合わせください。
</Accordion>

<Accordion title="**Habitify MCPでアプリ内の習慣がすべて取得されないのはなぜですか？**">
  Habitify MCPが一度に取得できる習慣は最大50件です。

  習慣が50件未満でもすべて取得できない場合は、接続し直してデータを更新してください。

  問題が解決しない場合は、サポートチームへお問い合わせください。
</Accordion>

<Accordion title="**Claudeで「Connect」ではなく「Configure」と表示されます。どうすればよいですか？**">
  Claudeのコネクター設定でHabitifyのメニューを開き、接続を解除します。その後、Connectを探し、Habitifyへのログインと認証を完了してください。メニュー名が異なる場合は、最新のClaude設定ガイドに従ってください。

  Connectが引き続き表示されない場合は、コネクター画面のスクリーンショットを撮り、サポートチームへお問い合わせください。
</Accordion>

## よくある質問

<Accordion title="**有料プランが必要ですか？トライアル中でも接続を試せますか？**">
  Habitify MCPはすべての方が無料で利用できるため、有料プランは必要ありません。

  ただし、REST APIを使った高度な利用にはProプランが必要になる場合があります。
</Accordion>

<Accordion title="**完全な履歴や、後から修正した進捗記録・メモの変更履歴を取得できますか？**">
  現在、Habitifyは習慣の完全な記録履歴の取得には対応していませんが、特定の日付の進捗は取得できます。

  値を記録してから変更した場合は最後の変更だけが保存されるため、修正履歴は取得できません。メモの変更も同様です。
</Accordion>

<Accordion title="**currentStreakは、指定した過去の日付時点の連続記録を表示しますか？**">
  currentStreakが表示するのは、本日までの連続記録です。

  過去の特定の日付までの連続記録を調べたい場合は、「_2026年10月10日時点で、瞑想の連続記録は何日でしたか_」のように依頼してください。
</Accordion>

<Accordion title="**Habitify MCPで定期レビューを実行したり、バックグラウンドで習慣を更新したりできますか？**">
  Habitify MCPは、まだ自動化ワークフローでの動作には対応していません。実行するには、ユーザーからの入力または操作が必要です。
</Accordion>
