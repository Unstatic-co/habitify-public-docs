Habitifyのサークルは、大切な人とつながり、共有し、一緒に成長するための非公開スペースです。メンバー同士で特定の習慣の進捗を共有し、励まし合い、互いの継続を支えます。

ランニング仲間とのマラソン練習、クラスメートとの語学学習、家族との水分補給など、1人で行う習慣記録を、協力的で楽しい体験へ変えられます。

この記事では、家族や友人とサークルを始めるために必要な内容を説明します。

## サークルとチャレンジの比較

![Circle Vs Challenge](/images/Circle-vs.-Challenge.png "Circle Vs Challenge")

|  | **サークル** | **チャレンジ** |
| :-- | :-- | :-- |
| **期間** | 終了日はなく、オーナーがアーカイブまたは削除するまで継続 | 開始日と終了日が決まった期間限定 |
| **記録する習慣** | 複数の習慣を同時に共有し、各メンバーが自分の習慣を設定 | チャレンジごとに共通の習慣目標を1つ設定 |
| **統計要素** | <ul><li>**一体感の連続記録**は、全メンバーが当日に予定された共有の日次習慣を1つ以上完了すると増えます。</li><li>**モメンタムポイント**は共有習慣を完了すると増え、メンバーごとのポイント順位も確認できます。</li></ul> | <ul><li>**連続記録ランキング**では、完了日ごとのポイントで参加者を順位付けし、未達成日には任意の減点を設定できます。</li><li>**チーム連続記録**は、全メンバーが当日のチャレンジ習慣を完了すると増えます。</li></ul> |
| **進捗の編集** | ジャーナルで後から変更した内容も習慣の進捗へ反映 | 当日の記録後はロックされ、過去日の追加記録や変更は不可 |
| **グループ人数** | 無制限 | 無制限 |
| **交流** | アクティビティタブ：リアクション、コメント、@メンション、継続的な会話 | アクティビティタブ：リアクション、コメント、@メンション、継続的な会話 |
| **対応プラットフォーム** | iOS、Android | iOS、Android |

    ## 新しいサークルを作成する

    1. Habitifyアプリ下部の**フレンド**を開きます。
    2. **＋ボタン**をタップし、**サークル**を選びます。
    3. 新しいサークルの詳細を入力します。
       ![Circle Create New](/images/Circle-CreateNew.png "Circle Create New")
       1. **サークル名**へ名前を入力します。
       2. **短い説明**へサークルの説明を入力します。
       3. **背景を変更**をタップし、**おすすめ**、**Unsplash**、**写真**からカバー画像を選びます。
    4. 設定が完了したら、右上の**完了**をタップします。

    ## 自分のサークルを管理する

    作成者は、サークルとメンバーの編集、アーカイブ、削除を行う権限を持ちます。

    **フレンド**からサークルを開き、**概要**タブへ移動します。

    ![Circle About](/images/Circle-About.png "Circle About")

    - **通知の購読**では、次の通知を受け取るかどうかを設定できます。
      - **ほかのメンバーのアクティビティ：** 自分の投稿へのリアクションやコメント、メンション、メンバーの連続記録更新、サークルの一体感の連続記録更新。
      - **自分の習慣に関するやり取り：** ほかの人が自分の習慣へチェックインし、リマインダーや励ましを送ったとき。
      - **サークルの実績と更新：** 参加リクエストの承認、新メンバーの参加、自分が作成したサークルへの参加リクエスト。
    - **管理者エリア**では次の操作ができます。
      - **サークルを編集：** 名前、説明、背景画像を変更します。
      - **サークルをアーカイブ：** サークルを保存したまま読み取り専用にします。履歴は閲覧できますが、新しい活動は追加されません。
      - **サークルを削除：** サークルとすべてのデータを完全に削除します。

    ## サークルの参加者を管理する

    ### 参加者を招待する

    自分が所有するサークルへ、友人、家族、同僚を招待する手順は次のとおりです。

    1. **フレンド**からサークルを開きます。
    2. 右上の📤をタップします。
    3. 共有画面の**公開リンクで招待**で設定します。
       ![Circle Sharing](/images/Circle-Sharing.png "Circle Sharing")
       - 招待の送信方法を選びます。
         - **メッセージ：** スマートフォンのメッセージアプリでリンクを直接送ります。
         - **リンクを共有：** 連絡先やアプリへ招待リンクを共有します。
         - **リンクをコピー：** 後で任意の場所へ貼り付けられるよう、リンクをコピーします。
       - **自動承認**を設定します。
         - **オン：** リンクを開いた人は許可なしですぐに参加できます。
         - **オフ：** 参加リクエストの通知が届き、メンバーになる前に手動で承認する必要があります。

    ### 参加リクエストを管理する

    自動承認をオフにした場合、参加リクエストを手動で承認します。

    ![Circle Manage Requests](/images/Circle-ManageRequests.png "Circle Manage Requests")

    リクエストが届くとプッシュ通知が送られます。また、サークルの**概要**タブにある**保留中のリクエスト**でも確認できます。

    - 参加を許可する場合は**承認**をタップします。
    - 参加させない場合は**拒否**をタップします。

    ### サークルからメンバーを削除する

    自分が作成したサークルでは、次の手順でメンバーを削除できます。

    1. **フレンド**からサークルを開き、**概要**タブへ切り替えます。
    2. 現在の参加者が表示される**メンバー**へ移動します。
    3. 対象メンバーの名前を**左へスワイプ**し、**削除**をタップします。
    4. 確認ポップアップで、もう一度**削除**をタップします。

    ![Circle Remove Member](/images/Circle-RemoveMember.png "Circle Remove Member")

    メンバーはすぐに削除され、共有習慣と今後の進捗は表示されず、グループにも反映されなくなります。過去にグループで達成した実績は履歴に残ります。

    ## ほかのオーナーのサークルを利用する

    ### ほかの人のサークルへ参加する

    Habitifyサークルへの招待は、相手が自己改善の旅を一緒に進める仲間になってほしいと考えていることを意味します。

    招待リンクを受け取ったら、次の操作を行います。

    - リンクをタップするとHabitifyアプリが開き、招待画面へ移動します。
    - **参加をリクエスト**をタップします。

    ![Circle Requesttojoin](/images/Circle-Requesttojoin.png "Circle Requesttojoin")

    その後の動作はサークルの公開設定によって異なります。

    - **公開サークル：** すぐに追加され、サークルとほかのメンバーを確認できます。
    - **非公開サークル：** 作成者へリクエストが送信されます。送信済みの確認が表示され、承認されると通知が届きます。

    ### ほかの人のサークルから退出する

    1. サークルで**概要**タブへ切り替えます。
    2. 一番下の**危険な操作**までスクロールし、**このサークルから退出**をタップします。
    3. 確認ポップアップで**退出**をタップします。

    <Warning>
      **サークルからの退出は即時に反映され、次の影響があります。**

      - サークルのメンバー一覧から直ちに削除されます。
      - 以前共有した内容も含め、ほかのメンバーから自分のプロフィール、共有習慣、進捗マップ、連続記録が見えなくなります。
      - サークルへアクセスできなくなり、ほかのメンバーの進捗や共有習慣も確認できなくなります。
    </Warning>

    ## サークルで自分の習慣を管理する

    ### サークルへ習慣を共有する

    進捗の共有はHabitifyサークルの中心となる機能であり、互いに刺激を与え、意欲を高めます。

    **参加中のサークルへ習慣を共有する手順：**

    - **フレンド**から共有先のサークルを開きます。
    - メンバーバーで自分のプロフィールをタップします。
    - 下部の**共有する習慣を選択**をタップします。
      ![Circle Select Habitto Share](/images/Circle-SelectHabittoShare.png "Circle Select Habitto Share")
    - 習慣一覧から共有するものを選びます。
    - 右上の**次へ**をタップします。
    - 最後に一覧を確認し、**確認**または**保存**をタップします。

    **共有される内容**

    確定すると、共有習慣はサークルの全メンバーへ表示されます。各習慣では次の内容が共有されます。

    ![Circle Shared Habit View 1](/images/Circle-SharedHabitView-1.png "Circle Shared Habit View 1")

    - **進捗ブロックマップ：** 過去3か月のチェックインを示し、継続状況を確認できます。
    - **習慣の目標：** その習慣へ設定した目標です。
    - **現在の連続記録：** グループと一緒に称えられる、現在の連続達成日数です。

    ### 共有習慣の一覧を編集する

    新しい目標を共有したり、共有中の習慣を非公開へ戻したりできます。

    - **フレンド**から対象のサークルを開きます。
    - メンバーバーで自分のプロフィール画像をタップします。
    - 共有習慣一覧の下までスクロールし、**共有習慣を管理**をタップします。
      ![Circle Edit Habitsto Share](/images/Circle-EditHabitstoShare.png "Circle Edit Habitsto Share")
    - 習慣をタップして選択または選択解除します。チェックマークが付いた習慣が共有されます。
    - 右上の**次へ**をタップします。
    - 一覧を確認し、**確認**または**保存**をタップします。

    <Note>
      変更後にほかのメンバーへ表示される内容は次のとおりです。

      - **新しい習慣を追加した場合：** サークル内のプロフィールへすぐに表示され、進捗マップ、目標、現在の連続記録を確認できるようになります。ただし、**一体感の連続記録**などの共同実績への反映は**翌日から**始まります。
      - **習慣の共有を停止した場合：** サークル内の公開プロフィールから直ちに削除され、進捗マップなどの詳細も見えなくなります。サークルの過去の実績には影響しません。
    </Note>

    ## **統計タブを理解する**

    Habitifyサークルでは、**一体感の連続記録**と**モメンタムポイント**という2つの主要統計で、グループ全体の成功と勢いを測ります。どちらも習慣の完了に基づきますが、チーム成績の異なる側面を記録します。

    <Info>
      習慣の進捗が一体感の連続記録とモメンタムポイントへ反映されるのは、**習慣を共有した翌日から**です。
    </Info>

    ### 一体感の連続記録

    一体感の連続記録は、サークルの日々の継続性を測る指標です。サークルの_アクティブな全メンバー_が、共有習慣を1つ以上完了できた連続日数を示します。

    ![Challenge Vs Circle (3)](/images/Challenge-vs.-Circle-\(3\).png "Challenge Vs Circle (3)")

    **<u>一体感の連続記録を維持する5つのルール</u>：**

    1. **日次目標**があり、**今日繰り返す予定**の習慣を**完了**した場合だけ反映されます。
    2. **全員が今日の日次習慣を1つ以上完了**すると、連続記録が1増えます。スキップまたは失敗は、実行しなかった場合と同じです。
    3. 当日分として反映されるのは、**当日に、当日を対象として完了した記録**だけです。
    4. メンバーが**オフモード**を有効にしている場合、その人は免除され、ほかのメンバーだけで継続できます。
    5. **全メンバーが同時にオフモード**の場合、連続記録は途切れず、最初の人が戻って習慣を完了するまで停止します。

    **統計**タブで**一体感の連続記録**をタップすると、今日1つ以上完了した人、未完了の人、免除されている人を確認できます。

    ### モメンタムポイント

    モメンタムポイントは、サークル全体の努力を最も簡単に表す指標で、グループの実行量を示します。

    ![Circle Momentum Point 1](/images/Circle-MomentumPoint-1.png "Circle Momentum Point 1")

    ルールはシンプルです：**1回の完了＝1モメンタムポイント**

    目標の種類に関係なく、メンバーが共有習慣を完了するたびに、サークルの合計へ1ポイント追加されます。これはグループが行った前向きな行動の累計です。

    全メンバーは次の情報を確認できます。

    - 過去30日間の**日ごとのモメンタムポイント**を示す傾向グラフ。
    - 月曜日を週の初日とする**今週の合計モメンタムポイント**。新しい月曜日になると週のポイントは0へリセットされます。

    **統計**タブで**モメンタムポイント**をタップすると、各メンバーのポイントを確認でき、サークルをゲーム感覚で楽しめます。

    ## アクティビティタブを見る

    Habitifyサークルは進捗記録だけでなく、活発なコミュニティでもあります。**アクティビティ**タブは、自分とグループメンバーだけが利用できる非公開のソーシャルフィードです。

    ![Circle Activities](/images/Circle-Activities.png "Circle Activities")

    ### サークルの最新情報を確認する

    アクティビティタブでは重要な出来事が自動更新され、次のイベントで投稿が作成されます。

    - **新メンバーの参加：** 全員が挨拶できるよう、歓迎の投稿が表示されます。
    - **メンバーの連続記録更新：** 共有習慣の連続記録を伸ばすと、お祝いの投稿が自動共有されます。

    ### サークルへ考えを共有する

    自動投稿に加えて、自分の考え、気持ち、近況を共有できます。

    1. **アクティビティ**タブで、**アクティビティを共有**をタップします。
    2. 投稿作成画面で次の操作を行えます。
       1. 共有する内容を書く。
       2. 🏞️で画像をアップロードするか、📷でカメラから撮影する。
    3. 右上の**投稿**をタップし、フィードへ共有します。

    ### サークル内の投稿へ反応する

    自動投稿かメンバーの投稿かにかかわらず、各投稿で次の操作を行えます。

    - **リアクションを送る：** リアクションボタンをタップし、応援、感謝、喜びなどを表す絵文字を選びます。
    - **コメントを残す：** 投稿をタップし、**返信を追加**へメッセージを書いて、↑をタップします。
    - **@メンションする：** コメント内で同じサークルの_@メンバー_を指定し、注意を引いたり直接返信したりできます。

    ## メンバーへリマインダーを送る

    **チェックイン**機能を使うと、共有習慣を今日完了するよう、ほかのメンバーへ親しみのあるリマインダーを送れます。

    ![Circle Check In](/images/Circle-CheckIn.png "Circle Check In")

    送信手順は次のとおりです。

    1. サークルで**統計**タブを開きます。
    2. メンバーバーで、リマインダーを送りたい人のプロフィールをタップします。
    3. その人の習慣一覧から対象を探し、進捗ブロックマップの下にある**チェックイン**をタップします。

    メンバーの端末へすぐにプッシュ通知が届き、その習慣へのチェックインを促します。

    <Note>
      **チェックインリマインダーのルール**

      - **習慣ごとに1回：** 同じ人の同じ習慣へは、24時間に1回だけ送信できます。
      - **1人につき5回：** 1人へ送信できるのは24時間に最大5回、つまり最大5つの異なる習慣です。

      チェックインは前向きな支援のための機能です。友人が優しいリマインダーを必要としていそうなときに利用し、グループの勢いを保ちましょう。
    </Note>

    ## **よくある質問**

    <Accordion title="**良い習慣をサークルへ共有できない場合はどうすればよいですか？**">
      良い習慣を共有できない場合、一時的な接続問題の可能性があります。次を試してください。

      - **インターネット接続を確認する。**
      - **Habitifyアプリを完全に閉じて開き直し**、再同期する。
      - **端末を再起動する。**

      それでも共有できない場合は、**設定 → お問い合わせ**から習慣の詳細とサークル名を添えてサポートチームへご連絡ください。
    </Accordion>

    <Accordion title="**悪い習慣をサークルへ共有できないのはなぜですか？**">
      サークルは、前向きな行動と成長を一緒に実践する考え方に基づきます。進捗、モメンタムポイント、一体感の連続記録は、メンバーの実行と完了から計算されます。

      - **良い習慣**は行動することが目標で、完了するとサークルの成功へ貢献します。
      - **悪い習慣**は_避けること_や_行動しないこと_が目標で、何かをしないことで成功します。

      「行動しない」という考え方は積極的な共同貢献の仕組みに合わないため、共有できるのは良い習慣だけです。

      **解決方法：** グループで悪い習慣をやめたい場合は、前向きな「良い習慣」として言い換えてください。

      - 「_ジャンクフードを食べない_」の代わりに「_健康的な間食をする_」を作成して共有する。
      - 「_喫煙しない_」の代わりに「_呼吸エクササイズをする_」を作成して共有する。
    </Accordion>

    <Accordion title="**完了記録がサークルの一体感の連続記録へ反映されない場合はどうすればよいですか？**">
      次の2つの理由が考えられます。

      - 習慣が日次目標ではない。**週、月、年単位の目標**を持つ習慣の完了は、一体感の連続記録へ反映されません。
      - 習慣を今日サークルへ共有した。全メンバーが新しい共有習慣を確認して始められるよう、新しい習慣の計算は追加した翌日から始まります。
    </Accordion>

    <Accordion title="**Web・デスクトップアプリでは、どこからサークルへアクセスできますか？**">
      サークルはまだWeb・デスクトップアプリに対応していません。現在利用できるのはスマートフォンとタブレットです。
    </Accordion>
