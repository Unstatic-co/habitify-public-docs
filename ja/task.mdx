---
title: "タスク"
---

タスクは、特定の習慣に追加できる小さな1回限りの作業です。習慣の主な目標とは別ですが、その習慣に関連付けられます。たとえば、「読書」習慣を始める前に本を受け取る、初めてジムへ行く前に用具を買うなど、習慣そのものを複雑にせず、周辺の小さな準備を残すために使えます。

タスクは、関連付けられた習慣と違って繰り返しません。一度作成し、一度完了すれば終了です。

## タスクとチェックリストの違い

どちらも習慣の中にありますが、用途が異なります。

- **タスク**：1回限りの作業です。作成し、一度完了すれば終了します。
- **チェックリスト：** 習慣を行うたびにリセットされ、毎回適用される繰り返し可能な手順です（例：「朝のルーティン」習慣内の決まったチェックリスト）。

1回だけ必要なことにはタスクを、習慣とともに繰り返すことにはチェックリストを使用します。

    ## タスクを追加する

    1. _ジャーナル_で、習慣をタップします。
    2. _個別進捗画面_で、右上の**•••**をタップします。
    3. **この習慣について**を選択します。
    4. **タスク**で、**新しいタスク**をタップします。
    5. タスク名を入力し、タスクの日付と時刻を設定します。
    6. 最後に、キーボードの**✓**または**↵**をタップして新しいタスクを保存します。

    ## タスクを完了する

    1. **ジャーナル**で、習慣をタップします。
    2. 個別進捗画面で、右上の**•••**をタップします。
    3. **この習慣について**を選択します。
    4. **タスク**で、タスクの前にある〇をタップして完了にします。

    完了にすると、次回この画面を開いたときに一覧から削除されるため、習慣のページには未完了の項目だけが表示されます。

    ## タスクを削除する

    未完了のタスクを削除するには、次の操作を行います。

    1. **ジャーナル**で、習慣をタップします。
    2. 個別進捗画面で、右上の**•••**をタップします。
    3. **この習慣について**を選択します。
    4. **タスク**でタスクを左へスワイプし、**削除**を選択します。

  <Tab title="🤖 Android">
    <iframe src="https://drive.google.com/file/d/1uBD1MLY1rRxqiJ3l0QzAdk2YavbKeQNY/preview" width="640" height="360" />

    ## タスクを追加する

    1. **ジャーナル**で、習慣をタップして個別進捗画面を開きます。
    2. 個別進捗画面で、**概要**タブへ切り替えます。
    3. **タスク**で、**新しいタスク**をタップします。
    4. タスク名を入力し、キーボードの**完了**をタップして保存します。
    5. タスクをダブルタップすると、日付と時刻を編集できます。

    ## タスクを完了する

    1. **ジャーナル**で、習慣をタップして個別進捗画面を開きます。
    2. 個別進捗画面で、**概要**タブへ切り替えます。
    3. **タスク**で、タスクの横にある**〇**をタップして完了にします。

    タスクを終えたら、習慣の**概要**タブから直接完了として記録します。

    ## タスクを削除する

    1. **ジャーナル**で、習慣をタップして個別進捗画面を開きます。
    2. 個別進捗画面で、**概要**タブへ切り替えます。
    3. **タスク**でタスクを左へスワイプし、**削除**を選択します。

    ## すべてのタスクを確認する

    タスクを完了にしても、その記録は削除されません。完了した内容はいつでも振り返れます。

    1. 習慣の個別進捗画面で、右上の**（⋮）ボタン**をタップします。
    2. **アクションリストを管理**をタップして開きます。

    通常の進捗とともに、習慣を支えるために行った操作と、まだ保留中の操作を一覧で確認できます。

    ## タスクを追加する

    1. 習慣一覧から、習慣の個別進捗画面を開きます。
       1. **グリッド**：習慣を1回クリックします。
       2. **リスト**：習慣をダブルクリックします。
    2. 個別進捗画面の右上にある**サイドバー切り替えボタン**をクリックします。
    3. 右側のサイドバーで、**概要**をクリックします。
    4. **アクションリスト**で、**新しいアクションを追加**をクリックして新しいタスクを入力し、キーボードのEnterキーを押して保存します。
    5. タスクの下にある**明日 09:00**をクリックして、タスクの期限を調整します。

    ## タスクを完了する

    1. 習慣一覧から、習慣の個別進捗画面を開きます。
       1. **グリッド**：習慣を1回クリックします。
       2. **リスト**：習慣をダブルクリックします。
    2. 個別進捗画面の右上にある**サイドバー切り替えボタン**をクリックします。
    3. 右側のサイドバーで、**概要**をクリックします。
    4. **アクションリスト**で、タスクの前にある〇をクリックして完了にします。

    ## タスクを削除する

    1. 習慣一覧から、習慣の個別進捗画面を開きます。
       1. **グリッド**：習慣を1回クリックします。
       2. **リスト**：習慣をダブルクリックします。
    2. 個別進捗画面の右上にある**サイドバー切り替えボタン**をクリックします。
    3. 右側のサイドバーで、**概要**をクリックします。
    4. **アクションリスト**でタスクの右側にある•••をクリックし、**アクションを削除**を選択します。
