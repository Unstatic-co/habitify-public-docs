---

Habitifyには習慣そのものに加え、通知のタイミング、週の表示、チェックイン時の見た目や音など、日々のアプリの動作を決める設定があります。すべて**設定**から変更できます。

<Tabs>
  <Tab title=" iOS">
    ## **ジャーナル**

    ![App Behaviour Journal I OS 1](/images/AppBehaviour-Journal-iOS-1.png "App Behaviour Journal I OS 1")

    「ジャーナル」という標準名を、「Janeのビジョン」、モットーなど、好きな名前へ変更できます。表示名だけが変わり、機能には影響しません。

    ## 週の開始日

    ![App Behaviour First Day I OS](/images/AppBehaviour-FirstDay-iOS.png "App Behaviour First Day I OS")

    週の開始日は**日曜日**または**月曜日**に設定できます。

    1. **設定**を開き、_アプリの動作_の**週の開始日**をタップします。
    2. **日曜日**または**月曜日**を選びます。
    3. 左上の❮をタップして保存します。

    週次習慣は選んだ曜日にリセットされ、個別進捗画面のカレンダーも同じ週構成で表示されます。

    ## Appアイコンのバッジ

    ![App Behaviour Appbadge I OS](/images/AppBehaviour-Appbadge-iOS.png "App Behaviour Appbadge I OS")

    Habitifyのアイコンに、未完了の習慣数を表示します。

    1. **設定 → アプリの動作 → Appアイコンのバッジ**を開きます。
    2. 次から選びます。
       1. **必要なすべての習慣：** 「すべての習慣」にある未完了の進行中習慣の総数。
       2. **時間帯に基づく：** 現在の時間帯に該当する未完了の習慣数。
       3. **オフ：** バッジを無効にします。
    3. 左上の❮をタップして保存します。

    ## 通知

    ![App Behaviour Notification I OS](/images/AppBehaviour-Notification-iOS.png "App Behaviour Notification I OS")

    朝の開始と夜の締めくくりを知らせる毎日の概要通知を管理できます。

    1. **設定 → アプリの動作 → 通知**を開きます。
    2. スヌーズ時間を設定します。
    3. _毎日の概要_の**朝**と**夜**について、受け取る通知をオンにし、時刻をタップして調整します。
    4. 左上の❮をタップして保存します。

    ## 時間帯

    <iframe src="https://drive.google.com/file/d/1Z5ghdzaL-DicVDK7FaDQgGK8zj5dBcD3/preview" width="640" height="360" />

    1日を朝、午後、夜などの時間ブロックに分け、習慣の「時間帯」で選べる項目を管理します。ジャーナルでは現在時刻に応じて該当する時間帯へ切り替わり、習慣が絞り込まれます。

    ### 既存の時間ブロックを編集する

    1. **設定 → アプリの動作 → 時間帯**で対象を選びます。
    2. アイコンと名前、_スケジュール_の**開始**と**終了**を変更します。
    3. _含める_の➖で習慣を外し、☰をドラッグして順序を変えます。_除外_の➕で習慣を追加します。
    4. 右上の✓でブロックを保存し、もう一度✓をタップして時間帯設定全体を保存します。

    ### 新しい時間ブロックを追加する

    1. **設定 → アプリの動作 → 時間帯**で**＋ さらに追加…**をタップします。
    2. アイコン、名前、開始・終了時刻を設定し、必要に応じて_除外_から習慣を追加します。
    3. 右上の✓でブロックを保存し、もう一度✓をタップして設定全体を保存します。

    <Note>
      **Habitifyは0:00（深夜0時）を含むブロックを必ず先頭へ並べます。**

      「夜」が**23:00〜05:00**の場合、日付をまたいで0:00を含むため一覧の先頭になります。ジャーナルでの習慣の流れには影響しません。
    </Note>

    <Note>
      **24時間ルール**

      1日のどの時刻も、必ずいずれかのブロックに属する必要があります。たとえば「朝」を短くすると「午後」が自動的に広がります。「朝」を10時で終了し「午後」を12時から始めるなど、空白ができる変更は保存できません。
    </Note>

    <Note>
      エラーなく設定するには、**先にすべてのブロックを作成し、後から時間を調整**してください。朝など1日の最初から順に変更すると、余った時間が次のブロックへ移り、調整しやすくなります。
    </Note>

    ### 時間ブロックを削除する

    1. **設定 → 時間帯**で対象を右へスワイプし、**削除**をタップします。
    2. 右上の✓を2回タップし、ブロックと時間帯設定全体を保存します。

    <Note>
      時間帯ブロックは常に**1つ以上**必要です。最後の1つは削除できません。
    </Note>

    <Note>
      **時間帯は一覧の絞り込みと整理だけに使われます。** 習慣のリセット時刻は変わりません。目標の種類に応じて、新しい日、週、月、年の0:00に一覧と目標が更新されます。
    </Note>

    <Note>
      時間帯の「朝」「夜」とは別に、進捗記録とメモには追加時点のデバイスの正確な日時が保存されます。
    </Note>

    ## アプリ内サウンド

    習慣を完了したときなどに、小さな操作音で視覚的な変化を補います。**設定 → アプリの動作 → 通知**で、トグルをオンにすると有効、オフにすると無効になります。

    ## アプリのテーマ

    デバイスのテーマをライトまたはダークへ変更すると、Habitifyもそれに従います。デバイス全体と一貫した表示になります。

    ## アプリの言語

    Habitifyは次の言語に対応しています。

    - **基本言語：** 英語（米国）
    - **ヨーロッパの言語：** カタルーニャ語、チェコ語、デンマーク語、オランダ語、フィンランド語、フランス語、ドイツ語、ハンガリー語、イタリア語、ノルウェー語、ポーランド語、ポルトガル語（ポルトガル／ブラジル）、ルーマニア語、ロシア語、スロバキア語、スペイン語、スウェーデン語、ウクライナ語。
    - **アジアの言語：** 中国語（簡体字／繁体字）、ヒンディー語、韓国語、日本語、ベトナム語、トルコ語。

    iPhoneまたはiPadで言語を変更するには、現在の言語とは別の言語パックを1つ以上デバイスへ追加します。

    <Steps>
      <Step title="デバイスへ新しい言語を追加する">
        - **設定 → 一般 → 言語と地域 → ほかの言語**を開きます。
        - 追加する言語を選び、ポップアップで**［現在の言語］を使用**を選びます。
      </Step>
      <Step title="Habitifyの言語を変更する">
        - **設定**を開いてHabitifyまでスクロールします。
        - _優先する言語_の**言語**を選び、使用する言語を選びます。
      </Step>
    </Steps>

    ## シェイクで取り消す

    直前の誤操作を、スマートフォンを振ってすぐに取り消すショートカットです。

    ### **仕組み**

    誤ってチェックマークをタップした直後にスマートフォンを軽く振ると、直前の操作を取り消すポップアップが表示されます。**取り消す**をタップすると、チェックインや記録が元に戻ります。

    複数の操作は、実行した順序と逆に1つずつ取り消されます。習慣A、習慣Bの順に完了した場合、1回目でB、2回目でAが元に戻ります。

    ### **制限**

    取り消し状態は一時的です。Habitifyを閉じる、別の画面へ移動する、ログアウトする、といった操作後は、それ以前の操作を振って取り消せません。

    <Note>
      画面を移動してシェイクを使えなくなった場合は、記録履歴から誤った記録を手動で削除してください。
    </Note>

    ### 有効／無効にする

    1. デバイスの**設定 → アクセシビリティ → タッチ**を開きます。
    2. **シェイクで取り消し**を探し、オフで無効、オンで有効にします。

    <Note>
      この設定を無効にすると、Habitifyだけでなくスマートフォン上のすべてのアプリで「シェイクで取り消し」がオフになります。
    </Note>

    ## プライバシーロック

    ![App Behaviour Privacy Lock Android](/images/AppBehaviour-PrivacyLock-Android.png "App Behaviour Privacy Lock Android")

    Habitify自体へパスコードを設定し、ほかの人がスマートフォンを手に取っても習慣データを保護します。有効にすると、アプリを開くたびに入力を求められます。

    1. **設定 → アプリの動作 → プライバシーロック**を開きます。
    2. **プライバシーロックを有効化**をオンにし、4桁のコードを入力します。コードは自動保存されます。
    3. 左上の←をタップして戻ります。

    同じ画面で、トグルをオフにして現在のコードを入力すると無効化できます。**パスコードを変更**から新しいコードも設定できます。

    ## 週の開始日

    ![App Behaviour First Day Android](/images/AppBehaviour-FirstDay-Android.png "App Behaviour First Day Android")

    **設定 → アプリの動作 → 週の開始日**で、**日曜日**または**月曜日**を選びます。週次習慣のリセット日と個別進捗画面のカレンダーが、この設定に従います。

    ## 通知

    ![App Behaviour Notification Android](/images/AppBehaviour-Notification-Android.png "App Behaviour Notification Android")

    **設定 → アプリの動作 → 通知**でスヌーズ時間を設定し、_毎日の概要_の**朝**と**夜**をオンにします。_通知時刻_をタップして時刻を変更し、左上の←で保存します。

    ## **時間帯**

    <iframe src="https://drive.google.com/file/d/1lEggXoVdb6FhW2YDqtq1X_uf7JCSrflQ/preview" width="640" height="360" />

    朝、午後、夜などの時間ブロックを設定します。ジャーナルでは現在時刻に応じて該当する時間帯へ切り替わり、習慣が絞り込まれます。

    ### 既存の時間ブロックを編集する

    1. **設定 → アプリの動作 → 時間帯**で対象を選びます。
    2. アイコン、名前、_スケジュール_の開始・終了を変更します。
    3. _含める_の×で習慣を外し、⚌をドラッグして順序を変えます。_除外_の➕で習慣を追加します。
    4. 右上の**保存**をタップし、←で時間帯設定全体を保存します。

    ### 新しい時間ブロックを追加する

    **設定 → アプリの動作 → 時間帯 → ＋ 新規追加**を開き、アイコン、名前、開始・終了時刻、含める習慣を設定します。**保存**をタップし、←で設定全体を保存します。

    <Note>
      **0:00を含むブロックは常に先頭です。** 「夜」が23:00〜05:00の場合は日付をまたぐため先頭になりますが、ジャーナルでの流れには影響しません。
    </Note>

    <Note>
      **24時間ルール：** どの時刻も必ずいずれかのブロックに属します。「朝」を短くすると「午後」が自動的に広がり、空白ができる変更は保存できません。
    </Note>

    <Note>
      先にすべてのブロックを作成し、後から1日の最初から順に時間を調整すると、エラーなく設定しやすくなります。
    </Note>

    ### 時間ブロックを削除する

    **設定 → 時間帯**で対象を開き、一番下の**削除**をタップしてもう一度確定します。時間帯画面へ戻り、←をタップして変更を保存します。

    <Note>
      時間帯ブロックは常に**1つ以上**必要で、最後の1つは削除できません。
    </Note>

    <Note>
      **時間帯は一覧の絞り込みと整理だけに使われます。** 習慣のリセット時刻は変わらず、目標の種類に応じて日、週、月、年の0:00に更新されます。
    </Note>

    <Note>
      進捗記録とメモには、時間帯の区分とは関係なく、追加時点のデバイスの正確な日時が保存されます。
    </Note>

    ## アプリの言語

    Android版Habitifyは、スマートフォンの言語一覧で最初に見つかる対応言語を使用します。

    対応言語は、英語（米国）、カタルーニャ語、チェコ語、デンマーク語、オランダ語、フィンランド語、フランス語、ドイツ語、ハンガリー語、イタリア語、ノルウェー語、ポーランド語、ポルトガル語（ポルトガル／ブラジル）、ルーマニア語、ロシア語、スロバキア語、スペイン語、スウェーデン語、ウクライナ語、中国語（簡体字／繁体字）、ヒンディー語、韓国語、日本語、ベトナム語、トルコ語です。

    ## シェイクで取り消す

    Android版Habitifyに標準搭載された機能です。誤操作の直後にスマートフォンを振り、表示された**取り消す**をタップすると、直前のチェックインや記録が元に戻ります。

    ### **仕組み**

    複数の操作は逆順に1つずつ取り消されます。習慣A、習慣Bの順に完了した場合、1回目でB、2回目でAが元に戻ります。

    ### **制限**

    取り消し状態は一時的です。アプリを閉じる、別の画面へ移動する、ログアウトする、といった操作後は使えません。

    <Note>
      画面を移動してシェイクを使えなくなった場合は、記録履歴から誤った記録を手動で削除してください。
    </Note>

    ## テーマ

    - **ライト：** 常に明るいテーマを使用します。
    - **ダーク：** 常に黒い背景のダークテーマを使用します。
    - **システム：** コンピューターのテーマに自動的に合わせます。

    ## 週の開始日

    **日曜日**または**月曜日**を選びます。週次習慣のリセット日と、進捗画面の週単位表示に反映されます。

    ## 言語

    言語のドロップダウンからアプリ表示に使う言語を選びます。英語（米国）のほか、ヨーロッパおよびアジアの各対応言語（中国語簡体字、ヒンディー語、韓国語、日本語、ベトナム語、トルコ語など）を利用できます。
