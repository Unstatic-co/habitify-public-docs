チャレンジは、グループで習慣を身につけるための期間限定の取り組みです。1人で記録する代わりに、決められた期間、ほかの参加者と一緒に同じ目標へ取り組み、競い合ったり励まし合ったりできます。

この記事では、ほかの人とチャレンジを始めるために必要な内容を詳しく説明します。

## チャレンジとサークルの比較

![Challenge Vs Circle](/images/Challenge-vs.-Circle.png "Challenge Vs Circle")

|  | **チャレンジ** | **サークル** |
| :-- | :-- | :-- |
| **期間** | 開始日と終了日が決まった期間限定 | 終了日はなく、オーナーがアーカイブまたは削除するまで継続 |
| **記録する習慣** | チャレンジごとに共通の習慣目標を1つ設定 | 複数の習慣を同時に共有し、各メンバーが自分の習慣を設定 |
| **統計要素** | <ul><li>**連続記録ランキング**では、完了日ごとのポイントで参加者を順位付けし、未達成日には任意の減点を設定できます。</li><li>**チーム連続記録**は、全メンバーが当日のチャレンジ習慣を完了すると増えます。</li></ul> | <ul><li>**一体感の連続記録**は、全メンバーが当日に予定された共有の日次習慣を1つ以上完了すると増えます。</li><li>**モメンタムポイント**は共有習慣を完了すると増え、メンバーごとのポイント順位も任意で確認できます。</li></ul> |
| **進捗の編集** | 当日の記録後はロックされ、過去日の追加記録や変更は不可。<br />スキップ回数は無制限、オフモードに対応 | ジャーナルで後から変更した内容も習慣の進捗へ反映。<br />スキップ回数には制限があり、オフモードに対応 |
| **グループ人数** | 無制限 | 無制限 |
| **交流** | アクティビティタブ：リアクション、コメント、@メンション、継続的な会話 | アクティビティタブ：リアクション、コメント、@メンション、継続的な会話 |
| **対応プラットフォーム** | iOS、Android | iOS、Android |

    ## チャレンジを主催する

    ### 新しいチャレンジを作成する

    1. Habitifyアプリで**フレンド**タブを開きます。
    2. **＋**ボタンをタップし、**チャレンジ**を選びます。
    3. チャレンジの詳細を設定します。
       ![Challenge Info](/images/Challenge-Info.png "Challenge Info")
       1. **背景を選択**をタップし、**おすすめ**、**Unsplash**、または**写真**からカバー画像を選びます。
       2. **チャレンジ名**の入力欄へ、「30日間のマインドフルネス」「早起きクラブ」など、分かりやすく意欲が湧く名前を入力します。
       3. 名前の下で、チャレンジ内のボタンや操作要素に使う色を選びます。
       4. **＋短い説明を追加**をタップし、内容、参加者が期待できること、参加する理由などを入力します。
    4. チャレンジのルールを設定します。
       ![Challenge Rule](/images/Challenge-Rule.png "Challenge Rule")
       - **期間：** 7、14、21、30、45、60、90日のプリセットから選ぶか、**カスタム**で任意の期間を設定します。
       - **最低目標：** 使用できる記録方法と、各メンバーが約束する最低値を設定します。
         - **使用可能な記録方法：** 手動記録と、ヘルス＆ウェルネスアプリ（Apple Health、Fitbit、Strava、Health Connect）からの自動記録を選べます。
           ![Challenge Rule Goal1](/images/Challenge-Rule-Goal1.png "Challenge Rule Goal1")
         - **対象アクティビティ：** 選択した記録方法に応じて、利用できるアクティビティが一覧表示されます。
           ![Challenge Rule Goal2](/images/Challenge-Rule-Goal2.png "Challenge Rule Goal2")
         - **日次の最低目標を設定：** 各メンバーが取り組む基準を設定します。利用できる目標単位も、選んだ記録方法によって異なります。
           ![Challenge Rule Goal3](/images/Challenge-Rule-Goal3.png "Challenge Rule Goal3")
       - **難易度：** 競争の厳しさとポイント計算を設定します。
         ![Challenge Rule Difficulty Level](/images/Challenge-Rule-DifficultyLevel.png "Challenge Rule Difficulty Level")
         - **フレンドリー：** 完了 ＋100、スキップ ＋0、失敗 －0
         - **競争：** 完了 ＋100、スキップ ＋0、失敗 －50
         - **ハードコア：** 完了 ＋100、スキップ ＋0、失敗 －150
       - **許可するスキップ回数：** 連続記録を維持したまま1日をスキップできる回数を決めます。
    5. 右上の**完了**をタップし、チャレンジを保存します。

    ### 自分のチャレンジへ参加を確約する

    ![Challenge Commit](/images/Challenge-Commit.png "Challenge Commit")

    主催者として最初に参加し、取り組みを確約します。

    1. **フレンド**タブで、作成したチャレンジを開きます。
    2. 下へスクロールし、**日次目標を確約する**をタップします。
    3. チャレンジの最低目標以上となる、自分の日次目標を入力します。
    4. **署名**し、**ボタンをスライド**して確約します。

    ### チャレンジへ参加者を招待する

    チャレンジを開始するには、目標を確約したメンバーが、オーナーを含めて2人以上必要です。

    ![Challenge Sharing](/images/Challenge-Sharing.png "Challenge Sharing")

    参加者を招待する手順は次のとおりです。

    1. チャレンジを開き、**＋メンバーを招待**をタップします。
    2. 共有ポップアップで次の方法から選びます。
       - **メッセージ：** メッセージアプリから直接送信します。
       - **リンクを共有：** システムの共有機能で、連絡先、SNS、メールアプリなどへ送信します。
       - **リンクをコピー：** URLをクリップボードへコピーし、任意の場所へ貼り付けます。\
    3. 主催者は**自動承認**で参加者を管理できます。
       - **オン：** 承認なしですぐに参加できます。
       - **オフ：** 参加を許可する人を自分で決めます。

    ### チャレンジの参加者を管理する

    **自動承認**を無効にすると、招待リンクを開いた人は参加リクエストを送る必要があります。リクエストは次の場所から確認できます。

    - 新しいリクエストの通知をタップする、または
    - チャレンジ内で、承認待ちの人がいることを示すバナーをタップします。

    ![Challenge Pendingrequest](/images/Challenge-Pendingrequest.png "Challenge Pendingrequest")

    共有オプションの**承認待ち**セクションで、次の操作を行います。

    - 許可する場合は**承認**をタップします。
    - 参加させない場合は**拒否**をタップします。

    ![Challenge Pending Request2](/images/Challenge-PendingRequest2.png "Challenge Pending Request2")

    ### チャレンジを開始する

    チャレンジのオーナーが開始の合図を出します。

    1. 作成済みで、まだ始まっていないチャレンジを開きます。
    2. 名前と説明のすぐ下にある**チャレンジを開始**をタップします。

    ![Challenge Start](/images/Challenge-Start.png "Challenge Start")

    チャレンジはすぐに始まり、設定した期間から算出された終了日の**23:59:59**まで続きます。開始すると、全メンバーへプッシュ通知が送信されます。

    <Note>
      チャレンジを始めるには、参加して目標を確約したメンバーが2人以上必要です。
    </Note>

    ## チャレンジへ参加する

    Habitifyチャレンジの招待リンクを受け取ったら、次の手順で参加します。

    1. Habitifyアプリをインストールし、アカウントへログインします。
    2. 招待リンクをタップすると、アプリでチャレンジが直接開きます。
    3. チャレンジのルールを確認します。
       ![Challenge Join](/images/Challenge-Join.png "Challenge Join")
       - **チャレンジ名と説明：** 内容と、主催者が参加者へ期待することを確認します。
       - **チャレンジのルール：**
         - **期間：** 継続期間（例：30日）。
         - **最低目標：** 毎日達成する目標（例：「20ページ読む」）。
         - **許可するスキップ回数：** 利用できる休息日の回数。
       - **メンバー：** すでに参加している人を確認します。
    4. 名前と説明の下にある**確約して参加**をタップし、次の操作を行います。
       ![Challenge User Commit](/images/Challenge-UserCommit.png "Challenge User Commit")
       - **日次目標を設定：** 主催者が設定した**最低目標以上**となる目標を入力します。
       - **確約へ署名：** 画面下部へ署名します。
       - **スライドして確認：** ボタンをスライドし、参加を確定します。

    これで準備完了です。主催者が開始するまで待ちます。開始時にはプッシュ通知が届きます。

    ## チャレンジと連携する習慣を追加する

    チャレンジが始まると、主催者を含む全参加者は、チャレンジと連携した習慣をジャーナルの日次一覧へ追加する必要があります。これにより、忘れずに取り組み、進捗を簡単に記録できます。

    1. アプリを開き、チャレンジへアクセスします。
    2. **参加する準備はできましたか？**で、**習慣を作成**をタップします。
       ![Challenge Create Habit](/images/Challenge-CreateHabit.png "Challenge Create Habit")
    3. このチャレンジ専用の新しい習慣を設定する画面が開きます。
       1. **目標**をタップし、希望する記録方法を選びます。選択肢は主催者の設定に基づきます。
          ![Challenge Set Challenge Habit](/images/Challenge-SetChallengeHabit.png "Challenge Set Challenge Habit")
       2. **保存**をタップして習慣を保存します。

    <Note>
      チャレンジ習慣では、次の設定が適用されます。

      - **繰り返し**は初期状態で「毎日」となり、**開始日**と**終了条件**はチャレンジ期間に従います。
      - **目標**は変更できますが、チャレンジの最低目標以上である必要があります。
    </Note>

    ## チャレンジの進捗を記録する

    チャレンジ習慣の進捗は、次の2つの方法で記録できます。

    ### **ジャーナルの一覧から記録する**

    チャレンジ習慣は個人の習慣と一緒に**ジャーナル**のメイン一覧へ表示され、ほかの習慣と同じ方法で記録できます。

    1. **ジャーナル**でチャレンジ習慣を探します。
       ![Challenge Habit Challenge](/images/Challenge-HabitChallenge.png "Challenge Habit Challenge")
    2. _手動記録_を選んだ場合は、次の方法を利用できます。
       - **右へスワイプ**して、完了または進捗を記録します。
       - **左へスワイプ**して、スキップまたは失敗にします。
       - 習慣の横にある**スマートボタン**を使います。
    3. 別のアプリとの同期を選んだ場合、ヘルスケアアプリのデータから進捗が自動更新されます。

    ### **チャレンジの統計から記録する**

    チャレンジを開いている場合は、**統計**タブから記録できます。

    - **統計**タブの**今日の概要**で、**自分の進捗を記録**をタップします。
      ![Challenge Log Progress](/images/Challenge-LogProgress.png "Challenge Log Progress")
    - 進捗値を入力するか、**スキップ**または**失敗**を選びます。
    - 最後にスライドして記録を保存します。

    ## チャレンジの統計を見る

    Habitifyのチャレンジは、個人の努力だけでなく、グループ全体の進捗を一緒に確認するものです。**統計**タブのダッシュボードでは、チーム連続記録からランキングまで、チャレンジの詳細を確認できます。

    ### **期間の進捗**

    最初の進捗バーは、チャレンジ全体の期間と、その中で現在が何日目かを示します。

    **例：** 30日間のチャレンジ開始から15日目の場合は「30日中15日目」と表示され、具体的な**終了日**（例：2026年1月1日）も確認できるため、目標達成までの残り時間が分かります。

    ### **今日の概要**

    当日のグループ活動をリアルタイムで確認でき、次の状態にあるメンバー数が表示されます。

    - 日次目標を**完了**した人。
    - その日を**スキップ**した人。
    - **休憩中**の人（オフモードを使用中）。
    - まだ目標を**完了していない**人（進行中または失敗を含む）。

    ### **ランキング**

    ランキングでは、メンバーの成績を**今日**または**全体**で順位付けします。

    **「今日」表示：**

    - **現在の進捗：** 各メンバーが当日に記録した量（例：「15/30分」）。
    - **個人の連続記録：** 各メンバーの現在の連続記録。

    ![Challenge Today Rank](/images/Challenge-TodayRank.png "Challenge Today Rank")

    **「全体」表示：**

    - **合計ポイント：** チャレンジ初日から獲得した累計スコア。
    - **合計記録値：** 初日から記録したすべての活動の合計（例：「合計：450分」）。
    - **予想メダル：** これまでの成績に基づき、現在獲得が予想される金、銀、銅メダル。

    ![Challenge Overall Ranking 1](/images/Challenge-OverallRanking-1.png "Challenge Overall Ranking 1")

    参加者全員の順位は、公平に決めるため次の基準を使います。

    1. **第1基準：合計ポイント。** 最もスコアが高いメンバーが1位です。
    2. **同点時の第1基準：合計記録値。** ポイントが同じ場合、記録した合計量が多い人を上位とします。
    3. **同点時の第2基準：最後に記録した時刻。** ポイントと記録値も同じ場合、習慣を**早く**完了した人が上位です。

    **「全体」ランキングのメダル**は、チャレンジで進捗を残したメンバーの努力を称えるものです。

    ![Challenge Vs Circle (2)](/images/Challenge-vs.-Circle-\(2\).png "Challenge Vs Circle (2)")

    - 🥇 **金メダル：** **ランキング1位**のメンバー。
    - 🥈 **銀メダル：** 次に成績のよい**40%**のメンバー。
    - 🥉 **銅メダル：** 残りのメンバー。

    ### **チーム連続記録**

    ![Challenge Team Streak&point](/images/Challenge-TeamStreak&Point.png "Challenge Team Streak&point")

    **チーム連続記録**は、グループ全体で何日連続して成功できたかを表します。

    **次の場合に1日増えます：**

    - **全員が完了：** 全メンバーが当日中に、確約した日次目標を達成し、当日のチャレンジ習慣を完了にする。
    - **一部が完了（失敗者なし）：** 一部が完了し、残りはスキップまたはオフモードを利用し、未完了や失敗の人が**1人もいない**。

    **次の場合に0へリセットされます：**

    - **1人でも失敗：** 目標を達成できず、スキップやオフモードも使っていないメンバーが1人でもいる場合。

    ### **合計ポイント**

    チャレンジの全メンバーが獲得したポイントの合計で、グループ全体の努力と成功を表します。計算方法はチャレンジの難易度で設定されます。

    ## メンバーの進捗を見る

    Habitifyのチャレンジでは、任意の参加者の詳しい進捗を開き、現在の順位、連続記録の履歴、日ごとの記録を確認できます。

    1. チャレンジで**統計**タブを開きます。
    2. **ランキング**までスクロールし、確認するメンバーの名前をタップします。

    メンバーをタップすると、**今日**、**全体の成績**、**進捗履歴**の3セクションに分かれた個人進捗画面が表示されます。

    ### 今日

    ![Challenge Personal Progress1](/images/Challenge-PersonalProgress1.png "Challenge Personal Progress1")

    - **今日の進捗：** 進捗バーには、当日の記録と確約した日次目標との比較（例：「5,000 / 10,000 m」）が表示されます。
    - **現在の連続記録：** 炎のアイコンには、このチャレンジ習慣で現在継続している日数が表示されます。

    ### **全体の成績**

    - **合計ポイント：** 完了による加点とペナルティに基づく累計スコア。
    - **順位：** ランキングでの現在の位置。
    - **合計記録：** 開始以降に記録した合計量または合計回数。

    ### **進捗**

    ![Challenge Personal Progress 1](/images/Challenge-PersonalProgress-1.png "Challenge Personal Progress 1")

    **進捗**セクションでは、開始日以降の月ごとの継続状況を詳しく確認できます。

    - **概要：** 次の3つのステータスの合計が表示されます。
      - **成功：** 目標を完全に達成した日。
      - **スキップ：** スキップとして記録した日。
      - **失敗：** 目標を達成できなかった日。
    - **ブロックマップ：** 月ごとの履歴をグリッドで示します。
      - **塗りつぶされた四角：** 完了に成功。
      - **赤い（×）丸：** 失敗した日。
      - **矢印（→）アイコン：** スキップした日。
      - **休暇アイコン：** その日に[<u>オフモード</u>](https://intercom.help/habitify-app/en/articles/6095980-welcome-to-habitify-the-introduction)を使用していたことを示します。

    ## チャレンジのアクティビティを見る

    チャレンジは競争であるだけでなく、活発なコミュニティでもあります。その中心となる**アクティビティ**タブは、自分とほかのチャレンジメンバーだけが利用できる非公開のソーシャルフィードです。

    ![Challenge Activities](/images/Challenge-Activities.png "Challenge Activities")

    ### 最新情報を確認する

    **アクティビティ**タブでは、重要な出来事が自動更新されます。次のイベントが起きると、システムが投稿を作成します。

    - 新しいメンバーがチャレンジへ参加したとき。
    - メンバーが当日の目標を完了し、現在の連続記録を伸ばしたとき。

    ### 考えを共有する

    自動投稿に加えて、自分の考え、気持ち、近況をグループへ共有できます。

    1. **アクティビティ**タブで、右下の**＋ボタン**をタップします。
    2. 投稿作成画面で次の操作を行えます。
       1. 共有する内容を書く。
       2. 🏞️で画像をアップロードするか、📷でカメラから撮影する。
    3. 右上の**投稿**をタップし、フィードへ共有します。

    ### ほかのメンバーと交流する

    アクティビティフィードの各投稿では次の操作を行えます。

    - **リアクションを送る：** リアクションボタンをタップし、応援、感謝、喜びなどを表す絵文字を選びます。
    - **コメントを残す：** 投稿をタップし、**返信を追加**へメッセージを書いて、↑をタップします。
    - **@メンションする：** コメント内で同じチャレンジの_@メンバー_を指定し、注意を引いたり直接返信したりできます。

    ## よくある質問

    <Accordion title="**チャレンジ習慣の過去日の進捗を記録するにはどうすればよいですか？**">
      通常の習慣と同じ方法で、チャレンジ習慣へ自由にチェックインできます。

      ただし、ランキングとチャレンジ全体の成績に努力を反映するには、必ずその日が終わる前に進捗を記録する必要があります。
    </Accordion>

    <Accordion title="**チャレンジ習慣を削除するとどうなりますか？**">
      チャレンジ習慣を削除すると、すべての進捗が完全に削除され、復元できません。続ける場合は新しいチャレンジ習慣を作成する必要があり、進捗は再開した日から数えられます。
    </Accordion>

    <Accordion title="**チャレンジを編集するにはどうすればよいですか？**">
      **まだ始まっていない場合**は、詳細とルールを変更できます。

      - チャレンジを開き、右上の🖊をタップします。
      - **チャレンジを編集**で、名前、色、説明、背景、ルールを変更します。
      - **完了**をタップして保存します。

      **すでに始まっている場合**は、詳細だけを編集できます。

      - チャレンジを開き、**概要**タブへ切り替えます。
      - 一番下までスクロールし、**チャレンジを編集**をタップします。
      - 名前、色、説明、背景を変更します。
      - **完了**をタップして保存します。
    </Accordion>

    <Accordion title="**チャレンジから参加者を削除するにはどうすればよいですか？**">
      現在、チャレンジから参加者を削除する方法はありません。招待リンクをほかの人へ送ったり公開したりする前に、**自動承認**の設定を慎重に検討してください。
    </Accordion>
  </Tab>
  <Tab title="Web・デスクトップ">
    チャレンジの設定と参加はスマートフォンアプリで行う必要がありますが、Web・デスクトップアプリでもチャレンジと連携した習慣を記録できます。

    連携している場合、習慣一覧では習慣名の下にチャレンジ名が表示されます。

    ![Challenge Website&desktop](/images/Challenge-Website&Desktop.png "Challenge Website&desktop")

    別のヘルスケアアプリと連携している場合、進捗は自動更新され、手動記録は不要です。

    手動記録を設定している場合は、通常の習慣と同じ方法で進捗やステータスを更新できます。

    - **グリッド表示：**
      - 今日のセルを選択し、下部の操作バーから完了、スキップ、失敗を選びます。
      - 今日のセルを右クリックし、メニューから操作を選びます。
    - **リスト表示：**
      - チャレンジ連携習慣を選択し、下部の操作バーから完了、スキップ、失敗を選びます。
      - チャレンジ連携習慣を右クリックし、メニューから操作を選びます。

    <Note>
      チャレンジの達成状況に反映されるのは、当日の進捗またはステータスの更新だけです。
    </Note>
  </Tab>
</Tabs>

<Accordion title="**Web・デスクトップアプリでは、どこからチャレンジへアクセスできますか？**">
  現在、チャレンジのスペースを利用できるのはスマートフォンとタブレットのアプリです。

  ただし、チャレンジと連携した習慣への進捗記録は、どの端末からでも行えます。
</Accordion>
