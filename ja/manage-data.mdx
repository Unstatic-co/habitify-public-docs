## Habitifyへデータをインポートする

新しいアプリを使い始めるときも、ほかのアプリやスプレッドシートで積み重ねた大切な記録は失いたくないものです。ここでは、過去のデータをHabitifyへ取り込み、これまでの歩みをまとめて確認する方法を説明します。

### **ヘルスデータをインポートする**

過去のフィットネスデータがApple Health、Health Connect、Fitbit、Stravaに保存されている場合は、この方法が最も簡単で自動的です。

**仕組み：** いずれかのサービスをHabitifyの習慣へ初めて接続すると、アプリが自動的に**過去データを同期**し、以前のアクティビティを習慣の記録へ取り込みます。

- **Apple Health／Health Connect：** iPhoneまたはAndroidスマートフォンから、歩数、ワークアウト、睡眠、マインドフル時間などを直接同期します。
- **Fitbit：** Fitbitデバイスから、毎日の歩数、睡眠、消費カロリーなどを自動的に記録します。
- **Strava：** ランニング、サイクリング、ウォーキングなどのワークアウトを完了後すぐに習慣へ同期します。

### Productiveアプリからインポートする

まずProductiveアプリからデータをエクスポートしてください。通常、Productiveは`.sqlite`ファイルとして出力します。このファイルをHabitifyへのインポートに使用します。

Habitifyアプリで、**設定 → データをインポート／エクスポート → Productiveからインポート**へ移動します。

エクスポートした`.sqlite`ファイルを選び、画面の案内に従ってインポートを完了します。

次の主要な習慣データが取り込まれます。

- **習慣：** 習慣の一覧。
- **習慣の記録：** 過去のチェックイン、スキップ、失敗。
- **時間帯：** 朝、午後、夜の設定。
- **習慣の説明：** 習慣に追加したメモや説明。
- **終了条件：** Productiveで設定した終了日。ただし、当日または過去の日付は対象外です（Habitifyでは終了日を7日以上先に設定する必要があります）。

<Note>
  **重要な注意事項：**

  - Productiveの**チャレンジ**と**プログラム**はインポートされません。個別の習慣だけが転送されます。
  - Productiveで**一時停止または停止**した習慣はHabitifyへインポートされますが、自動的に**アーカイブ済み**になります。必要に応じて後からアーカイブを解除できます。
</Note>

Productiveのスケジュールと目標は、次のようにHabitifyの形式へ自動変換されます。

- **毎日／特定の曜日／特定の日付：** Productiveで毎日、特定の曜日、または毎月の特定日に繰り返す習慣は、同じスケジュールを保ったHabitifyの**日次目標**になります。
- **1日に複数の目標：** 1日の中に複数の目標がある場合（「朝2回＋夜2回」など）、Habitifyでは合算して1つの日次目標（「1日4回」など）にします。
- **週間頻度（「週3回」など）：** 週間頻度と1回あたりの日次目標がある場合、両者を掛けて1つの**週間目標**へ変換します。<br />_例：_ Productiveの「週3回、1日20分」→ Habitifyの**「週60分」**。
- **隔週の特例：** Productiveの「2週間ごとに1回」のような間隔は直接インポートできないため、代わりにHabitifyの**日次目標**へ変換されます。インポート後に手動でスケジュールを調整してください。

### Streaksアプリからインポートする

まずStreaksアプリからデータをエクスポートしてください。通常は`.streaks`という専用ファイルが出力されます。

Habitifyアプリで、**設定 → データをインポート／エクスポート → Streaksからインポート**へ移動します。

エクスポートした`.streaks`ファイルを選び、画面の案内に従ってインポートを完了します。

次の主要なデータが取り込まれます。

- **習慣名：** 元の名前を保ちます。
- **繰り返しスケジュール：** 毎日、毎週、毎月などの頻度を変換します。
- **頻度を目標へ変換：** 「1日／週／月にX回」という目標を保ちます。
- **リマインダー：** 設定した時刻を取り込みます（詳細は後述）。
- **メモ：** 習慣に追加したメモをコピーします。
- **最初の記録日を開始日へ変換：** Streaksで最も古い記録の日付をHabitifyの開始日にします。
- **記録履歴：** 過去の完了、失敗、スキップを取り込みます。
- **悪い習慣：** やめる、または制限する習慣も取り込みます（詳細は後述）。

HabitifyとStreaksでは仕組みが異なるため、一部のデータはインポート時に変換されます。

**1／リマインダー**

Streaksで設定したリマインダー時刻は、そのままHabitifyへ同期されます。HabitifyにはStreaksの「自動リマインダー」に相当する機能がないため、自動リマインダーはインポートされません。

**2／記録履歴**

- **日次習慣：** 次のように変換されます。
  - Streaksの`Complete` → Habitifyの`Complete`
  - Streaksの`Failed` → Habitifyの`Failed`
  - Streaksで**_未記録_**の日 → Habitifyの`Skipped`（連続記録を維持します）
- **週次習慣：** Habitifyで週の開始日に設定できるのは日曜日または月曜日ですが、Streaksでは任意の曜日を選べます。そのため、Streaksの週間記録はHabitifyで該当する週の**月曜日**へ割り当てられます。<br />_例：_ Streaksの週が水曜日から火曜日までの場合も、その週全体の完了ステータスはHabitifyでは月曜日に表示されます。
- **月次習慣：** 週次と同様に、Streaksの月全体の完了ステータスは、Habitifyでその月の**1日**へ割り当てられます。

**3／悪い習慣の目標**

- **習慣をやめる：** Streaksで「No［習慣名］」という目標だった場合、Habitifyの**「習慣をやめる」**としてインポートし、避けられた日数を記録します。
- **習慣を制限する：** 「1日／週／月にX回」へ制限する目標は、同じ頻度のHabitifyの**「習慣を制限」**としてインポートします。

### **スプレッドシートからインポートする**

以前の記録がスプレッドシートにある場合は、**Zapier**を使ってインポートできます。少し高度な方法ですが、任意の習慣の履歴をまとめて補完できます。

Google Sheetsの新しい行を検知し、対応する記録をHabitifyへ作成する自動化（「Zap」）を使用します。古いデータをGoogle Sheetsへコピー＆ペーストすると、インポートが実行されます。

<Steps>
  <Step title="スプレッドシートを準備する">
    以前のデータを[<u>Google Sheetsテンプレート</u>](https://docs.google.com/spreadsheets/d/1LN3wqWGwHToYL0pWqYPCGztiY9Rxi9KA_xLo1poQdU8/edit?usp=sharing)に合わせて整えます。1つのシートで1つの習慣の進捗を記録します。各行が1件の完了を表すように、日付、時刻、数値を整理してください。
  </Step>
  <Step title="Habitifyの習慣を設定する">
    データを取り込む対象の習慣をHabitifyで作成します。
  </Step>
  <Step title="Zapierテンプレートで設定する">
    用意されているZapierテンプレートを使って、スプレッドシートとHabitifyの習慣を接続します。
  </Step>
  <Step title="Zapを実行してインポートする">
    Zapを有効にしたら、過去のデータ全体をGoogle Sheetsへコピー＆ペーストします。Zapierが各行を読み取り、日付付きの記録としてHabitifyへ取り込みます。
  </Step>
</Steps>

Airtable、オンライン版Microsoft Excel、Zoho Sheetなど、ほかの表形式サービスでもZapierを使って同様に連携できます。

## Habitifyからデータをエクスポートする

用途に応じて2つの形式を用意しています。基本的な記録分析向けのシンプルな**CSVファイル**と、アカウント全体のスナップショットを保存する**完全バックアップ（.sqlite）**です。

#### 手順

1. Habitifyアプリの**設定**タブへ移動します。
2. **インポート／エクスポート**をタップします。
3. **.csvとしてエクスポート**または**バックアップとしてエクスポート**を選びます。
4. デバイスの案内に従い、ファイルを保存または共有します（メール、クラウドストレージなど）。

#### **エクスポート形式の比較**

| 形式 | .csv | バックアップ |
| --- | --- | --- |
| 最適な用途 | Google Sheets、Microsoft Excel、Apple Numbersなどで、基本的な習慣完了履歴を分析する。 | Habitifyの設定と履歴全体を完全にバックアップする。将来の復元や、データベースツールを使った高度な技術分析に利用できる。 |
| 拡張子 | `.csv` | `.sqlite` |
| 内容 | 習慣のチェックインを記録し、各行に次の列が含まれます。<ul><li>`Habit`：習慣名。</li><li>`Date`：記録日。</li><li>`Total log`：記録した数値（該当する場合）。</li><li>`Unit`：目標の単位（分、km、回など）。</li><li>`Status`：完了、スキップ、失敗。</li><li>`Habit ID`：習慣固有の識別子。</li></ul> | アカウント内の**すべて**を含む包括的なスナップショットです。<ul><li>**習慣の詳細：** 有効・アーカイブ済みの全習慣、目標、チェックリスト、リマインダー（時刻、場所、スタッキング）、終了条件、マイルストーンなど。</li><li>**進捗と記録：** チェックイン、スキップ、失敗、数値記録、メモ、気分、チェックリスト、連続記録（`currentStreak`）、計算済み進捗データ（`logCalculations`、`progresses`）。</li><li>**設定：** 週の開始日（`firstDayOfWeek`）などのアカウント設定。</li></ul> |

## Habitify内のデータを管理する

### 習慣データをリセットする

<Warning>
  リセット前に、次の内容をご確認ください。

  - アカウント内のすべての習慣について、**過去のデータが完全に削除**されます。
  - チェックイン、スキップ、失敗、現在の連続記録、メモ、アーカイブ済み習慣の進捗もすべて対象です。
  - **元に戻せません。** 削除後は、サポートチームでも復元できません。
  - _現在_の習慣一覧は残りますが、進捗と連続記録は0へリセットされます。
</Warning>

<Tabs>
  <Tab title=" iOS">
    1. **Habitify**を開き、**設定**へ移動します。
    2. プロフィールをタップします。
    3. **プライバシーとデータ**で、**習慣データをリセット**をタップします。
    4. 確認画面でもう一度**習慣データをリセット**をタップします。
  </Tab>
  <Tab title="🤖 Android">
    1. **Habitify**を開き、**設定**へ移動します。
    2. 自分の名前をタップします。
    3. **Caution zone**まで下へスクロールします。
    4. **習慣データをリセット**の横にある**削除**ボタンをタップします。
    5. 確認画面で**OK**をタップします。
  </Tab>
  <Tab title="🖥️ Web・デスクトップ">
    1. Habitifyアプリを開きます。
    2. プロフィール写真をクリックし、**プロフィール**を選びます。
    3. **Caution Zone**で、**習慣データをリセット**をクリックします。
    4. 確認画面でもう一度**習慣データをリセット**をクリックします。
  </Tab>
</Tabs>

### すべてのデータを削除する

<Warning>
  実行前に、次の内容を必ずお読みください。

  - 一覧にある**すべての習慣**が完全に削除されます。
  - チェックイン、スキップ、失敗、メモ、連続記録を含む**すべての履歴データ**も完全に削除されます。
  - **元に戻せません。** 確定後は、本人にもサポートチームにも復元できません。
  - アカウントは**完全に空の状態**になります。
</Warning>

<Tabs>
  <Tab title=" iOS">
    1. **Habitify**を開き、**設定**へ移動します。
    2. プロフィールをタップします。
    3. **プライバシーとデータ**で、**すべてのデータを削除**をタップします。
    4. 確認画面でもう一度**すべてのデータを削除**をタップします。
  </Tab>
  <Tab title="🤖 Android">
    1. **Habitify**を開き、**設定**へ移動します。
    2. 自分の名前をタップします。
    3. **Caution zone**まで下へスクロールします。
    4. **すべてのデータを削除**の横にある**削除**ボタンをタップします。
    5. 確認画面で**OK**をタップします。
  </Tab>
  <Tab title="🖥️ Web・デスクトップ">
    1. Habitifyアプリを開きます。
    2. プロフィール写真をクリックし、**プロフィール**を選びます。
    3. **Caution Zone**で、**データを削除**をクリックします。
    4. 確認画面で**すべてのデータを削除**をクリックします。
  </Tab>
</Tabs>

## よくある質問

<Accordion title="**エクスポートしたCSVをExcelで開くと1列だけになるのはなぜですか？**">
  ExcelがCSVファイルの区切り文字を認識していないことが原因です。Habitifyのエクスポートではセミコロン（`;`）で項目を区切りますが、Excel側が別の区切り文字を想定している場合があります。

  **データを列ごとに表示する方法**

  1. ExcelでCSVファイルを開き、**A列**を選びます。
  2. **データ → 区切り位置**へ移動します。
  3. **区切り文字付き**を選び、**次へ**をクリックします。
  4. **セミコロン**を選び、ほかの区切り文字の選択を外します。
  5. **完了**をクリックします。

  データが**Habit、Date、Total Log、Unit、Status、Habit ID**の列に分かれて表示されます。
</Accordion>
