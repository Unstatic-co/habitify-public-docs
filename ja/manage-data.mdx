## Habitifyへデータをインポートする

新しいアプリを使い始めるときも、ほかのアプリやスプレッドシートにある大切な記録履歴は失いたくないものです。ここでは、過去のデータをHabitifyへ取り込み、これまでの歩みをまとめて確認する方法を説明します。

### **ヘルスケアデータをインポートする**

フィットネス関連の過去データがApple Health、Health Connect、Fitbit、Stravaに保存されている場合は、最も簡単で自動的な方法です。

**仕組み：** いずれかのサービスをHabitifyの習慣へ初めて接続すると、アプリが自動で**履歴を同期**し、過去のアクティビティを習慣の記録へ取り込みます。

- **Apple HealthまたはHealth Connect：** iPhoneまたはAndroidスマートフォンから歩数、ワークアウト、睡眠、マインドフル時間などを直接同期します。
- **Fitbit：** Fitbitデバイスから毎日の歩数、睡眠、消費カロリーなどの統計を自動的に記録します。
- **Strava：** ランニング、ライド、ウォーキングなどのワークアウトを完了後すぐに習慣へ同期します。

### Productiveアプリからデータをインポートする

先にProductiveアプリからデータをエクスポートしてください。通常は`.sqlite`ファイルとして書き出されます。Habitifyへのインポート開始時にこのファイルが必要です。

Habitifyアプリで、**設定 → データのインポート／エクスポート → Productiveからインポート**へ移動します。

エクスポートした`.sqlite`ファイルを選択し、画面の案内に従ってインポートを完了します。

主に次の習慣情報が取り込まれます。

- **習慣：** 習慣の一覧。
- **習慣の記録：** 過去のチェックイン、スキップ、失敗。
- **時間帯：** 朝、午後、夜の設定。
- **習慣の説明：** 習慣へ追加したメモや説明。
- **終了条件：** Productiveで終了日が設定されていた場合、その日付が今日以前でなければ取り込まれます（Habitifyの終了日は7日以上先である必要があります）。

<Note>
  **重要な注意事項：**

  - Productiveの**チャレンジ**と**プログラム**は取り込まれません。個別の習慣のみが対象です。
  - Productiveで**一時停止または停止**されていた習慣も取り込まれますが、Habitifyでは自動的に**アーカイブ済み**になります。必要に応じて後からアーカイブを解除できます。
</Note>

Productiveのスケジュールと目標は、次のようにHabitify形式へ自動変換されます。

- **毎日／特定の曜日／月の特定日：** Productiveで毎日、特定の曜日、月の特定日に繰り返す習慣は、同じスケジュールを維持したHabitifyの**日ごとの目標**として取り込まれます。
- **1日に複数の目標：** 1日の中に複数の目標がある場合（例：「朝2回＋夜2回」）、Habitifyでは1つの日次目標へ**合算**されます（例：「1日4回」）。
- **週ごとの頻度（例：「週3回」）：** 週ごとの頻度（例：「週3回」）と日ごとの目標（例：「1回20分」）がある場合は、頻度と日次目標を掛けた1つの**週ごとの目標**へ変換されます。<br />_例：_ Productive「週3回、1日20分」→ Habitify **「週60分」**。
- **特殊なケース — 隔週：** Productiveで「2週間ごとに1回」などの間隔を設定していた場合、この間隔は直接取り込めないため、代替としてHabitifyの**日ごとの目標**へ変換されます。インポート後にスケジュールを手動で調整してください。

### Streaksアプリからデータをインポートする

先にStreaksアプリからデータをエクスポートしてください。通常、`.streaks`拡張子の専用ファイルとして書き出されます。このファイルを用意してからHabitifyへのインポートを開始します。

Habitifyアプリで、**設定 → データのインポート／エクスポート → Streaksからインポート**へ移動します。

エクスポートした`.streaks`ファイルを選択し、画面の案内に従ってインポートを完了します。

次の主要な記録要素が取り込まれます。

- **習慣名：** 同じ名前を維持します。
- **繰り返しスケジュール：** 習慣の頻度（日、週、月）を変換します。
- **目標としての頻度：** 「日／週／月にX回」という目標を維持します。
- **リマインダー：** カスタムのリマインダー時刻を取り込みます（詳細は以下）。
- **習慣メモ：** 習慣へ追加したメモをコピーします。
- **最初の記録日を開始日に設定：** Streaksで最も古い記録の日付をHabitifyの「開始日」にします。
- **記録履歴：** 過去の完了、失敗、スキップを取り込みます。
- **悪い習慣：** やめる／制限する習慣も取り込みます（詳細は以下）。

HabitifyとStreaksでは動作が少し異なるため、インポート時に一部のデータが変換されます。

**1／リマインダー**

Streaksで特定のリマインダー時刻を設定していた場合、同じ時刻がHabitifyへ同期されます。HabitifyにはStreaksの「自動リマインダー」に相当する機能がないため、これは取り込まれません。

**2／記録履歴**

- **毎日の習慣：** そのまま変換されます。
  - Streaksの`完了` → Habitifyの`完了`
  - Streaksの`失敗` → Habitifyの`失敗`
  - Streaksで**_未記録_**の日 → Habitifyの`スキップ`（連続達成記録を維持）
- **週ごとの習慣：** Habitifyでは週の開始日を日曜日または月曜日に限る一方、Streaksでは任意の日を選べます。そのため、Streaksの週間記録はHabitifyで該当する週の**月曜日**に割り当てられます。<br />_例：_ Streaksの週が水曜日から火曜日の場合、その週全体の完了ステータスはHabitifyで同じ週の月曜日に表示されます。
- **月ごとの習慣：** 週間習慣と同様に、Streaksの月全体の完了ステータスはHabitifyで**その月の1日**に割り当てられます。

**3／悪い習慣の目標**

- **習慣をやめる：** Streaksの目標が「［習慣名］をしない」の場合、Habitifyでは「習慣をやめる」**として取り込まれ、避けられた日数を記録します。
- **習慣を制限する：** 悪い習慣を「日／週／月にX回」へ制限する目標は、同じ頻度目標を持つHabitifyの「習慣を制限」**として取り込まれます。

### **スプレッドシートからデータをインポートする**

以前の記録がスプレッドシートにある場合は、**Zapier**を使って取り込めます。少し高度な方法ですが、任意の習慣の完全な履歴を補完するのに適しています。

この方法では、Googleスプレッドシートの新しい行を監視し、Habitifyへ対応する記録を作る自動化（「Zap」）を使用します。古いデータをGoogleスプレッドシートへコピー＆ペーストすると処理が始まります。

<Steps>
  <Step title="データのスプレッドシートを準備する">
    以前のデータを[<u>Googleスプレッドシートのテンプレート</u>](https://docs.google.com/spreadsheets/d/1LN3wqWGwHToYL0pWqYPCGztiY9Rxi9KA_xLo1poQdU8/edit?usp=sharing)に合わせて整形します。各シートには1つの習慣の進捗を記録し、各行が日付、時刻、数値を含む1回の完了を表すよう整理します。
  </Step>
  <Step title="Habitifyの習慣を設定する">
    データの取り込み先となる習慣をHabitifyで作成します。
  </Step>
  <Step title="Zapierテンプレートで簡単に設定する">
    データの取り込み先となる習慣をHabitifyで作成します。
  </Step>
  <Step title="Zapを実行してデータをインポートする">
    Zapを有効にしたら、履歴データ全体をGoogleスプレッドシートへコピー＆ペーストします。Zapierが各行を読み取り、日付付き記録としてHabitifyへ取り込み、過去の進捗を補完します。
  </Step>
</Steps>

Airtable、オンライン版Microsoft Excel、Zoho Sheetなど、ほかの表形式データサービスでもZapierを使って同様の連携を実装できます。

## Habitifyからデータをエクスポートする

用途に応じて、基本的な記録分析用のシンプルな**CSVファイル**と、アカウント全体を保存する**完全バックアップファイル（.sqlite）**の2形式を利用できます。

#### 手順

1. Habitifyアプリの**設定**タブへ移動します。
2. **インポート／エクスポート**をタップします。
3. **.csvとしてエクスポート**または**バックアップとしてエクスポート**を選択します。
4. デバイスの画面案内に従い、ファイルを保存または共有します（例：メール、クラウドストレージ）。

#### **エクスポート形式の比較**

| 形式 | .csv | バックアップ |
| --- | --- | --- |
| 最適な用途 | Googleスプレッドシート、Microsoft Excel、Apple Numbersなどで、基本的な習慣完了履歴を分析する。 | Habitifyの設定と履歴全体を完全にバックアップする。将来のデータ復元や、データベースツールによる高度な技術分析に利用できる可能性があります。 |
| 拡張子 | `.csv` | `.sqlite` |
| 内容 | 各記録の次の列を含む、習慣チェックインの分かりやすい一覧です。<ul><li>`Habit`：習慣名。</li><li>`Date`：記録日。</li><li>`Total log`：記録した数値（該当する場合）。</li><li>`Unit`：目標の単位（分、km、回など）。</li><li>`Status`：完了、スキップ、失敗のいずれか。</li><li>`Habit ID`：習慣の固有識別子。</li></ul> | 次を含む（ただしこれらに限られない）アカウント内の**すべて**の包括的なスナップショットです。<ul><li>**習慣の詳細：** 有効／アーカイブ済みの全習慣、目標、チェックリスト、リマインダー（時間、場所、スタッキング）、終了条件、マイルストーンなど。</li><li>**進捗と記録：** すべてのチェックイン、スキップ、失敗、数値記録、メモ、気分、チェックリスト記録、連続達成履歴（`currentStreak`）、計算済み進捗データ（`logCalculations`、`progresses`）。</li><li>**設定：** 週の開始日（`firstDayOfWeek`）などのアカウント設定。</li></ul> |

## Habitifyのデータを管理する

### 習慣データをリセットする

<Warning>
  リセット前に、次の内容をご確認ください。

  - アカウント内のすべての習慣の**履歴データが完全に削除**されます。
  - すべてのチェックイン、スキップ、失敗、現在の連続達成記録、メモ、アーカイブ済み習慣の進捗が含まれます。
  - **この操作は取り消せません。** 削除後は永久に失われ、サポートチームでも復元できません。
  - _現在_の習慣一覧は残りますが、進捗と連続達成記録は0に戻ります。
</Warning>

<Tabs>
  <Tab title=" iOS">
    1. **Habitify**を開き、**設定**へ移動します。
    2. プロフィールをタップします。
    3. **プライバシーとデータ**で**習慣データをリセット**をタップします。
    4. 確認のため、**習慣データをリセット**をタップします。
  </Tab>
  <Tab title="🤖 Android">
    1. **Habitify**を開き、**設定**へ移動します。
    2. 自分の名前をタップします。
    3. **注意が必要な操作**まで下へスクロールします。
    4. **習慣データをリセット**の横にある**削除**をタップします。
    5. 確認のため、**OK**をタップします。
  </Tab>
  <Tab title="🖥️ ウェブサイトとデスクトップ">
    1. Habitifyアプリを開きます。
    2. プロフィール写真をクリックし、**プロフィール**を選択します。
    3. **注意が必要な操作**で**習慣データをリセット**をクリックします。
    4. 確認のため、**習慣データをリセット**をクリックします。
  </Tab>
</Tabs>

### すべてのデータを削除する

<Warning>
  続行する前に、次の内容を十分にご確認ください。

  - 一覧から**すべての習慣**が完全に削除されます。
  - すべてのチェックイン、スキップ、失敗、メモ、連続達成記録を含む**すべての履歴データ**も完全に削除されます。
  - **この操作は取り消せません。** 確定後、すべての情報が永久に失われ、ご自身でもサポートチームでも復元できません。
  - アカウントは**完全に空の状態**になります。
</Warning>

    2. プロフィールをタップします。

    4. 確認のため、**すべてのデータを削除**をタップします。
  </Tab>
  <Tab title="🤖 Android">
    1. **Habitify**を開き、**設定**へ移動します。

    3. **注意が必要な操作**まで下へスクロールします。
    4. **すべてのデータを削除**の横にある**削除**をタップします。
    5. 確認のため、**OK**をタップします。
  </Tab>
  <Tab title="🖥️ ウェブサイトとデスクトップ">

## よくある質問

<Accordion title="**エクスポートしたCSVファイルがExcelで1列に表示されるのはなぜですか？**">
  ExcelがCSVファイルの区切り文字を認識していない場合に発生します。Habitifyのエクスポートではフィールドをセミコロン（`;`）で区切りますが、Excelの設定で別の区切り文字が指定されている可能性があります。

  **データを別々の列に表示する方法**

  1. ExcelでCSVファイルを開き、**A列**を選択します。
  2. **データ → 区切り位置**へ移動します。
  3. **区切り文字付き**を選択し、**次へ**をクリックします。
  4. **セミコロン**を選択し、ほかの区切り文字の選択を解除します。
  5. **完了**をクリックします。

  **習慣、日付、合計記録、単位、ステータス、習慣ID**が別々の列に表示されます。
</Accordion>
