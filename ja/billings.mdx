    ## Habitifyプランを購入する

    ### **Plusの定期購入を開始する**

    1. Habitifyを開き、下部ナビゲーションの**アップグレード**タブへ移動します。
    2. _プランを比較_表の一番下までスクロールし、**Plusを試す →**をタップします。
    3. App Storeのポップアップで、プラン、料金、初回請求日を確認します。
    4. 問題がなければ、iOSデバイスの案内に従って購入を確定します。

    ### **PROの定期購入を開始する**

    1. Habitifyを開き、下部ナビゲーションの**アップグレード**タブへ移動します。
    2. 希望する支払いサイクルのプランを選び、**Habitify PROへアップグレード**をタップします。
    3. App Storeのポップアップで、プラン、料金、初回請求日を確認します。
    4. 問題がなければ、iOSデバイスの案内に従って購入を確定します。

    <Warning>
      Proの月払いには12か月の継続条件があり、いつでも解約できる月単位の請求ではありません。

      詳細：[**iOSの継続条件付き定期購入のお支払い方法**](https://support.apple.com/en-vn/126901)
    </Warning>

    ### PRO Lifetimeアクセスを購入する

    1. Habitifyを開き、下部ナビゲーションの**アップグレード**タブへ移動します。
    2. 料金画面で**Lifetime**を選び、**Lifetimeアクセスを購入**をタップします。
    3. App Storeのポップアップで料金と支払日を**よく確認します。**
    4. 問題がなければ、iOSデバイスの案内に従って購入を確定します。

    ## Habitifyプランを変更する

    ### 定期購入から別の定期購入へ変更する

    1. iPhoneまたはiPadで**設定**を開きます。
    2. _［自分の名前］_ → **サブスクリプション**をタップします。
    3. Habitifyの定期購入を選びます。
    4. **すべてのプランを表示 ＞**をタップし、プランを選びます。
    5. 画面の案内に従って購入を完了します。

    ### 定期購入からLifetimeへ変更する

    1. **自動更新を解約：** 現在の定期購入が更新されないよう、次回の支払いを解約します。
    2. **有効期限まで待つ：** 支払い期間が重ならないよう、現在の定期購入が完全に終了するまで待ちます。
    3. **Lifetimeを購入：** 定期購入の終了後、Lifetimeアクセスを購入します。

    切り替え中も、習慣と過去の実績は安全に保存されます。

    ## Habitifyプランを解約する

    1. iPhoneまたはiPadで**設定**を開きます。
    2. _［自分の名前］_ → **サブスクリプション**をタップします。
    3. Habitifyの定期購入を選びます。
    4. **サブスクリプションをキャンセル**をタップします。

    キャンセルボタンがない場合や、有効期限が赤字で表示されている場合は、すでに解約されています。

    <Note>
      Lifetimeはアプリ内購入です。Lifetimeアクセスを取り消す場合は、直接返金を申請してください。
    </Note>

    ### 返金を申請する

    iPhoneまたはiPadのHabitifyアプリから購入した場合、支払い先はApp Storeです。返金はAppleのポリシーに従ってAppleが処理します。

    Appleの返金ポリシー：[<u>https://support.apple.com/en-vn/118223</u>](https://support.apple.com/en-vn/118223)

    1. [<u>reportaproblem.apple.com</u>](http://reportaproblem.apple.com)へサインインします。
    2. **ご希望の項目を選択してください**から**返金をリクエストする**を選びます。
    3. 返金理由を選び、**次へ**を選びます。
    4. 最近購入したHabitifyの項目を選び、**送信**を選びます。

    Appleが承認した後、返金が支払い方法へ反映されるまでさらに時間がかかる場合があります。詳しくはApple公式サポートをご確認ください。

    ## よくある質問

    <Accordion title="Lifetimeを購入済みなのに月払い／年払いが請求されました。どうすればよいですか？">
      Lifetimeへのアップグレードで、月払いまたは年払いの定期購入が自動的に解約されることはありません。二重請求を避けるため、Lifetimeの購入前に定期購入の自動更新を解約してください。
    </Accordion>

    <Accordion title="支払い済みなのに一部の機能を利用できません。どうすればよいですか？">
      一部の機能はPro限定です。年払いのPlusに含まれるのは、習慣数無制限、習慣ごとのリマインダー数無制限、カスタムエリア数無制限です。

      Proで有料機能を利用できない場合は、次をお試しください。

      - Premiumを購入したAppleアカウントへログインしていることを確認します。
      - Habitifyで**設定 → Payment & Billing → Restore Purchase**をタップします。

      解決しない場合は、支払い領収書のスクリーンショットを[<u>contact@habitify.me</u>](mailto:contact@habitify.me)へお送りください。
    </Accordion>

    <Accordion title="7日間のトライアルではなく、すぐに請求されたのはなぜですか？">
      **7日間無料トライアルを利用できるのはPro年間プランだけ**です。また、初回購入者向けの特典であり、App StoreがApple IDに基づいて利用資格を判定します。
    </Accordion>

    <Accordion title="トライアル後にLifetimeへ変更したいのですが、選択肢が表示されません。どうすればよいですか？">
      無料トライアルは有効な定期購入として扱われるため、終了まではLifetimeを含むアップグレード画面が一時的に非表示または無効になります。

      1. **iOS設定 →［自分の名前］→ サブスクリプション → Habitify → サブスクリプションをキャンセル**を開き、更新を解約します。
      2. 解約後もトライアル終了日まではPROを利用できます。終了までお待ちください。
      3. Freeへ戻ったら、**Habitify → 設定 → Premiumへアップグレード**を開きます。
      4. **Lifetime**を選び、購入を完了します。
    </Accordion>

    <Accordion title="無料トライアルを終了する方法と、その後の動作を教えてください。">
      無料トライアルはいつでも解約でき、**残りの期間は引き続きすべてのPRO機能を利用できます。** 手続きはHabitifyではなくApp Storeで行います。

      1. iPhoneまたはiPadの**設定**を開きます。
      2. 上部の**［自分の名前］**をタップします。
      3. **サブスクリプション** → **Habitify**を開きます。
      4. **サブスクリプションをキャンセル**をタップして確定します。

      解約後は更新されないことと終了日が表示されます。終了日まではPremiumを利用でき、その日に自動でFreeへ戻り、料金は請求されません。
    </Accordion>

    3. **お支払いと定期購入 → 定期購入**をタップします。

    1. Google Playを開き、正しいGoogleアカウントのプロフィールをタップします。

    3. _有効_の一覧からHabitifyを選びます。
    4. **定期購入を解約**をタップし、画面の案内に従います。

    <Note>
      Lifetimeはアプリ内購入です。取り消す場合は、直接返金を申請してください。
    </Note>

    ### 返金を申請する

    AndroidのHabitifyアプリから購入した場合、支払い先はPlay Storeです。返金は[Googleの返金ポリシー](https://support.google.com/googleplay/answer/15574908?sjid=14936331635526272250-NC)に従ってGoogleが処理します。

    1. **Play Store**を開きます。
    2. 右上の**プロフィール写真**をタップします。
    3. **お支払いと定期購入 → 予算と履歴**を開きます。
    4. 対象の注文で**問題を報告**をタップします。
    5. 返金理由を選び、案内に従って**送信**します。

    ブラウザでは[<u>Google Playの返金をリクエスト</u>](https://play.google.com/store/account/orderhistory)から申請できます。

    ## Habitifyプランを購入する

    1. 左側メニューの**お支払い**をクリックします。
    2. 月払い、年払い、Lifetimeから希望する支払い方法を選びます。
    3. PLUSまたはPROを選び、該当する**このプランを選択**をクリックします。

    ## Habitifyプランを変更する

    ### PlusからProへアップグレードする

    二重払いを防ぐため、有料プランの利用中はお支払い画面が非表示になります。Proの料金を確認して変更するには、次の手順を行います。

    - Webまたはデスクトップアプリで、左側の**オフモード**から休止期間を追加するなど、Pro機能へアクセスします。
    - 表示されたProの料金を確認します。
    - 新しいプランを選び、**Proへアップグレード**をクリックします。
    - 画面の案内に従って認証と支払いを完了します。

    <Warning>
      **現在のプランと同じ支払い元でアップグレードしてください。**

      - MacでPlusを開始した場合はAppleへ支払っているため、Macアプリからアップグレードします。
      - WebまたはWindowsで開始した場合はHabitifyの決済サービスへ支払っているため、WebまたはWindowsアプリからアップグレードします。
    </Warning>

    ### Proの月払いから年払いへ変更する

    Appleへ支払っている場合は、Macで次の手順を行います。

    1. Macの**App Store**を開きます。
    2. 左下の自分の名前をクリックし、購入に使用した同じ[Apple Account](https://support.apple.com/en-vn/guide/app-store/aside/glosbdc8e694/3.0/mac/27)へログインします。
    3. 上部の**アカウント設定**をクリックし、必要なら再度ログインします。
    4. _管理_で、サブスクリプションの横にある**管理**をクリックします。
    5. **編集**をクリックし、オプションを選んで**完了**をクリックします。

    Habitifyの決済サービスへ支払っている場合は、領収書を添えてサポートチームへご連絡ください。

    ### 定期購入からLifetimeへ変更する

    現在、直接変更することはできません。定期購入の自動更新を解約し、期間終了後にアカウントがFreeへ戻るまで待ちます。左側メニューにお支払い画面が戻ったら、Lifetimeを購入できます。

    ### Lifetimeから定期購入へ変更する

    Lifetimeは一度の支払いで所有する商品です。定期購入へ変更するには、Lifetimeの返金を申請してFreeへ戻った後、定期購入を購入します。

    MacアプリからAppleへ支払った場合：

    1. [<u>reportaproblem.apple.com</u>](http://reportaproblem.apple.com)へサインインします。
    2. **ご希望の項目を選択してください**から**返金をリクエストする**を選びます。
    3. 返金理由を選び、**次へ**を選びます。
    4. **Habitify Lifetime**を選び、**送信**します。

    WebまたはWindowsから決済サービスへ支払った場合は、領収書を添えてお問い合わせください。

    ## Habitifyプランを解約する

    Webアプリでの支払いはPaddleが処理します。支払い後にPaddleから届く件名**Your receipt from Habitify**のメールを探します。

    1. メール内の**Need help with your purchase? Please contact us on [<u>paddle.net</u>](http://paddle.net).**というリンクをクリックします。
    2. Paddleの購入画面でHabitifyの定期購入を探し、**Get Help**をクリックします。
    3. チャットで解約を依頼します。Paddleから届く**解約リンク**を開き、案内に従います。

    お困りの場合は、Paddleの領収書メールに添付された請求書を[サポートへ転送](mailto:contact@habitify.me)してください。24時間以内に確認し、解約を支援します。

    <Note>
      Lifetimeはアプリ内購入です。取り消す場合は、直接返金を申請してください。
    </Note>

    ## 返金を申請する

    **Appleから直接購入した定期購入とLifetime**はAppleの返金ポリシーに基づいて判断されます。申請後は[<u>返金状況を確認</u>](https://support.apple.com/en-vn/118224)できます。承認後、支払い方法への反映まで時間がかかる場合があります。

    **Habitifyの決済サービスから直接購入した定期購入とLifetime**はHabitifyチームが処理し、支払日から**7日間の返金期間**を設けています。

    1. 購入後にメールで届いた請求書を用意します。
    2. 請求書を添付し、[**<u>contact@habitify.me</u>**](mailto:contact@habitify.me)へ送信します。
    3. チームが申請を確認し、処理します。
