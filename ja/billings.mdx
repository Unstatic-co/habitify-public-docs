    ## Habitifyプランを購入する

    ### **Plusサブスクリプションを開始する**

    1. Habitifyを開き、下部のナビゲーションバーにある**アップグレード**タブへ移動します。
    2. _プランを比較_表の末尾まで下へスクロールし、<br />**Plusを試す →**を見つけてタップします。
    3. App Storeのポップアップに、申し込むプランの詳細、価格、初回支払日が表示されます。
    4. 内容に問題がなければ、iOS端末で求められる操作を行い、サブスクリプションを確定します。

    ### **PROサブスクリプションを開始する**

    1. Habitifyを開き、下部のナビゲーションバーにある**アップグレード**タブへ移動します。
    2. 料金一覧で自分に合う支払いプランのサブスクリプションを選び、<br />**Habitify PROにアップグレード**をタップします。
    3. App Storeのポップアップに、申し込むプランの詳細、価格、初回支払日が表示されます。
    4. 内容に問題がなければ、iOS端末で求められる操作を行い、サブスクリプションを確定します。

    <Warning>
      PROの月払いオプションには、いつでも解約できる請求サイクルではなく、12か月間の契約が伴います。

      詳細：[**iOSで契約期間を伴うサブスクリプションの支払いオプション。**](https://support.apple.com/en-vn/126901)
    </Warning>

    ### PROの買い切りアクセスを取得する

    1. Habitifyを開き、下部のナビゲーションバーにある**アップグレード**タブへ移動します。
    2. 料金一覧で**買い切り**オプションを選び、**買い切りアクセスを取得**をタップします。
    3. App Storeのポップアップに価格と支払日が表示されます。
    4. 内容に問題がなければ、iOS端末で求められる操作を行い、購入を確定します。

    ## Habitifyプランを変更する

    ### サブスクリプションから別のサブスクリプションへ

    1. iPhoneまたはiPadで**設定**アプリを開きます。
    2. _［自分の名前］_をタップし、**サブスクリプション**をタップします。
    3. Habitifyのサブスクリプションを見つけてタップします。
    4. **すべてのプランを表示**をタップし、一覧からプランを選びます。
    5. 画面の案内に従って新しい購入を完了します。

    ### サブスクリプションから買い切りへ

    買い切りプランへ切り替えるには、次の手順に従います。

    1. **自動更新を解約する：**まず、現在のサブスクリプションが自動更新されないよう、次回の支払いを解約します。
    2. **有効期限を待つ：**現在のサブスクリプションが完全に終了するまで待ちます。これにより、支払い期間の重複を避けられます。
    3. **買い切りを購入する：**サブスクリプションの終了後、買い切りアクセスを購入できます。

    新しいプランへ移行している間も、習慣と過去の実績は安全に保持されます。

    ## Habitifyプランを解約する

    1. iPhoneまたはiPadで**設定**アプリを開きます。
    2. _［自分の名前］_をタップし、**サブスクリプション**をタップします。
    3. Habitifyのサブスクリプションを見つけてタップします。
    4. **サブスクリプションをキャンセル**をタップします。

    キャンセルボタンがない場合、または赤字で有効期限に関するメッセージが表示されている場合、サブスクリプションはすでに解約されています。

    <Note>
      買い切りはアプリ内購入です。買い切りアクセスを取り消したい場合は、直接返金を申請してください。
    </Note>

    ### 返金を申請する

    iPhoneまたはiPadのHabitifyアプリからサブスクリプションを開始した場合、支払いはApp Storeへ行われます。そのため、返金申請はAppleのポリシーに従い、Appleが処理します。

    Appleの返金ポリシー：[<u>https://support.apple.com/en-vn/118223</u>](https://support.apple.com/en-vn/118223)

    1. [<u>reportaproblem.apple.com</u>](http://reportaproblem.apple.com)にサインインします。
    2. **ご希望の項目を選択してください**をタップし、**返金をリクエストする**を選びます。
    3. 返金を希望する理由を選び、**次へ**を選択します。
    4. Habitifyの最近のサブスクリプション項目を見つけて選択し、**送信**を選びます。

    Appleが申請を承認した後、支払い方法へ返金されるまでさらに時間がかかる場合があります。詳しくはAppleの公式サポートをご確認ください。

    ## よくある質問

    <Accordion title="**すでに買い切りプランを持っているのに、月払い／年払いプランの請求がありました。どうすればよいですか？**">
      買い切りアクセスへのアップグレードは、月払いまたは年払いのプレミアムサブスクリプションを自動的に解約するものではありません。

      二重請求を防ぐには、買い切りプランを購入する前に更新プランを解約する必要があります。
    </Accordion>

    <Accordion title="**支払い済みなのに一部の機能を利用できません。どうすればよいですか？**">
      まず、PROプランでのみ利用できる機能があります。年払いのPlusプランには、次の機能が含まれます。

      - 習慣数が無制限
      - 習慣ごとのリマインダー数が無制限
      - カスタムエリア数が無制限

      PROプランを利用しているにもかかわらず、支払い後に有料機能へアクセスできない場合は、購入方法に応じて次の手順をお試しください。

      - Premiumの購入に使用したAppleアカウントへログインしていることを確認します。
      - Habitifyアプリを開き、**設定**タブへ移動します。
      - **支払いと請求**をタップします。
      - **購入を復元**をタップします。

      すべて試しても問題が解決しない場合は、**支払い領収書のスクリーンショットを[<u>contact@habitify.me</u>](mailto:contact@habitify.me)へ送信してください。**確認のうえ、サポートいたします。
    </Accordion>

    <Accordion title="**7日間のトライアルではなく、すぐに請求されたのはなぜですか？**">
      Habitifyでは柔軟に選べるよう、月払い、年払い、買い切りなど複数のサブスクリプションプランを用意しています。ただし、**7日間の無料トライアルを利用できるのは、年払いのPROプランだけです。**

      また、**無料トライアルは初回利用者向けの特典**です。App Storeはトライアルの利用資格をApple IDへ直接関連付け、この条件を厳格に適用します。
    </Accordion>

    <Accordion title="**トライアル終了後に買い切りアクセスへ切り替えたいのですが、その項目が表示されません。どうすればよいですか？**">
      無料トライアルは有効なサブスクリプションとして扱われます。そのサブスクリプションが有効な間、買い切りを含む_アップグレード_画面は、トライアルが終了するまで一時的に非表示または無効になります。

      次の手順に従ってください。

      1. **iOSの設定 → ［自分の名前］ → サブスクリプション → Habitify → サブスクリプションをキャンセル**を開き、現在のサブスクリプションの更新を解約します。
      2. 解約するとトライアルから有料サブスクリプションへの移行は停止しますが、トライアル終了日まではPROを利用できます。終了までお待ちください。
      3. トライアルが終了してアカウントがFreeへ戻ったら、<br />**Habitify** → **設定** → **Premiumにアップグレード**を開きます。
      4. **買い切り**を選択し、購入を完了します。
    </Accordion>

    <Accordion title="**無料トライアルを終了する方法と、その後の動作は？**">
      PROプランの無料トライアルは、Habitifyの全機能を試すのに最適な方法です。一方で、自分には合わないと判断した場合や、トライアル後の自動更新を防ぎたい場合もあります。

      **無料トライアルはいつでも解約でき、解約後もトライアルの残り期間中はすべてのPRO機能を引き続き利用できます。**

      この手続きはHabitifyアプリ内ではなく、スマートフォンのアプリストアがすべて管理します。

      1. iPhoneまたはiPadで**設定**アプリを開きます。
      2. 一番上にある**［自分の名前］**をタップします。
      3. **サブスクリプション**をタップします。
      4. 有効なサブスクリプションの一覧から**Habitify**を見つけてタップします。
      5. **サブスクリプションをキャンセル**ボタンをタップして確定します。

      解約後、サブスクリプションページにはプランが更新されないことが表示されます。「サブスクリプションは［日付］に期限切れになります」または「［日付］までこのサブスクリプションを引き続き利用できます」のようなメッセージが表示されます。

      - その有効期限までは、Premiumのすべての特典を引き続き利用できます。
      - その日になると、アカウントは自動的にFree版へ戻ります。
      - 料金は請求されません。
    </Accordion>

    Android端末のHabitifyアプリからサブスクリプションを開始した場合、支払いはPlay Storeへ行われます。そのため、返金申請はGoogleのポリシーに従い、Googleが処理します。[Googleの返金ポリシー](https://support.google.com/googleplay/answer/15574908?sjid=14936331635526272250-NC)をご確認ください。

    返金を申請するには、次の手順に従います。

    1. **Play Store**アプリを開きます。
    2. 右上にある**プロフィール写真**をタップします。
    3. **お支払いと定期購入 > 予算と注文履歴**をタップします。
    4. 返品する注文を見つけ、**問題を報告**をタップします。
    5. ドロップダウンメニューから返金理由を選択します。
    6. 画面の案内に従い、**送信**をクリックします。

    ブラウザーで次の直接リンクを使用することもできます：[<u>Google Playの払い戻しをリクエスト</u>](https://play.google.com/store/account/orderhistory)。

    ## Habitifyプランを変更する

    ### PlusからPROへアップグレードする

    Habitifyですでに有料プランを契約している場合、重複した支払いを避けるために支払いセクションは非表示になります。

    PROの価格をもう一度確認してプランをアップグレードするには、次の手順に従います。

    - ウェブアプリまたはデスクトップアプリで、左側のサイドバーから**オフモード**を開いて休暇を追加するなど、PROの機能へアクセスします。
    - PROの価格が表示され、確認できます。
    - 新しいプランを選択し、**PROへアップグレード**ボタンをクリックします。
    - 手順に従って支払いを承認し、処理します。

    <Warning>
      **アップグレードは、現在のプランで利用している支払い方法から処理する必要があります。**

      - MacでPlusを開始した場合、Appleへ支払っています。Macアプリでアップグレード手続きを行ってください。
      - ウェブサイトまたはWindowsアプリでPlusを開始した場合、当社の決済代行サービスへ支払っています。ウェブサイトまたはWindowsアプリでアップグレード手続きを行ってください。
    </Warning>

    ### 月払いから年払いのPROへ変更する

    Appleへ支払っている場合、Macで次の手順に従ってサブスクリプションプランを変更します。

    1. Macで**App Storeアプリ**を開きます。
    2. 左下にある_自分の名前_をクリックします。サインインしていない場合は「サインイン」をクリックします。サブスクリプションの購入に使用したものと同じ[Appleアカウント](https://support.apple.com/en-vn/guide/app-store/aside/glosbdc8e694/3.0/mac/27)へサインインしてください。
    3. ウィンドウ上部の**アカウント設定**をクリックし、必要に応じてもう一度サインインします。
    4. _管理_セクションで、「サブスクリプション」の横にある**管理**をクリックします。
    5. **編集**をクリックし、**オプション**一覧から設定を選択して、**完了**をクリックします。

    当社の決済代行サービスへ支払っている場合は、支払い請求書を添えてサポートチームへお問い合わせください。サブスクリプションを特定し、更新をサポートします。

    ### サブスクリプションから買い切りプランへ変更する

    現在、サブスクリプションから買い切りへ直接変更することはできません。

    現在のサブスクリプションの更新を解約してください。プランが終了し、アカウントがFreeへ戻るまで待ちます。その時点で支払いセクションがサイドバーへ戻るため、そこから買い切りを購入できます。

    ### 買い切りプランからサブスクリプションへ変更する

    買い切りプランは、1回支払うことで永続的に所有する製品購入です。一定期間に適した支払いプランを利用するためにサブスクリプションへ変更したい場合は、買い切り購入の返金を申請してアカウントをFreeへ戻し、その後サブスクリプションを改めて購入できます。

    Macアプリから買い切りを購入し、Appleへ支払った場合は、次の手順に従います。

    1. [<u>reportaproblem.apple.com</u>](http://reportaproblem.apple.com)にサインインします。
    2. **ご希望の項目を選択してください**をタップまたはクリックし、**返金をリクエストする**を選びます。
    3. 返金を希望する理由を選び、**次へ**を選択します。
    4. **Habitify買い切り**の購入を選び、**送信**を選択します。

    ウェブサイトまたはWindowsアプリから買い切りを購入し、当社の決済代行サービスへ支払った場合は、支払い請求書を添えてお問い合わせください。

    ## Habitifyプランを解約する

    Habitify Web Appでの支払いはすべてPaddleが処理します。支払いのたびに、Paddleから「**Habitifyの領収書**」という件名のメールが届きます。そのメールを見つけてください。

    1. メール内の「**購入についてサポートが必要ですか？[<u>paddle.net</u>](http://paddle.net)からお問い合わせください。**」を見つけ、リンク付きのテキストをクリックします。このリンクには支払いを管理するための専用URLが設定されています。
    2. Paddleの購入サイトでHabitifyのサブスクリプションを見つけ、**サポートを受ける**ボタンをクリックします。
    3. チャットボックスが開くので、解約の依頼を入力します。Paddleから**解約リンク**が案内されます。リンクをクリックし、Paddleの案内に従ってください。

    手続きが複雑になりサポートが必要な場合は、Paddleの領収書メールに添付された支払い請求書を[当社へ転送](mailto:contact@habitify.me)してください。確認のうえ、24時間以内のサブスクリプション解約をサポートします。

    <Note>
      買い切りはアプリ内購入です。買い切りアクセスを取り消したい場合は、直接返金を申請してください。
    </Note>

    ## 返金を申請する

    **Appleへ直接支払ったサブスクリプションと買い切り購入**の返金は、Appleの返金ポリシーに基づいて判断されます。申請後、[<u>返金申請の状況を確認</u>](https://support.apple.com/en-vn/118224)できます。Appleが申請を承認した後、支払い方法へ返金されるまでさらに時間がかかる場合があります。

    **当社の決済代行サービスへ直接支払ったサブスクリプションと買い切り購入**は、当社チームが支払い処理を担当します。支払日から7日間の返金期間を設けています。

    次の手順に従ってください。

    1. 購入後にメールで送信された支払い請求書を見つけます。
    2. 請求書を添付し、サポートチームの[**<u>contact@habitify.me</u>**](mailto:contact@habitify.me)へメールを送信します。
    3. 当社チームが申請内容を確認し、状況に応じて処理します。

    <Accordion title="すでに買い切りプランを持っているのに、月払い／年払いプランの請求がありました。どうすればよいですか？">
      買い切りプランへのアップグレードは、月払いまたは年払いのプレミアムサブスクリプションを自動的に解約するものではありません。

      - 習慣数が無制限
      - 習慣ごとのリマインダー数が無制限
      - カスタムエリア数が無制限

      PROプランを利用しているにもかかわらず、支払い後に有料機能へアクセスできない場合は、PROの購入に使用した正しいアカウントでサインインしていることを確認してください。

    </Accordion>
