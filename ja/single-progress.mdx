sidebarTitle: "単一の進捗"
---

個別進捗は、ジャーナルまたは進捗画面で習慣をタップして開く、1つの習慣の詳細画面です。カレンダー、成績グラフ、継続状況を示す正確な数値から、1つの連続記録の履歴全体を確認できます。

良い習慣と悪い習慣には、それぞれ個別進捗画面があります。この記事では両方の画面を説明します。

<Tabs>
  <Tab title="iOS">
    ## 良い習慣の個別進捗

    ### 現在の連続記録

    ![Current Streak Good Habit Single I OS](/images/CurrentStreak-GoodHabitSingle-iOS.png "Current Streak Good Habit Single I OS")

    最初に、その習慣で現在維持している連続記録が表示されます。目標期間によって増え方が異なります。

    - **日次目標：** 繰り返し予定日に習慣を完了すると増え、下に直近7日間の進捗が表示されます。
    - **週次目標：** 週の目標を完了すると増え、直近7週間または開始した週からの進捗が表示されます。
    - **月次目標：** 月の目標を完了すると増え、直近7か月または開始月からの進捗が表示されます。
    - **年次目標：** 年の目標を完了すると増え、直近7年間または開始年からの進捗が表示されます。

    ### **終了条件までの進捗バー**

    終了条件を設定している場合、最終目標までの道のりを示す進捗バーが表示されます。これまで達成した量と、大きな目標までに残る量を視覚的に確認できます。

    ### 主要指標

    ![Core Index Good Habit Single I OS](/images/CoreIndex-GoodHabitSingle-iOS.png "Core Index Good Habit Single I OS")

    4つの指標があります。

    - **成功：** その月に習慣の目標を達成した日数。
    - **失敗：** その月に失敗として記録した日数。
    - **スキップ：** その月にスキップとして記録した日数。
    - **合計：** その月に完了した総量または回数。分など、目標と同じ単位で表示されます。

    各数値の下では、今月と先月、今年と前年など、直前期間の合計と比較できます。

    <Note>
      **「成功」の計算方法**

      - 日次習慣：目標を完了した日数。
      - 週次目標：週の目標を完了すると、スキップまたは失敗の日を除いた7日を成功として数えます。
      - 月次目標：月の目標を完了すると、スキップまたは失敗の日を除いた月の日数を成功として数えます。
      - 年次目標：年の目標を完了すると、スキップまたは失敗の日を除いた年の日数を成功として数えます。
    </Note>

    ### カレンダーでの進捗

    ![Calendar View Good Habit Single I OS](/images/CalendarView-GoodHabitSingle-iOS.png "Calendar View Good Habit Single I OS")

    月内の進捗を、日ごとの状態に応じた記号で表示します。

    - **塗りつぶされた円：** 完了にした日、または週、月、年目標の習慣で進捗がある日。
    - **未完成の円：** 日次目標の習慣で一部だけ進めた日。
    - **右向き矢印：** スキップした日。
    - **黒い×：** 失敗にした日。

    右へスワイプすると前月、左へスワイプすると現在月までの後の月を確認できます。

    ### 連続記録の履歴

    日次目標では、最初から最新までに達成した連続記録を表示します。

    ![Streak Daily Good Habit Single I OS](/images/StreakDaily-GoodHabitSingle-iOS.png "Streak Daily Good Habit Single I OS")

    週、月、年目標では、開始期間以降の各週、月、年の完了率を表示します。

    ![Streak Period Good Habit Single I OS](/images/StreakPeriod-GoodHabitSingle-iOS.png "Streak Period Good Habit Single I OS")

    ### 傾向棒グラフ

    ![Trend Chart Good Habit Single I OS](/images/TrendChart-GoodHabitSingle-iOS.png "Trend Chart Good Habit Single I OS")

    時間の経過に伴う成績を示します。下部で**日、週、月、年**を切り替え、日々の状況から長期傾向まで確認できます。

    - **成績の傾向：** 各棒は、曜日や月など選択した各期間の合計達成量を示します。
    - **正確な詳細：** 棒を長押しすると、その期間の達成値を確認できます。
    - **平均：** 習慣を始めてからの1期間あたり平均達成量。

    グラフの**赤い破線**は設定した目標です。例：1日2,000 m歩く目標なら、日次グラフの2,000 mへ線が表示され、達成または超過した日をすぐに確認できます。

    ### 継続性の折れ線グラフ

    ![Consistency Good Habit Single I OS](/images/Consistency-GoodHabitSingle-iOS.png "Consistency Good Habit Single I OS")

    日次目標の習慣では、30、60、90、180日の選択期間における成績を、単純な連続記録より細かく示す**継続性指数**を確認できます。

    連続記録が成功か失敗かの二択なのに対し、継続性指数は**努力と立て直す力**を評価します。連続記録が途切れても高い継続性を維持できるため、長期的な自己改善を現実的に捉えられます。

    計算例は次のとおりです。

    <Info>
      **分かりやすくするため、3日間の習慣を例にします。**

      **1日目：** 習慣を完了。

      - **日次値：** 100%
      - **1日目の日次継続性：** 100%（まだ1日目だけなので、その平均）

      **2日目：** 目標の半分を完了。

      - **日次値：** 50%
      - **2日目の日次継続性：**（100%［1日目］＋50%［2日目］）÷2＝**75%**

      **3日目：** 習慣に失敗。

      - **日次値：** 0%
      - **3日目の日次継続性：**（100%＋50%＋0%）÷3＝**50%**

      **最終計算：** この3日間の**全体継続性**は、日次継続性の平均です：`（100%＋75%＋50%）÷3＝75%`
    </Info>

    グラフ内の**破線**は過去の成績で、現在の継続傾向が以前より良いか悪いかを比較できます。

    - 直近**30日**では、破線は**その前の60日間**の平均。
    - 直近**60日**では、**その前の120日間**の平均。
    - 直近**90日**では、**その前の180日間**の平均。

    実線と破線の位置関係から、継続性が上向きか下向きかを判断できます。

    ## 悪い習慣の個別進捗

    ### 現在の連続記録

    ![Current Streak Bad Habit Single I OS](/images/CurrentStreak-BadHabitSingle-iOS.png "Current Streak Bad Habit Single I OS")

    最初に、その悪い習慣で現在維持している連続記録が表示されます。

    **制限型習慣**では目標に応じて増えます。

    - 日次上限：その日を成功で終えると増えます。
    - 週次上限：週の実行量を上限内に保つと増えます。
    - 月次上限：月の実行量を上限内に保つと増えます。
    - 年次上限：年の実行量を上限内に保つと増えます。

    **断絶型習慣**では、その日に習慣を避けて成功と記録されると増えます。

    ### 主要指標

    ![Core Index Bad Habit Single I OS](/images/CoreIndex-BadHabitSingle-iOS.png "Core Index Bad Habit Single I OS")

    グリッド形式のレポートで、達成と変化を示す数値を確認できます。

    - **成功：** 選択期間中、悪い習慣を行わなかった、または上限内に収めた回数。
    - **失敗：** 上限を超えて失敗した日数。
    - **ゼロの日（制限型のみ）：** 習慣をまったく行わなかった日数。
    - **合計（制限型のみ）：** 悪い習慣を行った総量。単位が「分」なら合計時間を表示します。

    週、月、年単位の制限型習慣では、上限を超えて失敗すると、その日と現在の期間の残りの日が「失敗」として数えられます。

    ### カレンダーでの進捗

    ![Calendar Bad Habit Single I OS](/images/Calendar-BadHabitSingle-iOS.png "Calendar Bad Habit Single I OS")

    月内の進捗を、日ごとの状態に応じた記号で表示します。

    - **塗りつぶされた円：** 成功にした日。
    - **右向き矢印：** スキップした日。
    - **黒い×：** 失敗にした日。

    右へスワイプすると前月、左へスワイプすると現在月までの後の月を確認できます。

    ### 傾向棒グラフ

    ![Trend Chart Bad Habit Single I OS](/images/TrendChart-BadHabitSingle-iOS.png "Trend Chart Bad Habit Single I OS")

    日、週、月、年ごとの成績と、記録開始以降の平均進捗値を示します。特定の棒をタップすると、選択した日、週、月、年の正確な量を確認できます。

    ### 連続記録の履歴

    断絶型または日次制限型では、最初から最新までの連続記録を表示します。

    ![Streak Daily Bad Habit Single I OS 1](/images/StreakDaily-BadHabitSingle-iOS-1.png "Streak Daily Bad Habit Single I OS 1")

    週、月、年単位の制限型では、開始期間以降の各週、月、年の記録値を表示します。

    ![Streak Period Bad Habit Single I OS](/images/StreakPeriod-BadHabitSingle-iOS.png "Streak Period Bad Habit Single I OS")

    ## iPhone Duoの個別進捗

    iPhone Duoを折りたたんだ状態、または開いて縦向きにした状態では、通常のiPhoneと同じ表示です。

    **iPhone Duoでの個別進捗は次の動画で確認できます。**

    <iframe src="https://drive.google.com/file/d/1cW7vDzIvVgp8Muk33-xs1V5l7BFRziw3/preview" width="640" height="360" />

    **端末を開いて横向きにすると表示が変わります。** 右側に選択月、左側にその前月の2か月を並べ、月を切り替えずに最近の進捗を比較できます。

    成功、失敗、スキップ、合計のカードは上部へ広がり、ほかのセクションはカレンダーの下ではなく横へ配置されるため、1画面でより多くの進捗を確認できます。

    終了条件を設定している場合、最終目標までの道のりを示す進捗バーが表示されます。これまで達成した量と、目標までに残る量を視覚的に確認できます。

    ### 主要指標

    4つの指標があります。

    - **成功：** その月に習慣の目標を達成した日数。
    - **失敗：** その月に失敗として記録した日数。
    - **スキップ：** その月にスキップとして記録した日数。
    - **合計：** その月に完了した総量または回数。分など、目標と同じ単位で表示されます。

    各数値の下では、今月と先月、今年と前年など、直前期間の合計と比較できます。

    <Note>
      **「成功」の計算方法**

      - 日次習慣：目標を完了した日数。
      - 週次目標：週の目標を完了すると、スキップまたは失敗の日を除いた7日を成功として数えます。
      - 月次目標：月の目標を完了すると、スキップまたは失敗の日を除いた月の日数を成功として数えます。
      - 年次目標：年の目標を完了すると、スキップまたは失敗の日を除いた年の日数を成功として数えます。
    </Note>

    ### カレンダーでの進捗

    表示中の月を左側に置き、連続する2か月の進捗を表示します。各日は状態に応じた記号で示されます。

    - **塗りつぶされた円：** 完了にした日、または週、月、年目標の習慣で進捗がある日。
    - **未完成の円：** 日次目標の習慣で一部だけ進めた日。
    - **右向き矢印：** スキップした日。
    - **黒い×：** 失敗にした日。

    ### 連続記録の履歴

    日次目標では、最初から最新までに達成した連続記録を表示します。週、月、年目標では、開始期間以降の各週、月、年の完了率を表示します。

    ### 傾向棒グラフ

    時間の経過に伴う成績を示し、下部で**日、週、月、年**を切り替えられます。

    - **成績の傾向：** 各棒は選択した各期間の合計達成量を示します。
    - **正確な詳細：** 棒を長押しすると、その期間の達成値を確認できます。
    - **平均：** 習慣を始めてからの1期間あたり平均達成量。

    **赤い破線**は設定した目標です。例：1日2,000 m歩く目標なら、日次グラフの2,000 mへ線が表示され、達成または超過した日をすぐに確認できます。

    ## 悪い習慣の個別進捗

    ![Bad Habit Single Web&desktop](/images/BadHabitSingle-Web&Desktop.png "Bad Habit Single Web&desktop")

    上から下、左から右へ、次の情報が表示されます。

    - 現在の連続記録。
    - 表示中の月の主要指標。
    - 現在月と前月を並べたカレンダー。

    ### 現在の連続記録

    最初に、その悪い習慣で現在維持している連続記録が表示されます。

    **制限型習慣**では目標に応じて増えます。

    - 日次上限：その日を成功で終えると増えます。
    - 週次上限：週の実行量を上限内に保つと増えます。
    - 月次上限：月の実行量を上限内に保つと増えます。
    - 年次上限：年の実行量を上限内に保つと増えます。

    **断絶型習慣**では、その日に習慣を避けて成功と記録されると増えます。

    ### 主要指標

    グリッド形式のレポートで、達成と変化を示す数値を確認できます。

    - **成功：** 選択期間中、悪い習慣を行わなかった、または上限内に収めた回数。
    - **失敗：** 上限を超えて失敗した日数。
    - **ゼロの日（制限型のみ）：** 習慣をまったく行わなかった日数。
    - **合計（制限型のみ）：** 悪い習慣を行った総量。単位が「分」なら合計時間を表示します。

    週、月、年単位の制限型習慣では、上限を超えて失敗すると、その日と現在の期間の残りの日が「失敗」として数えられます。

    ### カレンダーでの進捗

    月内の進捗を、日ごとの状態に応じた記号で表示します。

    - **塗りつぶされた円：** 成功にした日。
    - **右向き矢印：** スキップした日。
    - **黒い×：** 失敗にした日。

    右へスワイプすると前月、左へスワイプすると現在月までの後の月を確認できます。

    ### 傾向棒グラフ

    日、週、月、年ごとの成績と、記録開始以降の平均進捗値を示します。特定の棒をタップすると、選択した日、週、月、年の正確な量を確認できます。

    ### 連続記録の履歴

    断絶型または日次制限型では、最初から最新までの連続記録を表示します。週、月、年単位の制限型では、開始期間以降の各週、月、年の記録値を表示します。
