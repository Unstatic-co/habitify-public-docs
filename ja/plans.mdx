## 利用できるプラン

Habitifyには3つのメンバーシッププランがあります。

- **無料**：同時に最大3つのアクティブな習慣を追跡でき、習慣ごとに1つの時刻リマインダーを設定できます。毎日チェックインして連続記録を伸ばし、進捗に関する簡単なメモを残せます。
- **Plus**：無料プランの機能に加えて、習慣とリマインダーを無制限に作成でき、習慣をまとめるカスタムエリアも利用できます。
- **Pro**：Plusの機能に加えて、習慣管理の機能やツールがさらに増え、高度な自動化やサードパーティアプリとの連携も利用できます。

## プラットフォーム別のお支払いオプション

お支払いオプションは、購読するプラットフォームによって異なります。

| プラットフォーム | 無料 | Plus | Pro |
| :-- | :-: | :-: | :-: |
| iOS | ✓ | 年額 | **年額（12か月契約付き）**、年額、買い切り |
| Android | ✓ | 年額 | 月額、年額、買い切り |
| Web | ✓ | 年額 | 月額、年額、買い切り |

- **Plusはすべてのプラットフォームで年額のみです。** 月額プラン（AndroidとWeb）または買い切りをご希望の場合は、Proを選択してください。
- **買い切りはProでのみ利用できます。** 一度きりのお支払いで、定期購入ではありません。

## 重要：iOSの12か月契約付き年額プランについて

<Warning>
  iOSでは、このプランは月額ではなく**年額プラン**です。お支払いは12回の月払いですが、12回すべてのお支払いを完了することが条件となります。解約しても、残りのお支払いは停止されません。
</Warning>

これは、Appleが提供する年間サブスクリプション向けのお支払いオプションです。Proの1年分の料金を、一括払いではなく12回の月払いに分割します。一括でお支払いになる場合は、通常の**年額**プランを選択してください。

### 仕組み

- Pro年額プランの料金が12回に分割されます。
- 毎月の分割金をお支払いいただくことで、期間中ずっとProのすべての機能を利用できます。
- 12回目のお支払い後、解約していない場合は、新たな12か月契約として更新されます。

### 解約すると

いつでも解約できます。解約すると、次のようになります。

- 契約期間が終了するまで、Proを**引き続き利用できます**。
- 契約期間の終了後は、サブスクリプションが**更新されません**。
- 残りの月払いは**停止されません**。引き続き請求されます。

新たな12か月契約への更新を避けるには、更新日の少なくとも1日前までに解約してください。

<Note>
  Appleは、このオプションをiOS 26.4以降で提供しており、米国とシンガポールでは提供していません。[Appleの詳細はこちら](https://support.apple.com/en-vn/126901)。
</Note>

### 12か月契約付きProプランに関するよくある質問

<AccordionGroup>
  <Accordion title="契約付きプランをすぐに解約して、支払いを止めることはできますか？">
    できません。12か月契約付きの年額プランを解約しても、お支払いの契約は終了しません。残りの月数分は引き続き請求され、すべてのお支払いが終わるまでProを利用できます。解約によって防げるのは、次回の更新のみです。

    契約なしでProを利用したい場合は、AndroidまたはWebで購読してください。これらのプラットフォームのPro月額プランには、12か月契約は付いていません。
  </Accordion>

  <Accordion title="サブスクリプションを解約するにはどうすればよいですか？">
    1. iPhoneまたはiPadで、**設定**アプリを開きます。
    2. **自分の名前**、**サブスクリプション**の順にタップします。
    3. **Habitify**をタップします。
    4. **サブスクリプションをキャンセルする**をタップし、確認します。

    iOSでのご購入のお支払いはAppleが管理しているため、HabitifyからAppleのサブスクリプションを解約することはできません。
  </Accordion>

  <Accordion title="残りのお支払い回数を確認するにはどうすればよいですか？">
    **設定 → 自分の名前 → サブスクリプション → Habitify**を開きます。お支払い済みの回数と残りの回数がAppleの画面に表示されます。また、更新の前には、Appleからメールが届きます。通知を有効にしている場合は、プッシュ通知も届きます。
  </Accordion>

  <Accordion title="解約したのに、なぜ請求されたのですか？">
    12回すべてのお支払いが完了する前に解約した場合でも、残りの月払いは引き続き請求されます。これは正常な動作です。更新日より前に解約していれば、12回目のお支払いが最後の請求になります。
  </Accordion>

  <Accordion title="残りのお支払いについて返金を受けられますか？">
    iOSでのご購入の返金は、HabitifyではなくAppleが対応します。[reportaproblem.apple.com](https://reportaproblem.apple.com)から申請でき、承認されるかどうかはAppleが判断します。
  </Accordion>

  <Accordion title="アプリに12か月契約のオプションが表示されないのはなぜですか？">
    Appleは、このお支払いオプションを米国とシンガポールでは提供しておらず、iOS 26.4以降が必要です。どちらかに該当する場合は、年額（一括払い）または買い切りを選択してください。
  </Accordion>
</AccordionGroup>

## Proを利用するその他の方法

- [**Habitify Family**](/habitify-family)：Appleのファミリー共有を通じて、ご家族でProを共有できます。
- [**Habitify Team**](/habitify-team)：Proのアクセス権をまとめて購入し、チームコードで配布できます。
- [**Habitify Student**](/habitify-student)：有効な学校のメールアドレスで、Pro年額プランの初年度が50%オフになります。
