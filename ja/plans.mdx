## ご利用可能なプラン

メンバーシッププランは3種類あります。

- **無料**：同時に最大3件の有効な習慣を記録でき、習慣ごとに時間指定リマインダーを1件設定できます。毎日のチェックイン、連続達成記録の積み上げ、進捗に関する基本的なメモの保存が可能です。
- **Plus**：習慣とリマインダーを無制限に記録でき、習慣をまとめるためのカスタムエリアを追加できます。
- **Pro**：Plusのすべての機能に加えて、さらに多くの習慣機能とツール、高度な自動化、サードパーティ製アプリとの連携を利用できます。

## お支払いオプション

各有料プランでは、ご利用期間に合わせて異なる請求サイクルを選択できます。

| プラン | 月額 | 年額 | 買い切り |
| :-- | :-: | :-: | :-: |
| Habitify Plus | — | ✓ | — |
| Habitify Pro | ✓ | ✓ | ✓ |

以下の点にご注意ください。

- **Plusは年額プランのみです。** 月額プランまたは買い切りをご希望の場合は、Proをお選びください。
- **買い切りはProでのみ利用できます。** 定期購入ではなく、1回限りのお支払いです。
- **iOSアプリのPro月額プランには12か月の継続利用条件があります。** いつでも解約できる請求サイクルではありません。[詳細はこちら](https://support.apple.com/en-vn/126901)。
