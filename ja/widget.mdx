Habitifyのウィジェットを使うと、アプリを開かなくても、**ホーム画面**やロック画面から習慣の進捗をすばやく詳しく確認できます。

この記事では、Habitifyで利用できるすべてのウィジェットを紹介します。

## ウィジェットの種類

<Tabs>
  <Tab title=" iOS">
    ## ホーム画面のウィジェット

    ### **進捗チェーン**

    ![Progress Chain Widget I OS](/images/Progress-Chain-Widget-iOS.png "Progress Chain Widget I OS")

    習慣一覧と、各習慣の進捗を表すヒートマップを表示します。

    期間は、_過去7日、過去14日、過去21日、過去30日、今週、今月_から選べます。一覧には、すべての習慣、現在の時間帯、またはカスタムエリアを指定できます。

    3つのサイズがあります。

    - 小：最大3件
    - 中：最大3件
    - 大：最大8件

    ### 現在の連続記録

    ![Current Streak Widget I OS](/images/Current-Streak-Widget-iOS.png "Current Streak Widget I OS")

    選んだ1つの良い習慣について、現在の連続記録を表示します。ホーム画面で記録が伸びる様子を確認でき、継続の励みになります。利用できるのは小サイズだけです。

    ### 継続グリッド

    ![Consistency Grid Widget I OS](/images/Consistency-Grid-Widget-iOS.png "Consistency Grid Widget I OS")

    良い習慣の進捗をヒートマップで表示します。

    - 小：過去96日
    - 中：過去216日

    ### **今日の習慣**

    ![Today Habits Widget I OS](/images/Today-Habits-Widget-iOS.png "Today Habits Widget I OS")

    当日に繰り返す良い習慣をコンパクトな一覧で表示します。すべての習慣、現在の時間帯、またはカスタムエリアを選択でき、各習慣の横には現在の連続記録が表示されます。順序は**設定 → すべての習慣**で設定したものに従います。

    - 小：最大3件
    - 中：最大3件
    - 大：最大8件

    ### タップして記録

    ![Tap To Track Widget I OS](/images/Tap-to-Track-widget-iOS.png "Tap To Track Widget I OS")

    ホーム画面から習慣のステータスを更新できます。2つのボタンを、完了、スキップ、失敗としてマークする操作、またはタイマー開始に設定できます。利用できるのは小サイズだけです。

    ### 経過日数

    ![Days Since Widget I OS](/images/Days-Since-Widget-iOS.png "Days Since Widget I OS")

    やめることを目標にした1つの悪い習慣をホーム画面で記録します。好ましくない行動を促さないよう、チェックインや進捗記録のボタンはありません。悪い習慣を避けられた現在の連続記録を確認できます。小サイズだけです。

    ### 目標の進捗

    ![Goal Progress Widget I OS](/images/Goal-Progress-Widget-iOS.png "Goal Progress Widget I OS")

    週、月、年単位の目標を持つ良い習慣の進捗バーを表示します。小サイズだけです。

    ### 上限トラッカー

    制限を目標にした悪い習慣の進捗バーです。中央の赤い縦線が超えないようにする上限を示し、超過分は赤色で表示されます。小サイズだけです。

    ![Limit Tracker Widget I OS](/images/Limit-Tracker-Widget-iOS.png "Limit Tracker Widget I OS")

    ## ロック画面のウィジェット

    iOS 16以降では、ロック画面にウィジェットを追加できます。Habitifyは「今日の習慣」「継続グリッド」「タップして記録」を用意しており、ロックを解除する前に進捗を確認できます。

    **追加方法：**

    1. **カスタマイズ**が表示されるまでロック画面を長押しします。
    2. **カスタマイズ → ロック画面**をタップします。
    3. ウィジェット領域をタップしてギャラリーを開きます。
    4. 一覧から**Habitify**を探し、追加するウィジェットを選びます。
    5. カスタマイズ画面の外側をタップして保存します。

    ![Lockscreen Widget I OS](/images/Lockscreen-widget-iOS.png "Lockscreen Widget I OS")

    ## ウィジェットからチェックインする

    ウィジェット上の習慣をタップすると、アプリのジャーナルが開き、対象の習慣が強調表示されます。一覧から探しやすくなり、すぐに進捗を記録できます。

    **タップして記録**では、次の操作もできます。

    - 完了、スキップ、失敗のボタンをタップすると、ホーム画面上で記録が処理・保存されます。
    - タイマーをタップするとアプリが開き、すぐにタイマー画面へ移動します。

    ## ウィジェットのサイズ変更：機能と制限

    iOSでは角をドラッグして自由にサイズを変えられず、用意された標準サイズから選びます。

    ### **サイズを変更する**

    複数サイズに対応するウィジェットでは、長押しして表示されるメニューから利用可能なサイズを選びます。

    ### **制限**

    1つのサイズだけに対応するウィジェットはアプリアイコンへ縮小できますが、後から元のサイズへ戻すことはできません。ウィジェットギャラリーから追加し直してください。

    ## よくある質問

    <Accordion title="**Habitifyのウィジェットが見つかりません。どうすればよいですか？**">
      まず、Habitifyが最新版であることを確認します。**App Store → プロフィール**を開き、Habitifyに更新があれば**アップデート**をタップします。

      次に、**設定 → スクリーンタイム → コンテンツとプライバシーの制限**で、ウィジェットが許可されていることを確認します。

      解決しない場合は、電源ボタンを長押しして電源を切り、Appleロゴが表示されるまで再度長押ししてデバイスを再起動します。

      それでも表示されない場合は、Habitifyのアイコンを長押しして**Appを削除**し、App Storeから再インストールします。
    </Accordion>

    <Accordion title="**習慣の変更がウィジェットへ反映されません。どうすればよいですか？**">
      主な原因は次のとおりです。

      - **強いバッテリー最適化：** OSは電池を長持ちさせるため、ウィジェットなどのバックグラウンド処理が新しいデータを取得する頻度を制限します。更新が数分以上遅れる場合があります。
      - **ウィジェットは別のプロセス：** ホーム画面上の小さなアプリとしてHabitify本体と通信します。OSが本体を休止させると、新しいデータを取得できず、最後に受け取った情報を表示します。

      まず、次の一般的な手順をお試しください。

      1. **Habitifyを開く：** アプリを開き、30〜60秒間前面に表示します。
      2. **ウィジェットを削除して追加し直す：** 設定とデータが完全に再読み込みされます。
      3. **デバイスを再起動する：** 一時的なシステムの問題を解消できます。

      iOSでは更新時刻をシステムが管理します。キャッシュを更新するには、次を行います。

      - **ウィジェットを編集：** 長押しして**ウィジェットを編集**をタップし、データソースを「すべての習慣」から「エリア」へ変更して戻す、または対象の習慣を選び直します。
      - **Appのバックグラウンド更新を有効にする：** **設定 → 一般 → Appのバックグラウンド更新**で機能をオンにし、Habitifyも有効にします。
    </Accordion>

    <Accordion title="**一部のウィジェットに悪い習慣が表示されないのはなぜですか？**">
      悪い習慣は「今日の習慣」と「進捗チェーン」には表示されません。毎日の一覧を前向きで行動しやすいものに保つためです。

      1. **「今日の一覧」は行動するためのものです。** 「禁煙」のような悪い習慣を実行項目の一覧に置くと逆効果になります。悪い習慣は、前向きなタスクと並べて思い出すのではなく、避けることが目標です。
      2. **「進捗チェーン」は成功を祝うものです。** 悪い習慣の成功は、何もしないことや避けることで達成します。表示すると空欄や失敗（X）が並び、毎日ホーム画面で見るには励みになりません。

      良い習慣に絞ることで、より前向きで行動中心のダッシュボードになります。
    </Accordion>

    <Accordion title="**iPhoneをロックするとHabitifyのウィジェットが消えるのはなぜですか？**">
      不具合ではなく、iOSのプライバシー機能です。認証前に機密情報が見えないよう、初期設定ではロック中にウィジェットの内容を隠します。

      常に表示するには、次の手順を行います。

      1. iPhoneの**設定**を開きます。
      2. **Face IDとパスコード**（または**Touch IDとパスコード**）をタップします。
      3. パスコードを入力します。
      4. **ロック中にアクセスを許可**までスクロールします。
      5. **ロック画面のウィジェット**をオンにします。古いiOSでは**今日の表示と検索**と表示される場合があります。
    </Accordion>

    ## ホーム画面のウィジェット

    ### **継続グリッド**

    良い習慣の進捗をヒートマップで表示します。表示する履歴の長さは、ホーム画面上のサイズによって変わります。

    ![Consistency Grid Widget Android](/images/Consistency-Grid-widget-Android.png "Consistency Grid Widget Android")

    ### **経過日数**

    やめることを目標にした1つの悪い習慣をホーム画面で記録します。好ましくない行動を促さないよう、チェックインや進捗記録のボタンはありません。悪い習慣を避けられた現在の連続記録を確認できます。

    ![Days Since Widget Android](/images/Days-Since-Widget-Android.png "Days Since Widget Android")

    ### **目標トラッカー**

    週、月、年単位の目標を持つ良い習慣、または制限を目標にした悪い習慣を記録します。

    - 良い習慣では、目標達成までの進捗バーを表示します。

    ![Goal Progress Widget Android](/images/Goal-progress-widget-Android.png "Goal Progress Widget Android")

    - 制限する悪い習慣では、上限に対する進捗バーを表示します。中央の赤い縦線が超えないようにする上限を示し、超過分は赤色になります。

    ![Limit Tracker Widget Android](/images/Limit-Tracker-Widget-Android.png "Limit Tracker Widget Android")

    ### 現在の連続記録

    選んだ1つの習慣について、現在の連続記録を表示して継続を後押しします。

    ![Current Streak Widget Android](/images/Current-Streak-Widget-Android.png "Current Streak Widget Android")

    ### 今日の習慣

    当日に繰り返す良い習慣をコンパクトな一覧で表示します。すべての習慣、またはエリアの習慣を選べ、各習慣の横には現在の連続記録が表示されます。順序はアプリ内のジャーナルでの並び順に従います。

    習慣を完了すると、連続記録が更新され、未完了の項目を優先するため一覧の一番下へ移動します。

    ![Today Habits Widget Android](/images/Today-habits-widget-Android.png "Today Habits Widget Android")

    ## ウィジェットからチェックインする

    ウィジェット上の習慣をタップすると、アプリのジャーナルが開き、一覧が対象の習慣まで移動します。すぐに進捗を記録できます。

    ## **ウィジェットのサイズ変更：機能と制限**

    Androidでは、配置後もほとんどのウィジェットを自由に変更できます。

    ### **サイズを変更する**

    1. Habitifyのウィジェットをホーム画面へ配置します。
    2. 端にサイズ変更用の点や線が表示されるまで**長押し**します。
    3. **ハンドルをドラッグ**して希望のサイズへ変更します。
    4. 内容は新しい寸法に合わせて自動調整されます。

    ### **制限**

    主な制限はデバイス固有のランチャーです。メーカーによって操作が少し異なる場合があります。

    ## よくある質問

    <Accordion title="**習慣の進捗がウィジェットで更新されません。どうすればよいですか？**">
      まず、Habitifyを開いて30〜60秒間前面に表示する、ウィジェットを削除して追加し直す、デバイスを再起動する、の順にお試しください。

      Androidでは、ほとんどの場合、強いバッテリー最適化によってアプリのバックグラウンド動作が止められています。

      - **バッテリーを「制限なし」にする：** **設定 → アプリ → Habitify → バッテリー**で、「最適化」から**制限なし**へ変更します。
      - **最近使ったアプリでロックする（特にXiaomi／OnePlus／Oppo）：** 最近使ったアプリを開き、Habitifyのプレビューを長押しして**ロックアイコン**をタップします。
      - **自動起動の権限を確認する：** 設定の「自動起動」または「起動」管理でHabitifyを有効にします。
    </Accordion>

    <Accordion title="**一部のウィジェットに悪い習慣が表示されないのはなぜですか？**">

      2. **「進捗チェーン」は成功を祝うものです。** 悪い習慣の成功は、何もしないことや避けることで達成します。表示すると空欄や失敗（X）が並び、励みになりません。

      良い習慣に絞ることで、より前向きで行動中心のダッシュボードになります。
    </Accordion>
