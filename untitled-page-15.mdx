## Zapier integration

Zapier connects Habitify with over 500 other apps and tools. Each connection you build is called a **Zap**, made up of two parts: a **trigger** (the event that starts the Zap, like completing a habit in Habitify) and an **action** (what happens as a result, like adding a row to a spreadsheet).

Start using Habitify on Zapier: [https://zapier.com/apps/habitify/integrations](https://zapier.com/apps/habitify/integrations)

Each connection between Habitify and an app or tool using Zapier Integration is called a zap.

- **a Trigger**: an event that starts a Zap
- **an Action**: an event that a Zap performs.

### **Triggers by Habitify to a Zap**

- **Add new log**: Triggers when you add a new progress log for a habit
- **Add new mood**: Triggers when you add a mood log.
- **Add new note**: Triggers when you add a new note for a habit.
- **Add new status**: Triggers when you mark a habit as completed, skipped, or failed.

### **Actions by a Zap to Habitify**

- **Add Log**: Add logs to your habit after an action from other apps
- **Add Mood**: Create a new mood after an action from other apps
- **Add Note**: Add a note on your habit after an action from other apps
- **Update Status**: Change the status of your habit after an action from other apps

## IFTTT integration

IFTTT, short for "If This, Then That", is a broader automation service connecting apps, devices, and services, with over 700 services available.

Start using Habitify on IFTTT: [https://ifttt.com/habitify](https://ifttt.com/habitify)

Where Zapier connections are called Zaps, IFTTT connections are called **Applets**. An Applet is built from three pieces:

- a **trigger**: the data change that starts it, either real-time or polling.
- a **query**: optional extra data pulled in along the way.
- an **action**: what IFTTT does once the trigger fires.

### Triggers by Habitify to an Applet

- **New habit status:** Triggers when a habit is updated with a new status.
- **New mood logged:** Triggers when a new mood is logged.
- **New habit log:** Triggers when a new log is added to your habit.
- **New habit note:** Triggers when a note is added on your habit.

### Actions by an Applet to Habitify

- **Create a new log:** This action will add a new log on your habit
- **Create a new mood:** This action will add a new mood log
- **Create a new note:** This action will add a new note on your habit
- **Update status of habit:** This action will update the status of your habit

## FAQs

<Accordion title="Zapier vs. IFTTT: which one to use?">
  Both do fundamentally the same job: letting Habitify talk to other apps, but they lean in different directions:

  - **Zapier** tends to be the stronger choice for connecting Habitify to productivity and business tools (spreadsheets, task managers, CRMs), with more room for multi-step workflows.
  - **IFTTT** tends to be the stronger choice for smart home devices and simpler, single-action automations.

  If the tool you want to connect is supported by both, it usually comes down to which platform you already use for your other automations.
</Accordion>

<Accordion title="Is there any paid subscriptions required to use these integrations?">
  Basically, you can use Habitify and set up these integrations with free plan. You'll only run into a cost if you hit a paid feature or use up the free quota , at which point you'd pay according to that service's own pricing policy.
</Accordion>
